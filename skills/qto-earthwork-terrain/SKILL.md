# 土方与场地标高算量

先按用户目标定阶段：范围/能力问答只读相关边界与能力披露；用户仅要求已有明细复核时做表内复核；原始资料算量执行下文。用户要求检验或改进独立算量能力、底稿仅作参照时，执行[原图独立算量实测](../_qto-shared-evidence/references/原图独立算量实测.md)，不得因已有底稿或历史结果改成表内复核。表内复核不核准原图，细则按需见 [分阶段读取](../_qto-shared-evidence/references/按任务阶段读取.md)。

原图算量先读取并执行 [人工思路识图与算量流程](../_qto-shared-evidence/references/人工思路识图与算量流程.md)。模型负责依据图纸识别工程对象并形成可复核工作量，工具负责取证和计算；人工复核与正式采用另列，不以“用户尚未逐对象核定”代替模型识图。

先读现状/设计标高、基础或管沟平剖面及施工口径，按区域构建开挖和回填边界；计算并集、分层与占位，再核对标高和土方平衡。

以“标高基准 + 土方边界 + 土体状态 + 计量基准”为主线。缺少会改变结果的标高、支护、放坡或回填边界时，先形成可复算的方案量及影响；无法形成有意义候选才输出 `null`，不得用零或隐藏经验值补齐。

## 先判定对象边界

直接读取 [对象范围与相邻边界](references/对象范围与相邻边界.md)。

- 本 Skill 承担基坑、基槽、管沟、一般开挖、场地挖填、回填、余方、借方和场地平整。
- 道路挖填可由本 Skill承担土方边界；道路基层、面层、路缘石和沟渠构造交给 `qto-roads-siteworks`。
- 管沟土方在本 Skill；管道中心线、管径、阀门和管件交给 `qto-pipe-networks`。
- 桩孔、成孔、灌注、褥垫层和地基处理交给 `qto-piles-groundwork`；基坑内混凝土基础交给 `qto-concrete-formwork`。
- 支护构件本体不在本 Skill；但支护或批准放坡方案形成的开挖边界是本 Skill输入。

## 执行顺序

### 1. 锁定范围、来源和标高基准

读取 [图纸与资料范围筛选](../_qto-shared-evidence/references/图纸与资料范围筛选.md)，至少锁定项目、区域、图纸版本、坐标和高程系统、原始地面、设计或批准施工标高、基础或管沟底标高、土石类别、施工方案和输出维度。

项目、地区、合同和标准规则的采用顺序先按公共 [现行规则来源选择门](../_qto-shared-evidence/references/现行规则来源选择门.md) 判断；适用版本或优先级未闭合时，只形成不依赖争议规则的物理事实或明确命名的候选参考量。

先区分 [土石方计量基准与分层](references/土石方计量基准与分层.md) 中的四类数量：

- `physical_geometry`：可由图纸或测量事实直接表达的物理几何量；
- `scheme_reference`：按明确但尚未批准或仅用于比较的施工假设形成的方案参考量；
- `standard_boq`：适用计量标准闭合后形成的清单计量量；
- `project_contract`：合同或批准项目规则明确后的采用量。

四者可互相校核，不得相互替换。自然密实、夯实后、松散和空方状态也必须分开，未经证实不得换算。

### 2. 核对资料身份和中性事实

原始资料按 [资料提取与来源核对](../_qto-shared-evidence/references/按任务阶段读取.md#原始资料与计算) 选择相应公共资源；未进入提取阶段时不展开其他资料类型。

只能复用实体、坐标、标高、文字、闭合边界、来源身份和逐行守恒等中性事实；不得调用旧 Skill、旧归档或旧项目计算脚本，不得继承旧公式、旧数量或旧通过状态。

### 3. 选择专业分支和规则

- 基坑、基槽、管沟、工作面、放坡和重叠：[基坑基槽与工作面规则](references/基坑基槽与工作面规则.md)
- 原地面、设计面、场地挖填和场地平整：[场地标高与平整规则](references/场地标高与平整规则.md)
- 回填、余方、借方和土方平衡：[回填余方与土方平衡规则](references/回填余方与土方平衡规则.md)
- 清单计量请求：[现行计量标准摘要](references/现行计量标准摘要.md)

再读取 [规则清单与成熟状态](references/规则清单与成熟状态.md) 和公共 [推算分层协议](../_qto-shared-evidence/references/推算假定与发布分层协议.md)，逐条记录“采用 / 试用 / 不适用 / 证据不足”和“候选 / 试运行 / 正式 / 停用”。候选规则可支撑推算/暂估；试运行和候选规则必须明确标识并限制发布。

当前只有“浅基础矩形坑群按明确方案参数做平面并集后积分”有青海真实资料局部试运行。完整场地曲面、道路全断面、深基坑、完整回填和土方平衡仍是候选分支，见 [案例成熟度与建设门槛](references/案例成熟度与建设门槛.md)。

### 4. 建立计算对象并复算

读取 [计算与证据流程](references/计算与证据流程.md)，按以下顺序执行：

1. 建立唯一对象编号和对象身份签名，锁定区域、土方类型、土体状态、计量基准和采用角色；
2. 将原始地面、设计预设地面、批准施工地面、基底或槽底统一到同一高程系统；
3. 基坑、基槽和管沟先锁定底部边界，再分别处理垫层外伸、工作面、支护或放坡；
4. 多个开挖体相交时必须按空间并集计算，不能逐坑体积直接相加；
5. 场地挖填应由现状面与设计面同域比较，分开输出挖方和填方；场地平整面积不能代替挖填体积；
6. 回填按明确回填边界减去占位构筑物；余方和借方只在同范围、同土体状态、同计量基准下平衡；
7. 只对同对象类别、土体状态、计量基准、采用角色和完整性形成小计；
8. 缺少决定性事实时，正式量使用 `deferred` 与 `null`；有依据的边界、标高和施工方案按推算协议另列，注明假定及所需输入。

只有对象、边界、单位、标高、规则和采用角色已由证据明确时，才可使用 `scripts/calculate_earthwork_terrain.py` 做确定性复算。脚本不识别图纸语义、不选择计量规则、不推定放坡或工作面，也不执行土体状态换算。

### 5. 检查并形成成果

读取 [证据引用要求](../_qto-shared-evidence/references/证据引用要求.md)、[通用成果字段与状态](../_qto-shared-evidence/references/通用成果字段与状态.md) 和 [结果检查与输出](references/结果检查与输出.md)。

- 每条结果包含对象、数量种类、数值或 `null`、单位、公式、土体状态、计量基准、采用角色、来源、规则、状态和未决事项。
- `scheme_reference` 只能是 `reference`，不得进入采用小计。
- `standard_boq` 或 `project_contract` 采用量必须引用非候选规则和适用性证据。
- 局部或不完整结果不得表述为整个项目、系统或完整施工范围的总量。小计或合计表示相加，不自动代表范围完整；汇总时将名称与对象、区域、状态及未覆盖内容一起呈现，无需固定限定短语。范围、证据、未决关联和正式采用条件分别核对，名称通过不等于这些条件已满足。
- 零值只有在目标范围已完整检查且确实不存在对象时成立；未知、未提取或范围冲突不得写零。

先运行公共最小成果验证，再用 `scripts/validate_earthwork_result.py --calculator <计算器> --manifest <运行清单> --binding <成果>` 做绑定复算。通过只证明来源绑定、公式复算和已编码不变量成立，不替代设计、施工方案、计量规则或项目专业复核。

## 正式采用停止与局部分支继续

以下条件只阻断受影响结果进入正式量；物理几何、明确方案、替代方案和独立分区继续输出，无法形成有意义候选才使用 `null`：

- 原始地面、设计预设地面、批准施工地面、室内外标高或基底标高冲突；
- 坐标、高程系统、单位、比例、旋转或视图归属未确认；
- 支护、放坡、工作面、超挖、换填、降排水或施工分段会改变边界但未确认；
- 地勘要求继续开挖至持力层，而实际持力层标高未提供；
- 多坑、多槽或分期施工存在重叠，却没有并集或分段边界；
- 现状地形和设计地形不覆盖同一范围，三角网、网格或断面不闭合；
- 回填范围、构筑物占位或土体状态不明；
- 项目适用计量标准、实施时间、地方补充和合同优先级未确认，却要求正式清单量。

## 禁止事项

- 不读取、导入或调用旧 Skill、旧归档、旧项目方法或旧结果作为运行输入。
- 不把设计室外地坪自动当施工前原始地面，不把地勘平台标高跨区域传播。
- 不默认工作面、放坡系数、支护形式、超挖、土体状态换算或松胀系数。
- 不把各坑槽体积直接相加造成重叠重复，不把基槽中心线或轴线长度冒充唯一开挖边界。
- 不把场地平整面积当场地挖填体积，不把回填、余方和借方在不同状态或口径间直接相减。
- 不把方案参考量、标准清单量、合同量和报价数量混成一个“土方总量”。

## HTML图面复核交付

原图算量形成对象明细后，默认按公共[HTML交互复核与批注](../_qto-shared-evidence/references/HTML交互复核与批注.md)生成可离线点选的复核页，支持问题分组、成员例外、结论与原因、保存和处理回执。沿用共享生成器，不在项目重写前端；收到意见后由本专业复算并更新采用状态，用户方法意见不自动等于数值确认。纯问答、无图表内复核及用户指定其他形态按实际范围处理。
