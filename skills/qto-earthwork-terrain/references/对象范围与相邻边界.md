# 对象范围与相邻边界

## 本 Skill 直接负责

- 一般土石方、基坑、基槽、管沟及沟槽开挖；
- 现状地面与设计面之间的场地挖方、填方；
- 基础、构筑物、管道或室外工程完成后的回填；
- 同一口径下的余方弃置、借方和土方平衡；
- 场地平整面积及影响计算的未决标高。

## 相邻专业分工

| 对象 | 本 Skill | 相邻 Skill |
|---|---|---|
| 道路 | 路床以下或明确划入的土方边界 | `qto-roads-siteworks` 计算结构层、面层和附属构造 |
| 管网 | 管沟开挖、回填及余方 | `qto-pipe-networks` 计算管线、管件和附件 |
| 桩与地基处理 | 大面或基坑土方 | `qto-piles-groundwork` 计算桩孔、成孔、褥垫层和处理体 |
| 基础与垫层 | 消费其外轮廓作为底部或占位边界 | `qto-concrete-formwork` 计算混凝土和模板 |
| 支护 | 消费批准支护或放坡边界 | 支护构件本体另行归属，不在本 Skill 计量 |

多专业请求可以分链协作，不得因相邻 Skill 尚未建立就吞并其物理对象。

## 不属于本 Skill

- 土方单价、运距报价、消纳费、弃土场价格和成本；
- 混凝土、钢筋、模板、桩、管道、道路面层等实体工程量；
- 未提供设计或批准方案时的支护结构设计、边坡稳定计算和施工组织设计。
