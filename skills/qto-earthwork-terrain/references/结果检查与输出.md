# 结果检查与输出

## 逐项必查

- 区域、对象、来源 SHA、坐标和高程系统；
- 原地面、设计或施工地面、基底或槽底及深度方向；
- 坑槽底边界、工作面、放坡或支护、超挖和换填；
- 土体状态、计量基准、采用角色和范围完整性；
- 多坑槽并集、回填占位扣减、余方或借方的同口径条件；
- `complete / partial / unresolved / not_applicable` 与覆盖证据一致；
- `adopted / reference` 分开，参考量不进入采用小计。

## 典型异常

- 设计室外标高替代施工前原始地面；
- 旧项目 0.3m 工作面或 1:0.5 放坡被当通用规则；
- 六个相交坑逐个相加，未求并集；
- 基础底标高未含垫层或将结构底与开挖底混淆；
- 天然密实挖方直接减压实回填；
- 场地平整面积被写成挖填体积；
- 局部参考量冒称整个项目或系统已完成，或汇总时未同时呈现范围、状态和未覆盖内容；不因名称单独含“合计”判错；
- 未知值写成 0，方案参考量进入采用小计。

## 成果表达

每条成果必须包含：范围、名称、数值或 `null`、单位、公式或说明、来源、规则、状态、未决事项、计量基准、土体状态、采用角色、计算方法和对象身份签名。

只对同对象类别、数量种类、土体状态、计量基准、采用角色和范围完整性形成小计。不同状态或计量基准即使单位相同，也不得相加成“土方总量”。

## 验证顺序

1. 公共最小成果校验；
2. 本 Skill绑定复算校验；
3. 人工或模型复核图纸、标高、支护放坡方案和计量规则适用性；
4. 明确验证通过仍不代表的内容，例如合同清单适用性、实际施工前地形和未批准方案。

否定结论（“图上无”“未见”“不存在”等）是否都附检索记录，反向核对是否写明覆盖的图纸集合并覆盖所有可能含该类对象的图；没有检索记录的否定结论报待确认，不作为不计或判定清单有误的依据。格式见公共[通用成果字段与状态](../../_qto-shared-evidence/references/通用成果字段与状态.md)“否定结论与检索证据”。
