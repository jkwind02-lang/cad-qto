# 阶形独立基础来源复算

`scripts/calculate_stepped_foundations_reference.py INPUT --output OUTPUT` 重读当前 DXF 和权威 DWG 的哈希，计算模型已识别的嵌套矩形阶形基础及垫层。它是模型工作参考入口，不代表普通混凝土全部构件已实现；无斜面、杯口、孔洞或相邻梁柱净扣功能。

输入 `schema: qto-stepped-foundations-reference/1.0`，含 `source`（DXF 的 path、sha256 和 authoritative_source）、`unit_evidence`、`foundations`。`unit_evidence` 以完整 CADINST 实例路径、实际单位说明 `text_contains` 和 `unit` 绑定；有 INSUNITS 时须一致。单位未设时仍须明确的原图单位说明，不能只填换算系数。

每基础声明唯一 `physical_id`，`tiers` 自下往上列各阶的 `footprint_object_id` 和 `height_note`。轮廓由原图重读，限水平闭合四边矩形，上阶必须在下阶内。每阶高度用 `{object_id, text_contains, pattern, group, unit}` 从实际文字的正则捕获组提取，不接收外部体积或手填轮廓。识图者必须确认文字适用本基础及阶高的顺序，正则匹配通过不替代这个判断。

可选 `blinding` 用同格式的 `offset_note`、`thickness_note` 绑定原图。矩形等距外扩后计算垫层面积和体积。

`face_conditions` 必须覆盖 `tier_sides`、`bottom`、`exposed_horizontal_tops`，以及存在垫层时的 `blinding_sides`。每面给 `state`、`basis` 和 `source_notes`（object_id、text_contains）。`included/excluded/scenario/unresolved` 分别保留工作接触面积、有依据的工作零、施工方案参考和 null。层间内部水平界面不作为外侧模板重复计量。支模方式没有实际证据时，用明确方案或未决；不能因计算器输出正常就当正式模板量。

数量按每一唯一基础、各阶和垫层分列。相同底部源轮廓换物理编号不能重复计算。脚本拒绝覆盖已有输出，结果固定 `REFERENCE_ONLY`、`business_adoption_allowed:false`。尺寸指向、相邻柱梁的归属、材料及正式采用仍须模型回图和专业复核。
