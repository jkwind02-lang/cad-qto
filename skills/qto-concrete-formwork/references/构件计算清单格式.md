# 构件计算清单格式

`scripts/calculate_concrete_formwork_pairs.py` 接受 UTF-8 JSON 清单。它只复算清单已经明确选择的来源、尺寸和接触面，不识别构件类别，不推断图层语义，不决定清单标准。

## 顶层字段

```json
{
  "manifest_version": "qto-concrete-formwork-manifest/1.0",
  "case_id": "稳定案例编号",
  "scope": {"project": "项目", "building": "楼栋", "area": "区域"},
  "source": {
    "dwg_path": "冻结来源绝对路径",
    "dwg_sha256": "64位哈希",
    "entity_stream_path": "原生实体流绝对路径",
    "entity_stream_sha256": "64位哈希",
    "metadata_path": "缓存元数据绝对路径",
    "metadata_sha256": "64位哈希",
    "source_unit": "Millimeters",
    "expected_adapter": "经确认的原生适配器",
    "expected_schema_version": "缓存结构版本",
    "expected_unit_status": "单位状态",
    "expected_unit_basis": "单位确认依据",
    "expected_row_count": 1,
    "expected_entity_count": 1
  },
  "evidence_entities": [],
  "calculation": {},
  "project_rule_gate": {},
  "unresolved": []
}
```

路径必须指向原始/中性证据。清单若引用旧 Skill、旧归档、旧项目计算脚本、旧结果或旧验证文件，脚本拒绝运行。

## 证据实体

每项至少包含 `handle`、`entity_type` 和要核验的事实。支持：

- 尺寸：`expected_measurement_mm` 为实体流预期原始测量，`adopted_mm` 为图面标注采用值，二者差异必须在 `tolerance_mm` 内；
- 文字：`text_contains`，用于厚度、外扩或图名等直接说明；
- 轮廓：`closed`、`candidate_physical_id`、`layer`，用于唯一对象与几何交叉检查。

脚本要求每个 handle 在实体流中唯一，并核对行内 `source_sha256`。尺寸采用标注值时，清单必须说明显示精度或采用依据；不能借容差把任意量图值改成目标值。

## 当前确定性计算类型

首版只支持 `orthogonal_notched_raft_with_blinding`，字段包括：

- 由证据句柄映射的主体长、主体宽、四边外伸、角缺口长宽；
- 筏板厚度、垫层厚度和垫层外扩；
- 轮廓句柄及文字说明句柄；
- `template_conditions` 必须按限定面分别声明：筏板外侧成型方式、筏板底面局部拓扑、筏板顶面是否敞开、垫层侧面是否支模；
- 当前青海试运行只确认筏板顶面敞开，筏板外侧、局部底面和垫层侧面均保持未决，不能改写成“需要普通模板”或全范围真零。

计算式：

```text
L = 主体长 + 左外伸 + 右外伸
W = 主体宽 + 上外伸 + 下外伸
A = L×W - 角缺口长×角缺口宽
P = L + W + (L-缺口长) + 缺口宽 + 缺口长 + (W-缺口宽)
V筏板毛 = A×筏板厚
A垫层 = A + P×外扩 + 4×外扩²
P垫层 = P + 8×外扩
V垫层毛 = A垫层×垫层厚
```

仅当轮廓为无自交正交简单多边形且外扩不改变拓扑时使用垫层外扩公式。

## 未决与规则门

`project_rule_gate` 必须列明地区、招标日期、合同日期、合同标准和地方规则的状态。缺项不阻止独立物理量计算，但清单量结果必须为 `null`。

`unresolved` 每项包含编号、类型、说明、影响、所需输入和当前处理。局部下沉、沟槽、集水井、材料等级冲突和支模条件不能用零值或默认做法消除。

## 输出

脚本生成：

1. 计算证据 JSON：来源身份、对象证据、坐标几何交叉值、标注尺寸法、条件值和未决项；
2. 构件明细 CSV：每一步公式、输入、原始值、单位和状态；
3. `qto-result-minimum/1.0` 试运行成果 JSON：物理毛量、筏板外侧若支模的条件候选几何及正式 `null`、筏板底面正式 `null`、垫层侧模条件候选及正式 `null`、清单口径 `null`。

脚本不会回写项目目录或旧成果；输出路径必须由调用者显式指定。
