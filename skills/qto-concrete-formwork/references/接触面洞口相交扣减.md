# 接触面、洞口、相交与扣减

## 模板接触面判定

对每一构件面依次判断：

1. 该面是否属于本构件外边界；
2. 浇筑时是否敞开；
3. 是否贴土、贴垫层、贴既有混凝土或与同次浇筑构件连续；
4. 是否由普通模板、胎模、地模、永久模板或预制底板承托；
5. 项目清单规则是否计取该种接触面；
6. 是否已经归入另一构件或洞侧补回。

只有“实际需要模板并接触”且未重复归属的表面进入物理模板接触面积。普通模板、永久模板和条件性模板分开输出。

## 洞口的四条独立链

每个洞口分别计算：

- 物理混凝土空腔体积；
- 清单混凝土按适用阈值和规则扣减的体积；
- 模板主面被洞口占用而扣除的面积；
- 洞侧、洞顶、洞底等实际新增接触面积。

`0.3 m²` 若适用，是“单个洞口面积”的规则阈值。小于、等于和大于阈值必须有独立边界测试；不得把多个小洞合计后判断。物理空腔与清单“不扣”可以同时为真，不能互相覆盖。

## 相交和归属

- 构件实体先按空间相交检查，再依据物理浇筑边界和项目清单规则决定归属。
- 模板交接重叠面只允许一个归属或明确不计，不得在柱、墙、梁、板两侧重复。
- 梁—柱、梁—墙、主—次梁、墙—柱、墙—墙、板—梁/墙/柱、楼梯—平台/楼板均需对象级关系。
- 使用平面脚印扣减时，先求墙、柱、梁脚印并集；如果没有布尔并集证据，只能输出毛量或已证实部分。

## 扣减台账字段

| 字段 | 要求 |
|---|---|
| 关系编号 | 唯一，能回链参与构件 |
| 关系类型 | 洞口、空腔、实体相交、接触面重叠、施工分界或材料分界 |
| 几何 | 位置、尺寸、标高、面积/体积及单位 |
| 物理处理 | 扣减、不扣、并入或未决 |
| 清单处理 | 按已确认项目规则填写；适用门未闭合时未决 |
| 模板处理 | 主面扣减、侧面补回、归属或不计 |
| 来源与规则 | 项级可定位引用 |
| 防重复键 | 参与对象和接触面的稳定组合 |

## 真零与条件量

- `0` 只能用于覆盖范围完整、逐面复核且证据证明没有工程量的结果。例如“筏板底面位于垫层上，不形成普通底模”可以在仅限底面的范围内形成真零。
- 原槽浇筑、垫层侧模、砖胎模、永久模板等条件未确认时，正式结果为 `null`。可另存“若条件成立”的候选计算值，但不能进入采用汇总。
- 无洞口资料、未发现洞口或尚未检查洞口都不是零洞口。
