# 柱墙规则

## 柱

- 物理体积按截面沿高度的实体积分；等截面柱可用 `截面面积×高度`，变截面、柱帽和牛腿分别建模后按归属合并。
- 柱与基础、梁、板、墙的分界必须依据项目采用规则和浇筑实体关系分别保存。不得只用楼层高度而忽略板厚，也不得在柱、梁、板三处重复计交叉体积。
- 模板从柱各侧实际接触面扣除与梁、墙、板等构件重叠且不需要模板的面；柱帽、牛腿和异形侧面单列。
- 劲性骨架的物理占积和清单扣减需要钢结构 Skill 提供唯一构件事实；普通钢筋、螺栓和预埋件不由本 Skill 计算。

## 墙

- 等厚直墙物理体积可按净平面长度×厚度×高度；转角、交叉、变厚和曲墙应先形成墙段并集，避免墙墙交叉重复。
- 门窗、设备洞、套管洞、沟槽和后浇区分别建对象。物理体积扣真实空腔；清单体积再按已确认阈值和归属规则处理。
- 两侧模板不能机械取 `2×墙长×墙高`。应扣墙柱、墙梁、墙板交界和无需模板面，并按规则补洞侧、洞顶、洞底或端面。
- 扶壁柱、壁柱及突出墙面部分要有唯一归属；若并入墙，柱 Skill 不得重复输出。

## 交界最低记录

墙—柱、墙—梁、墙—板、墙—墙转角至少记录参与构件、相交面、物理体积归属、模板面归属、清单分类和防重复键。缺少任一会改变数量的关系时，受影响净量停止。
