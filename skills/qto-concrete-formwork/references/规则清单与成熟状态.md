# 规则清单与成熟状态

## 状态约定

- 本次判定：`采用 / 不适用 / 证据不足`，只描述当前任务。
- 成熟状态：`候选 / 试运行 / 正式 / 停用`，描述规则证据成熟度。
- 候选规则可标为本次“试用”并支撑规则推算或方案暂估；有当前项目直接权威依据或已确认裁决并记录项目采用依据时，才可在本项目标为“采用”。经过真实或等效案例验证的规则可以标为试运行，但整个 Skill 仍是候选，不等于通用正式成熟。
- 当前没有正式规则。规则来源变化、适用范围扩大或真实案例暴露错误时，立即回退为候选。

## R-CF-001 任务范围与来源身份门

- **Skill / 对象分支**：`qto-concrete-formwork` / 通用 / 全部构件。
- **来源**：重构任务书第 2.3、5.2、12、13.2 节；公共《图纸与资料范围筛选》《缓存身份与复用条件》。
- **适用 / 不适用**：适用于所有任务；不替代专业几何和计量规则。
- **前置条件**：任务范围、来源文件、修订、单位和缓存身份能够逐项核验。
- **输入、公式、单位、精度**：文件字节与 SHA-256；实体流行内来源哈希；无工程量公式。
- **扣减 / 不扣 / 并入 / 分列**：不处理数量；任何身份冲突使受影响对象停止。
- **相邻边界**：只锁定混凝土与模板资料，不把钢筋、钢结构、砌体、土方或价格资料静默纳入。
- **不确定性**：路径一致但哈希不一致时排除漂移文件；找不到身份闭合来源时 `INPUT_REQUIRED`。
- **输出与证据**：资料选择表、来源哈希、缓存哈希、单位、选择/排除原因、对象定位。
- **测试**：冻结 DWG 与原生实体流哈希通过；同路径漂移 DWG 必须拒绝；错误实体流哈希必须拒绝。
- **成熟状态**：试运行。青海消防泵房冻结 DWG 案例通过；尚未覆盖 PDF-only 和跨视口案例。

## R-CF-002 同一构件几何与四种口径

- **Skill / 对象分支**：通用 / 全部现浇及后浇构件。
- **来源**：重构任务书第 4.1、13.2 节；欧氏实体与表面几何定义。
- **适用 / 不适用**：适用于同一浇筑构件的混凝土与模板；不适用于完成品预制构件本体。
- **前置条件**：唯一构件编号、边界、尺寸、标高和单位已确认。
- **输入、公式、单位、精度**：一次几何生成 `m³` 体积和 `m²` 候选表面；对象级保留原精度，汇总后展示。
- **扣减 / 不扣 / 并入 / 分列**：物理混凝土、清单混凝土、物理模板、清单模板四条链分列；不互相替换。
- **相邻边界**：钢筋或钢构件只提供占积/接触事实，不在本规则计算其数量。
- **不确定性**：任一决定性尺寸缺失时受影响链为 `null`；另一独立链可继续。
- **输出与证据**：稳定几何签名、尺寸来源、四口径结果及各自状态。
- **测试**：同一筏板轮廓同时生成毛体积和外侧若支模候选面；修改几何签名必须同时使两条链失效，候选面不得成为采用量。
- **成熟状态**：试运行。真实筏板案例及等效矩形构件测试通过。

## R-CF-003 物理混凝土实体量

- **Skill / 对象分支**：通用 / 基础、柱、墙、梁、板、楼梯及异形构件。
- **来源**：实体体积定义；本 Skill《计算与证据流程》。
- **适用 / 不适用**：适用于图示实体、空腔和相交闭合的物理量；不直接代表清单量。
- **前置条件**：闭合实体或可证明等价的截面/长度组合，单位和材料边界明确。
- **输入、公式、单位、精度**：`V净 = V并集毛量 - V真实空腔 - V非本构件相交 + V明确并入`，单位 `m³`；先累计后舍入。
- **扣减 / 不扣 / 并入 / 分列**：真实空腔扣除；交界仅一个归属；不同材料和浇筑段分列。
- **相邻边界**：桩、钢构件、砌体和预制完成品实体由相邻 Skill 提供事实，不重复输出。
- **不确定性**：局部下沉、沟槽、集水井或交界未闭合时，只输出明确命名的毛量/已证实部分。
- **输出与证据**：毛量、逐项扣减、逐项补回、净量或 `null`，对象级公式和定位。
- **测试**：普通棱柱、墙洞空腔、相交并集、下沉缺资料四类。
- **成熟状态**：试运行。毛量和停止条件已过案例；复杂净实体仍为候选覆盖。

## R-CF-004 模板实际接触面

- **Skill / 对象分支**：通用 / 全部需要模板判面的构件。
- **来源**：实际接触面几何定义；本 Skill《接触面、洞口、相交与扣减》；GB/T 50854-2024 E.5.1 只作现行清单候选交叉参考。
- **适用 / 不适用**：适用于普通模板和明确的永久模板接触面；不适用于敞开面、贴垫层/贴土且无模板面、同次浇筑连续面。
- **前置条件**：每一候选面的几何、相邻对象、浇筑顺序及模板类型已确认。

- **扣减 / 不扣 / 并入 / 分列**：交接重叠不重复；普通、永久、条件性模板分列。
- **相邻边界**：压型钢板、钢管或预制底板本体归相邻 Skill；这里只记录其是否构成承托/接触关系。
- **不确定性**：支模条件或浇筑顺序缺失时为 `null`，不得按体积系数估算。
- **输出与证据**：面级台账、接触对象、扣减和补回、模板类型、状态。
- **测试**：等效已确认接触面；青海筏板外侧、局部底面和垫层侧面三个缺条件反例；梁底模缺资料。

- **前置条件**：参与构件、空间范围、浇筑边界和项目分类规则可定位。

- **不确定性**：标高、先后浇筑或分类未闭合时净量停止，毛量可分列。
- **输出与证据**：相交台账、归属、扣减/并入、规则、参与对象和防重复键。
- **测试**：墙柱、主次梁、梁板、板的墙柱梁脚印并集；缺标高冲突。
- **成熟状态**：候选。等效反例通过，尚缺对象级真实项目全链。

## R-CF-ZERO-001 零模板量证明

- **Skill / 对象分支**：通用 / 任一限定构件面。
- **来源**：公共《通用成果字段与状态》零值不变量；实际接触面定义。
- **适用 / 不适用**：只适用于覆盖范围完整且逐面证明没有模板的限定面；未知、未检查或条件未定不适用。
- **前置条件**：面范围、接触对象、施工关系、来源和规则完整。
- **输入、公式、单位、精度**：确认接触面积为 `0 m²`；不使用缺失值替代。
- **扣减 / 不扣 / 并入 / 分列**：只对限定面给零，不扩展为整个构件模板零。
- **相邻边界**：永久模板存在时普通模板可为零，但永久模板量必须分列而不能消失。
- **不确定性**：任一面条件未知则返回 `null`。
- **输出与证据**：结构化零值复核：范围覆盖、来源、规则、结论和说明。
- **测试**：等效完整范围的筏板底面贴垫层真零；青海局部底面未闭合及垫层侧面条件未知均不得为零。
- **成熟状态**：候选。等效完整覆盖案例通过；青海筏板局部底面拓扑未闭合，已撤销真零并回退为 `null`。
