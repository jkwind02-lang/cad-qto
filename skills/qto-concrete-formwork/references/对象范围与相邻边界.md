# 对象范围与相邻边界

## 本 Skill 的唯一职责

以“一个可定位的混凝土浇筑实体”为基本对象，维护一套构件几何、空腔、洞口和相交关系；从这套事实分别形成：

1. 物理混凝土体积；
2. 项目适用规则下的清单混凝土体积；
3. 实际模板或永久模板接触面积；
4. 项目适用规则下的清单模板面积。

同一构件不得为混凝土和模板分别抄录尺寸。模板不是混凝土体积的比例派生项，而是表面与施工接触条件的派生项。

## 纳入对象

- 现浇垫层、独立基础、条形基础、筏板、承台和基础联系梁；
- 现浇柱、墙、梁、板、栏板、挑檐、雨篷、楼梯、后浇带及其他异形浇筑实体；
- 装配式构件的后浇层、后浇节点、接缝后浇区及其模板；
- 普通模板、胎模、地模和永久模板的接触面事实；其中是否形成清单量必须依据项目规则；
- 洞口、空腔、下沉、交界、施工缝及构件归属所形成的扣减和补回关系。

## 相邻 Skill 的唯一出口

| 对象 | 归属 | 本 Skill 可保留的关系 |
|---|---|---|
| 钢筋、锚固、搭接、节点和钢筋重量 | `qto-rebar` | 只记录混凝土计量中通常不扣钢筋体积；不计算钢筋 |
| 型钢骨架、钢管、钢梁柱、压型钢板及节点 | `qto-structural-steel` | 需要时接收已确认的型钢占积或永久钢构件接触事实 |
| 桩体、桩长、成孔、灌注和护筒 | `qto-piles-groundwork` | 承台、筏板、基础联系梁仍归本 Skill；桩头是否扣除按适用规则处理 |
| 基坑、基槽、工作面、回填和余方 | `qto-earthwork-terrain` | 可提供已确认的基础外轮廓，但不顺带形成土方量 |
| 砌体墙及二次结构整体成果 | `qto-masonry-secondary` | 明确只算二次构件混凝土/模板时，复用墙系定位和马牙槎事实，仅本 Skill 输出数值 |
| 抹灰、防水、保温、涂料和饰面 | `qto-surfaces-envelope` | 可提供混凝土表面几何，不输出面层量 |
| 完成品预制构件编号、数量和安装 | `qto-components-points` | 只处理预制构件中的现场后浇区；完成品本体不生成现场模板 |
| 管网、道路和场坪 | 对应管网或道路场地 Skill | 混凝土管、混凝土路面不能只按材质词触发本 Skill |
| 单价、报价、成本和供应责任 | 不属于算量 Skill | 只交付可追溯物理量或清单量，不给价格 |

## 混合请求的处理

- “柱梁板混凝土、模板和钢筋”：本 Skill 处理混凝土与模板，钢筋拆给 `qto-rebar`；两边共用构件身份，不共用数值状态。
- “砌块墙和构造柱圈梁”：墙系及二次构件定位由砌体 Skill 负责；只有用户明确要求时，本 Skill 计算这些已定位构件的混凝土与模板，禁止两处重复汇总。
- “钢管混凝土柱”：钢管质量归钢结构；管内混凝土归本 Skill；钢管是否兼作模板必须有项目事实，无证据时模板为未决。
- “整栋主体结构”：全专业协调 Skill 尚未建立时，只承诺本 Skill 可独立完成的部分，并列出其他能力缺口。

## 不触发的语义反例

- 只算梁柱钢筋、钢梁钢柱、基础土方、墙面抹灰、预制构件数量或混凝土单价；
- “混凝土管道”“混凝土路面”“预制混凝土块”且主要对象分别是管网、道路场地或完成品；
- 只问施工方法、质量验收或配合比而没有工程量任务。

对象归属仍冲突时，先输出对象—Skill—数值出口表；不得让两个 Skill 各自形成一套数量。
