# 混凝土与模板算量

先按用户目标定阶段：范围/能力问答只读相关边界与能力披露；用户仅要求已有明细复核时做表内复核；原始资料算量执行下文。用户要求检验或改进独立算量能力、底稿仅作参照时，执行[原图独立算量实测](../_qto-shared-evidence/references/原图独立算量实测.md)，不得因已有底稿或历史结果改成表内复核。表内复核不核准原图，细则按需见 [分阶段读取](../_qto-shared-evidence/references/按任务阶段读取.md)。

原图算量先读取并执行 [人工思路识图与算量流程](../_qto-shared-evidence/references/人工思路识图与算量流程.md)。模型运用图文理解与工程知识，自主选择取证、判断和计算方法，生成有依据的专业输入及可复核工作量；原生工具负责精确取证和计算。人工方法是可按问题选用的策略，执行顺序可调整；普通识图不等待用户逐对象核定，正式采用另列。

先读结构说明、平面编号和剖面/节点，按基础—柱墙—梁板等实际构件关系建立同一几何；再算实体、相交扣减及实际模板接触面，最后回图查漏重。

以唯一构件几何为共同事实源，分别形成混凝土量和模板接触面积。清晰的单一混凝土或模板任务直接执行，不等待全专业协调 Skill。

## 先判定对象边界

直接读取 [对象范围与相邻边界](references/对象范围与相邻边界.md)。

- 纳入现浇混凝土、装配式构件的后浇混凝土和这些浇筑实体对应的普通模板或永久模板接触面。
- 完成品预制构件实例、数量和安装交给 `qto-components-points`；钢筋交给 `qto-rebar`；钢构件交给 `qto-structural-steel`。
- 砌体墙系及构造柱、圈梁、过梁的定位和二次结构整体成果交给 `qto-masonry-secondary`。用户明确只算这些二次构件的混凝土与模板时，本 Skill 可复用已确认的墙系事实计算，但只能有一个数值出口。
- “混凝土管、混凝土路面、预制混凝土块”不能因出现“混凝土”一词直接纳入；先按主要物理对象交给管网、道路场地或完成品构件能力。
- 混合任务只处理能独立划出的混凝土与模板部分，列明其余能力边界；不得把不同单位或不同计量口径合成一个数值。

## 执行顺序

### 1. 锁定范围和计量口径

读取 [图纸与资料范围筛选](../_qto-shared-evidence/references/图纸与资料范围筛选.md)，至少锁定楼栋、楼层或区域、构件类别、图纸版本、浇筑范围和输出维度。

先区分四种成果：物理混凝土量、清单混凝土量、物理模板接触面、清单模板量。它们可以共享几何，但不得相互替换。规则来源先按公共 [现行规则来源选择门](../_qto-shared-evidence/references/现行规则来源选择门.md) 判断；需要清单量时，再读取 [现行计量标准摘要](references/现行计量标准摘要.md)，核对项目地区、资金性质、招标日期、合同日期、合同约定标准和地方补充规则。适用门未闭合时，物理量可独立计算，清单量保持待确认。

### 2. 选择资料并核对缓存身份

原始资料按 [资料提取与来源核对](../_qto-shared-evidence/references/按任务阶段读取.md#原始资料与计算) 选择相应公共资源；未进入提取阶段时不展开其他资料类型。

公共文件缺失、不可读或版本不明时，停止受影响部分。缓存只提供中性图元、文字和表格事实；不得继承旧专业标签、旧公式、旧数量、旧验证结论或旧规则状态。来源路径和缓存记录冲突时以可验证的文件身份为准，并明确排除漂移文件。

### 3. 读取直接规则分支

按当前对象读取一个或多个文件，不建立第二层路由：

- 基础、承台、筏板和垫层：[基础与垫层规则](references/基础与垫层规则.md)
- 柱、墙及墙柱关系：[柱墙规则](references/柱墙规则.md)
- 梁、板及梁板关系：[梁板规则](references/梁板规则.md)
- 楼梯、后浇带和异形构件：[楼梯与异形构件规则](references/楼梯与异形构件规则.md)

凡涉及模板、洞口或构件交界，同时读取 [接触面、洞口、相交与扣减](references/接触面洞口相交扣减.md)。再读取 [规则清单与成熟状态](references/规则清单与成熟状态.md) 和公共 [推算分层协议](../_qto-shared-evidence/references/推算假定与发布分层协议.md)，按本次对象核对相关规则及状态；候选、试运行和正式采用保持分层，历史提升依据仅在追溯时展开。

### 4. 建立唯一构件模型并计算

读取 [计算与证据流程](references/计算与证据流程.md)，按以下顺序执行：

1. 建立唯一构件编号、空间范围、标高范围和来源定位；
2. 以图示尺寸、截面、轮廓和厚度形成一次几何，不为混凝土与模板各建一套尺寸；
3. 建立实体并集、空腔、洞口、相交和归属清单；
4. 计算物理混凝土毛量、扣减、补回和已证实净量；
5. 按浇筑顺序及接触对象识别真实模板接触面；
6. 需要清单量时，再应用已确认适用的构件分类、不扣除和洞口规则；
7. 保留对象级公式、来源、扣减关系和未决事项。

只有对象、尺寸、单位、接触面条件和来源身份已经由项目证据明确时，才可使用 `scripts/calculate_concrete_formwork_pairs.py` 做受支持几何类型的确定性复算；当前源实体接口限于毫米制单角缺口筏板及等距垫层，面条件逐面输入。其他构件继续按模型识别的几何使用相应量测工具，不套用案例结构。输入格式见 [构件计算清单格式](references/构件计算清单格式.md)。脚本只执行清单中已确认的几何和条件，不识别构件类别、不猜施工顺序，也不补洞口或标高。

### 5. 检查并形成成果

读取 [证据引用要求](../_qto-shared-evidence/references/证据引用要求.md)、[通用成果字段与状态](../_qto-shared-evidence/references/通用成果字段与状态.md) 和 [结果检查与输出](references/结果检查与输出.md)。

- 每条结果必须有构件范围、物理/清单口径、数值或空值、单位、公式、来源、规则、状态和未决事项。
- 混凝土以 `m³`、模板以 `m²` 分列；不得相加为“综合工程量”。
- 对象级先保留原精度，汇总展示精度另行说明；不得逐构件先行四舍五入。
- 洞口、下沉、施工缝、原槽浇筑、永久模板或交界归属缺少直接事实时，先按可定位几何和明确施工方案形成规则推算或多方案暂估；无法形成有意义候选才用 `null`，不得补零或隐藏经验系数。
- 真正零模板量必须逐面证明“不需或没有模板接触”，并形成结构化零值复核。
- 使用试运行规则的成果必须标识为试运行结果。

先运行公共最小成果验证，再运行 `scripts/validate_concrete_formwork_result.py` 检查同一几何、单位分列、洞口/交界关系、条件量和零值证据。验证通过只证明结构和已编码不变量，不替代专业复核。

## 正式采用停止与局部分支继续

以下条件只阻断受影响结果进入正式量；安全独立部分继续，受影响部分仍输出原始几何、规则推算或方案暂估，只有走完推算阶梯仍无法形成候选时才使用 `null`：

出现以下任一情况时执行上述分层处理：

- 来源版本、图纸范围或计量依据冲突且无法裁决；
- 单位、比例、视口变换、标高基准或缓存身份未确认；
- 构件截面、厚度、高度或边界只能靠量图、最近文字或经验猜测；
- 洞口、空腔、下沉、后浇区或构件相交会改变数量但拓扑未闭合；
- 浇筑顺序、贴土、垫层、地模、胎模、永久模板或施工缝事实缺失，导致模板接触面不能判定；
- 二次结构、预制完成品、钢管混凝土等跨 Skill 对象没有唯一数值出口；
- 项目适用计量标准和合同优先级未确认，却要求清单工程量；
- 当前真实案例暴露会改变数量的规则错误。

## 禁止事项

- 不读取、导入或调用旧 Skill、旧归档、旧规则目录、旧项目计算脚本或旧结果作为运行输入。
- 不用混凝土体积乘经验系数估算模板面积。
- 不把清单“不扣除”规则写成物理实体没有孔洞、钢筋或预埋件。
- 不把旧测试通过、旧结果吻合或旧状态继承为新规则成熟度。
- 不建立统一规则引擎、跨专业状态机、报价或成本模块。

## HTML图面复核交付

原图算量形成对象明细后，默认按公共[HTML交互复核与批注](../_qto-shared-evidence/references/HTML交互复核与批注.md)生成可离线点选的复核页，支持问题分组、成员例外、结论与原因、保存和处理回执。沿用共享生成器，不在项目重写前端；收到意见后由本专业复算并更新采用状态，用户方法意见不自动等于数值确认。纯问答、无图表内复核及用户指定其他形态按实际范围处理。

## 长任务持续执行

需要跨会话接续、并行合并或复杂修改依赖时，按共享[项目作业台账与持续执行](../_qto-shared-evidence/references/项目作业台账与持续执行.md)建立或恢复本任务；普通局部算量可直接调用专业工具。本专业继续主责识图、规则解释和计算，按[各专业持续算量执行路径](../_qto-shared-evidence/references/各专业持续算量执行路径.md)选择合适切入点、处理同族及例外。采用执行器时由模型调整任务并用 `next` 接续；任务文件不代替自主识图和真实计算。

物理对象与应计量项分开登记，结果引用本次原生文件及对象身份；复核视图从同一结果索引绑定。当前任务的有效检查点可恢复，图纸、规则或输入变化则沿依赖重算；独立复测使用新任务身份并隔离旧结果。程序完成不替代专业复核及正式采用。
