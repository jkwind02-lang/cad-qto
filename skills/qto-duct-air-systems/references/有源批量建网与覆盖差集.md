# 有源批量建网、完整曲线与覆盖差集（T28）

本入口消费当前中性取证与模型已形成的冻结识别配置，实际调用既有 `infer_duct_fittings_vertical.py`。配置是可复核工作判断，不是人工批准。原图、交换副本、流文件、识别证据、实例路径、完整几何和变换共同保留；不内置项目图层、句柄、系统名称或答案。

```text
python skills/qto-duct-air-systems/scripts/build_duct_network_from_neutral.py --cad-manifest CAD中性取证清单.json --profile 风管识别配置.json --output-dir 新的风管建网输出
```

输出 `风管实际消费输入.json`、`风管实际消费结果.json`、`风管图层覆盖差集.json` 和含真实退出码的 `实际风管消费日志.json`。消费失败仍保留输入、差集和日志，不能报成功。输出采用新目录/空目录，拒绝现存文件、硬链接和 symlink/reparse 别名；实际消费者仍保留旧输出合法覆盖，但不能覆盖其输入或任何冻结来源/证据的直接、硬链接或目录别名。数量仍是工作层级，未执行人工复核或正式采用。

## 配置与识别依据

配置版本为 `qto-duct-network-profile/1.0`，必填 `expected_source_sha256/layout/space_id/floor_id/package_id/target_layer_pattern/parameters/rules`。`parameters.parameter_basis` 必须说明当前容差与长度口径；`crop=[minX,minY,maxX,maxY]` 可选，单位为源WCS绘图单位。

每条规则包含 `rule_id/selector/representation/system/section/evidence`。`selector` 支持 `layer_pattern`、`entity_types` 和完整实例 `source_keys`，多个条件取交集。`representation` 为 `centerline/single_line/outline/riser_projection/exclude`。截面显式声明 `shape=rectangle,width,height,unit` 或 `shape=circle,diameter,unit`；缺规格的有据中心线可以进入未核规格候选，不补面积。`exclude` 可用于非线对象，须给出有据排除原因。

`evidence={path,sha256}` 指向冻结JSON，版本 `qto-duct-recognition-evidence/1.0`。其中 `source_sha256/layout/space_id/crop/rule_id/selector/representation/system/section` 必须与当前配置逐字段相同，并有 `basis/source_locator`。这是模型依据源资料形成的工作识别记录；不能以非空标题或邻近文字取代具体范围和结论。实际consumer重建同一输入，来源、几何、识别系统或尺寸被改写均拒绝。

顶层实例路径为 `CAD-源实体ID`；块内路径为 `CAD-插入ID/块名/CAD-定义实体ID`，嵌套逐级展开，单个part键为 `完整路径#part_index`。块的0图层继承实际插入图层，变换保留完整仿射矩阵。缺块、递归/深度限制、未恢复曲线和无位置的非线对象均保留未识别行，不静默丢弃。

IDEN/引注使用规则 `annotation_binding={source_key,expected_text,dimension_unit}`。可另声明 `elevation_regex`（唯一命名组 `value`）、`elevation_unit/elevation_reference`。证据须含 `annotation_relationships=[{tag_source_key,selector,basis,source_locator}]`，明确这条引注适用于哪一源实例范围。尺寸支持 `宽x高/宽×高/Φ直径/D直径`，标高基准明确为 `bottom/top/center`。不按全图最近标签、同图层类别或一个尺寸数字直接定案。

## 几何、连接与数量层级

- 直线及多段线逐part进入网络，保留完整WCS的非零Z；同XY不同源平面或空间不自动互接；ARC、bulge、完整椭圆弧保留实际曲线，采用圆弧解析长度或完整仿射曲线积分，包含测长误差估计。非水平直线也单列完整几何，不能丢Z后按平面计长。
- 标准完整曲线使用真实WCS端点和有向切向与同系统、同空间、同楼层的唯一端点衔接，形成 `source_curve_network` 的边、端点和连接候选；截面或切向不连续、多候选、跨空间及开放端保持未决。曲线端接位置不再被旧直线断口/旁接启发式重复补量。几何边长度始终取原曲线，绝不用弦长代替。
- 双线直轮廓要求同面、平行且间距符合显式截面；完整对应端或唯一局部重叠区间可计算；圆风管使用直径。`pair_tolerance` 显式给出且小于宽度/直径四分之一，正反向唯一配对后取中线。局部重叠将原part按0～1参数分区，计入重叠区间与未识别余段分别有完整几何与稳定子键，父part只作分区索引，不把整段全部报已计。完整同心、同扫角、同方向圆弧轮廓可合成中径弧。推导中线长度为规则推算，不升为源直线确认量。
- 一条边对应多条重叠/错缝轮廓的歧义分区、非等比变换后椭圆轮廓的真实等距中线恢复、复杂三通/变径与外皮扣减属于仍未支持的通用子项；源几何全部保留待办。不能把这些余项写成项目特例或宣称天正弧形建网整包完成。
- 等截面完整曲线的周长×中心线长度只形成理论外表面积工作候选，不能替代异形/变径/加工展开、阀件扣减及清单口径。管件、法兰、加固、损耗和竖向完整性继续分别核对。
- 竖井圆弧可进入 `riser_projection_candidates`，其 `height/length=null`；平面投影不是已知竖长，不从图形周长或默认层高取数。
- 源INSUNITS为 Unknown/Unitless 时只输出 `raw_DU` 几何关系，主长度、面积与依赖合计为null。显式米制标高/高度、截面毫米均不能倒推平面毫米。物理单位未核时外轮廓间距也不能用于恢复尺寸中线。

## 方法无关覆盖差集

差集以目标图层的全部展开源实例与完整part为全集。逐条只有 `counted/excluded/unrecognized` 去向；非线对象、块容器、块展开失败和未恢复曲线均有行。图框裁剪用完整曲线范围，跨边界对象留待判，不用端点或弦截断。汇总按当前 `layout/space_id/crop` 与图层、去向列出。

外部建网方法可另传 `--claims 覆盖声明.json`，版本 `qto-duct-coverage-claims/1.0`、同一原图SHA。每条声明精确绑定 `source_key/geometry_sha256/disposition/evidence`；证据JSON须逐项匹配原图SHA、实例part、完整几何、layout、space及去向，并有依据和定位。已计还须 `quantity_ref={path,sha256}/collection/index`，实际数量行保留同一唯一 `source_ids` part键、非bool且有限正数的length，声明明确计量单位、维度和口径；分区父part只能作索引，外部计量须绑定实际子区间。排除须有据。

外部数量行与claim须一致声明 `quantity_dimension=length`、`quantity_kind=duct_centerline_length`、物理长度 `unit` 和 `length_basis=gross_centerline|net_centerline`。实际行还须 `measurement_status=measured|calculated`、`currentness_status=current`。待核、未测、失效、文本/布尔/NaN/无穷、零或负长度均不能认已计；缺明确状态或计量依据也不接受。零量不计或扣减若需处理，另作有据排除或净量依据，不能直接把零/负数行当成已计中心线。

每条已计claim还须 `measurement_evidence={path,sha256}`，指向 `qto-duct-external-length-measurement/1.0` 冻结计量记录。记录绑定当前原图SHA、source_key、geometry_sha256、layout、space_id、`source_coverage=full_source_part`、上述维度/单位/口径/状态，给出 `basis/source_locator`、引用当前权威原图的 `source_evidence={path,sha256}`，并用 `quantity_row={path,sha256,collection,index,row_sha256}` 精确绑定实际数量行。`row_sha256` 使用当前完整行的UTF-8 JSON（ensure_ascii=false、sort_keys=true、separators为逗号和冒号、拒绝非有限数）计算SHA256。

计量记录的 `gross_length` 按已核源单位与完整源中心线几何核对；`attributed_length` 是该源part对实际数量行的正贡献。毛长口径的deductions必须为空；净长按 `gross_length－逐项有据扣减=attributed_length`，所以净量不必等于CAD毛长度。`deductions` 数组引用 `qto-duct-length-deduction/1.0` 冻结记录，每项带唯一deduction_id、本原图/part/几何/layout/空间、有限正length及明确unit、basis/source_locator和可核SHA的原始 `basis_source`；重复记录、重复条款位置、缺扣减依据或不守恒均拒绝。`rounding_tolerance` 可省略为0，不能超过本源part毛中心线长度的万分之一（不能借大聚合行放宽）。

聚合实际行可列多个source_ids；各已声明part贡献之和不得大于该行，全部source_ids均已声明时须与该行守恒。只核对本次逐part覆盖，不藉此证明未声明来源或完整净量。源单位未知时只可用 `unit=raw_DU`、`quantity_dimension=drawing_length`、`quantity_kind=duct_centerline_drawing_length` 作原图单位计量，扣减也只能raw_DU；外部m/mm单位不证明原图物理比例，主物理长度/面积仍为null。实例缺失、重复或曲线不符均拒绝，半宽缓冲、计入框和最近距离不会自动抹去未计对象。

`dispositions_closed` 只说明这份范围内去向已填；`quantity_complete` 始终为false。候选系统/规格、未核高度、管件扣减及图层外遗漏不因差集闭合而闭合。

## 在线附件真实数量接收（T20）

点位位置与风管宿主候选沿用点位T20已有契约；本入口新增风管实际数量消费者：

```text
python skills/qto-duct-air-systems/scripts/receive_duct_inline_components.py --attachment-report 首轮点位输出/点位位置与管段挂接.json --network-input 实际风管输入.json --output-dir 新的风管附件接收输出
```

实际输入必须为风管schema并包含源范围绑定、真实 `segments` 与 `valves`。在线附件必须有原物理ID、源实体/完整实例路径、独立离散单位、请求指纹、源几何位置和唯一 `connected_segment_ids`。连接证据沿用 `qto-inline-connection-evidence/1.0`，不能从bbox最近邻自动生成。附件类别沿用原点位有据category；若实际输入细分为其他类别，另给 `component_classification_evidence={path,sha256}`，其JSON版本 `qto-inline-component-classification/1.0` 须绑定同一原图、physical_id、source_instance_path、source_record_id、component_type、layout及space，并有basis/source_locator。实际风管consumer从有据宿主取得系统和完整截面，输出逐附件数量与分组守恒，再生成 `风管在线附件数量接收.json`；不是只写交接文件。

接收保存实际输入/结果/请求/生产者及关键依赖SHA、原始行定位和明确接收范围。将receipt路径/SHA放入另存新profile的 `point_host_attachment.receptions` 后，points按固定专业dispatcher重新运行真实风管CLI并核对结果。非支持owner、独立设备混入、来源变化、非离散单位、连接冲突、遗漏/重复接收、篡改结果、生产者依赖变化均不得闭合。相同版本可幂等重放；原点和外形位置继续分列。旧pipe路径和未启用T20的旧profile继续原有行为。

T20还支持由当前冻结生成器可重放得到的合成中线与完整曲线宿主：在 `qto-point-host-segments/1.0` 顶层声明 `generated_duct_input={path,sha256}`，`segments` 只列 `{segment_id}`。points重读相同原图/识别配置/生成器重建几何及系统规格，禁止手改几何或分类；完整曲线按真实三维最近点投影，不用弦，不从同XY不同Z对象中近邻定案。当前分支要求点位保留相同源坐标单位、factor=1；其他坐标单位配准未支持。显式物理连接证据仍必需，外形中心靠近曲线不证明真实端口；原始直线宿主及pipe路径继续原规则。
