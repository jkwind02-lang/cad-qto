# 范围与对象边界

最小对象为一段同系统、同材质、同形状和同截面的风管中心线段或一个明确管件/附件实例。

| 对象 | 唯一出口 |
|---|---|
| 直风管、弯头、三通/四通、变径、导流片、软接 | 本 Skill |
| 在线风阀、防火阀、排烟阀、止回阀、法兰/连接、加固 | 本 Skill；成套设备内部项需明确 |
| 风管专用支吊架、风管保温/外保护层 | 本 Skill |
| 风口、风机、空调箱、风机盘管等独立设备/末端 | `qto-components-points` |
| 冷冻水、冷却水、冷媒、冷凝水管 | `qto-pipe-networks` |
| 风管穿墙洞口和建筑面层扣减 | 对应土建/围护 Skill，只消费风管接口事实 |

风阀若作为风管在线附件由本 Skill 唯一计数；独立末端设备由点位 Skill。综合支吊架须按批准方案确定唯一出口。
