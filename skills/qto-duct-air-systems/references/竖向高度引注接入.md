# 源引线与明确竖向高度

`bind_duct_vertical_annotations.py` 将当前中性取证中的完整引线和明确上接/下接高度接入 `infer_duct_fittings_vertical.py`。输入仍为现有 `qto-duct-fitting-vertical-input/1.0`；新增可选 `vertical_annotation_input`。未提供该字段时原有行为、结果字段和门控不变。本能力是 T48 的竖向高度分支，不表示其他风管消费者、点位或工程量覆盖项已完成。

高度解释为长度，例如“风管下接高度2.3m”，长度为2.3m。该值不写入任何绝对标高；不需要伪造上下两个管段或标高。明确高度与绑定是否成立分别保存：原图平面单位未知时，2.3m高度事实保留；若引线、目标源管段与输入均在同一原图原坐标，来源和唯一指向已闭合，仍生成2.3m规则竖向段，不需要先把XY坐标换成米。依赖平面单位的截面周长及该竖段面积保留null，完整成果状态不写完整。标高文字、范围、约数、示意、暂定、多数值或缺单位不形成采用候选；不按引线长度、默认距离或符号外框补高度。当前解析限定为上接/下接高度加单个正值及m/cm/mm或米/厘米/毫米；起终绝对标高仍走原有带依据的标高差链。

## 输入与运行

先冻结既有风管输入，再编制绑定配置：

```json
{
  "schema_version": "qto-duct-vertical-annotation-binding/1.0",
  "duct_input": {"path": "<风管输入绝对路径>", "sha256": "<文件SHA256>"},
  "neutral_manifest": {"path": "<中性清单绝对路径>", "sha256": "<文件SHA256>"},
  "layout": "Model",
  "expand_blocks": [],
  "leader_layer_pattern": "^DIM_LEAD$",
  "text_attachment_policy": "terminal",
  "parameters": {
    "basis": "本图中引线、文字和端点容差的取证依据；数值均为原图坐标单位",
    "snap_tolerance": 0.01,
    "text_tolerance": 1,
    "target_tolerance": 1,
    "endpoint_tolerance": 0.01
  },
  "scopes": [{"scope_id": "单层局部", "floor_id": "F", "bounds": [0,0,10000,10000], "basis": "本图工作范围与楼层依据"}],
  "segment_bindings": [{"segment_id": "S", "source_id": "CAD-<句柄或完整实例路径>", "part_index": 0}]
}
```

示例容差仅适用于合成图，实际必须替换并写明依据，不是插件默认值。`segment_bindings` 必须覆盖本输入的全部管段；源曲线和输入中心线起终点须在已声明容差内一致。只有完整WCS直线源管段可接入当前直管消费者，缺源、弧形目标、合成中心线或未覆盖的竞争对象保留待办，不用项目脚本绕过。范围要同时包含文字和指向端；楼层与管段一致，系统须已明确；多个命中者即使距离不同也不取最近者。

```text
python bind_duct_vertical_annotations.py --input <绑定配置.json> --output <接入后风管输入.json>
python infer_duct_fittings_vertical.py --input <接入后风管输入.json> --output <推算结果.json>
python build_duct_vertical_annotation_review.py --input <推算结果.json> --output <复核视图.json> --html <复核页.html>
```

绑定入口及每次推算均复核当前原CAD、交换DXF、中性清单与布局/块定义流的SHA256。风管输入和冻结文件内容须一致，不接受先绑后手改目标的中间结果。来源非法或发生变化返回2，不留下本次新成果；未决候选属于有效工作回执，返回0仍不表示数量完整、专业复核通过或正式采用。输出保护所有被读取来源，不覆盖输入与已有绑定/复核页。

三处新增写入面统一比较解析后的路径与文件身份：`samefile`同时拒绝来源的硬链接，父目录junction/符号链接等别名按实际路径和文件身份核对；不能只比较路径字符串。JSON先完整序列化，再写独立临时文件，写入前复查后替换输出目录项，避免直接截断链接所指原件。推算器原本允许覆盖的非来源旧结果仍可覆盖；绑定和复核页仍保护已有成果与批注。复核HTML及JSON两个输出均在首次写入前检查，不能因HTML别名被拒绝而先留下部分视图。

高度主体取当前原图TEXT/MTEXT原文，不采用调用方缓存的`height/subject`替代。明确“水管下接高度2.4m”、桥架等其他专业，或文字含多个主体/高度，均为未决；明确风管及无矛盾、唯一有据风管目标下的“下接高度2.4m”“立管下接高度2.4m”继续按原条件工作。标准化输入中任填`subject=风管`不能覆盖原文的水管主体，每次消费者推算仍核当前来源并重读原文。

## 引线和实例

`DIM_LEAD` 是可配置图层过滤，不是假定实体类型。中性 `LINE/LWPOLYLINE/POLYLINE/ARC` 等曲线和 `LEADER` 顶点沿共享 `qto_segment_graph` 构图。只并连续端点，不桥接缺绘段或中途交叉；分叉、闭环、文字归组不唯一均待核。`LEADER` 的第一顶点须与最终指向端相符，反向矛盾不采用。中性展开按明确 `expand_blocks`，保留完整INSERT矩阵和实例路径；参数曲线整体变换，不以弦替代曲线或以bbox代替来源几何。

默认 `terminal` 要求文字在完整链的一个自由端附近。对原图文字置于水平肩线内侧上方的表达，须显式选择 `terminal_or_baseline_shoulder` 并给 `parameters.shoulder_angle_tolerance_deg`（小于45度）。该模式要求唯一肩线与完整变换后的文字基线平行，文字在肩线内部投影，且同一完整链两自由端中只有一端的线方向平行基线，另一端为唯一非平行指向端。多个肩线、分叉、非相似实例变换或多条文字共用同链均待核。文字投影距离、原文、矩阵及肩线段来源完整输出；不靠固定字高、固定行距、最近文字或项目专用ID归组。

原图坐标单位与文字高度单位分别核验。中性图纸单位已知时须与风管输入坐标单位一致；已知单位冲突时，说明坐标可能混换，须先核正，保留高度事实及null竖向量。Unitless时可给 `unit_evidence`，包含 `unit/basis/geometric_corroboration`，使用共享单位几何佐证契约（同图源对象范围和已知实物尺寸或图框两轴）。文字里的m不证明平面坐标为mm。未知比例不影响同原坐标的源几何身份和唯一指向，因此不单独阻断明示竖向长度；但新竖段理论展开面积null，并列 `annotation_surface_unit_unresolved`。既有按冻结输入声明单位计算的平面量、面积和混合总量移入 `conditional_on_input_unit` 条件参考区；主结果平面长度和完整总量置null，长度汇总只保留独立明示竖向量已知子集，面积汇总为空；`source_xy_unit_verified=false` 明示这一边界，不能用明示2.3m反向认证XY比例。

## 既有链路与采用边界

已闭合的结果列入 `vertical_items`，`kind=annotation_explicit_height`，数量层级固定规则推算，继承目标段规格；实际参与 `length_summary/theoretical_surface_summary/part_totals/metrics`。每项保留原文、SHA、原始对象ID、完整实例路径、坐标空间、完整曲线、矩阵、作用楼层系统及绑定距离。与同段既有竖向段或竖向方案可能重复时，新项保留null待核，不叠加；同一指向位置的多个引注也是重复候选，不以几何接近直接合并。此保守分支可能需要补充不同物理连接身份后再计独立竖向段。

同目标的两条引注，只有从当前源直管曲线推导的不同起终端口才能在本入口证明不同连接：保留源SHA、完整实例/部件、起终端口和端点坐标。相同端口或不能证明异端时，两项保持未决，不能因为箭头相差超过`snap_tolerance`就叠加两次。`snap_tolerance`只用于图元连续性；端口邻域使用已声明的目标命中范围。不同目标或有据不同端口的合法引注继续可算；任填不同`connection_id`不提供物理连接证据，本入口不开放这一绕过通道。更多同段内部独立连接需先补有据的独立源对象/端口事实，不能只给两个字符串。

`build_duct_vertical_annotation_review.py` 将已算长度、未知值和来源回执投影到已有共享 `qto-review-view/1.0`，调用现有HTML生成器；不另写前端，不生成新数量或签认。曲线采样仅用于图面显示，完整曲线仍在证据内。所有结果 `business_adoption_allowed=false`，无人工复核凭据；专业复核、项目采用、真实DWG完整算量验收和发布安装仍分别判断。
