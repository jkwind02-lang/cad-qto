# 管件中心线与竖向段推算

直管参考值不是计量长度。GB 50856 的风管长度是“直管 + 管件中心线 + 竖向段”：主管与支管以中心线交点划分，弯头、三通、变径、天圆地方的中心线计入，阀门等部件所占长度不计。平面图的中心线图层通常只画直管，管件处没有中心线、阀门处中心线断开、上翻下翻和层间立管在平面上不表示长度，三者合计常占直管长度的两成以上。本文规定从平面事实推算这三部分的方法和依据层级；脚本是 `scripts/infer_duct_fittings_vertical.py`，输入格式见文末。

## 1. 输入是模型已识别的对象，不是原始图层

模型先按 SKILL 第 2～4 步从图纸形成三类对象，再交给脚本：

- **直管段**：同层、同系统的中心线段（起止点、宽×高或直径、尺寸依据层级）。规格标注只在标注宽度与实测外轮廓宽度一致时绑定，不按就近文字取规格。
- **管件块**：弯头、三通/四通、变径、天圆地方、支管接头的块实例范围（`bbox`），`kind` 由图例或块名经模型核对后填写；不确定填 `unknown`。可显式给出 `ends`（接入的管段端点）和 `system`，否则脚本按“端点落在块范围内”判断。块范围同时覆盖多个风系统而未明确归属时列待办，不自动跨系统连接。单端件还须给下述 `single_end_geometry`；外包框本身不是中心线依据。
- **标高标注**：绑定到直管段，写明 `reference`（`bottom` 底标高 / `top` 顶标高 / `center` 管中心）和依据层级。BL 标注为底标高；无 BL 的标注按本项目图例确定是顶还是中心，不默认。楼层标高（`floors[].level`）来自系统原理图或说明，平面偏移（`plan_offset`）来自图框定位。

## 2. 管件中心线（规则推算）

| 情形 | 判定 | 长度 |
|---|---|---|
| 两端相交（弯头、斜接） | 两侧中心线延长线有交点且臂长不超过 `junction_max_arm` | 各端点到交点的距离 |
| 两端共线或平行（变径、天圆地方、同轴弯头对） | 无交点 | 两侧各计端点间距的一半，各侧按自己的规格记 |
| 三端及以上（三通、四通） | 最平行的一对为主管，交点取主管线与支管线交点 | 各端点到交点 |
| 单端支管接头（`tap/tee`） | 端点沿管向延伸落在同层、同系统主管区间内 | 端点到主管中心线交点 |
| 无块的自由端落在主管带宽内 | 同层、同系统，垂直距离 ≤ 主管半宽 + `tap_margin` | 端点到主管中心线交点，记为 `open_taps` |
| 单端弯头 | 已核对连接端、转弯平面及中心位置 | 平面段按几何依据计，竖向另列；缺依据不填数 |

同层、同系统的同类块范围重合（Revit 导出常见）按一个物理管件计一次；归属系统未明时不自动去重。两端都不在任何中心线范围内的块列为待办 `fitting_unconnected`。以上长度的依据层级都是“规则推算”；缺少单端几何依据时列未决，不用默认读法补量。

**单端平面段的几何依据。** `single_end_geometry` 必须有 `source_id`、`basis` 和 `endpoint_relation`。距离与坐标均用输入的原始长度单位，距离从直管连接端沿外向管线方向量取。`endpoint_relation` 为 `at_connection`（直管止于管件连接端）、`already_at_center`（已画到中心）、`reversed`（方向相反）或 `unknown`（关系未明）；后两种不出平面长度。

| 几何输入 | 前提 | 平面段 |
|---|---|---|
| `centerline_point: [x,y]` | 核对的转弯中心或在线件本体远端，在管向前方的中心线上、块范围内 | 直管端点到该点的距离 |
| `riser_projection: [近边距离,远边距离]` | `turn_plane: vertical`，从图面核对的立管本体两条投影边，排除法兰外伸 | 两边距离的中值 |
| `flange_allowance`（无外伸也须显式写 0） | `turn_plane: vertical`，块远端为外皮加法兰；立管沿来向尺寸取 `riser_depth`，未给时取圆管直径或矩形管高 | 块伸出长度 − 立管沿来向尺寸/2 − 远端法兰外伸 |
| `body_length` | 单端 `reducer/rect_to_round` 已核对本体连接端及本体长度 | 本体长度，不扣半宽，不作为竖向弯头 |

例如矩形管宽 1000、高 320，块沿来向伸出 385，远端法兰外伸 30，则平面段为 385 − 320/2 − 30 = 195，不是减半管宽后裁成零。`riser_depth` 指转弯后沿来向的尺寸，不能仅因有管宽就代替管高。多种依据不一致、扣减后为负、方向相反或只有外包框时，`centerline_length: null` 并列待办；已知直管仍保留。`already_at_center` 必须用吻合的中心点证明，才允许该段为零。水平转弯须写 `turn_plane: horizontal` 并提供中心点，不自动当成立管。

默认 `single_end_plane_policy: geometry_evidence`。旧 `extension_minus_half_width` 与 `extension_full` 参数仍可读，但只保留在 `single_end_plane_scenarios` / 逐件 `plane_scenarios` 作诊断，不再决定采用量。几何未决时几何合计为 `null`，`known_geometry_subtotal` 单列已知部分。旧输入须补齐几何依据后重跑，不能把诊断值或已知小计当完整量。

## 3. 阀门断口续接

同层、同系统的两个自由端共线、相向、间距在 `accessory_gap_min`～`accessory_gap_max` 之间且没有管件块时，判为在线部件（阀门、软接）断口：拓扑上续接，用于标高和规格传播；长度按 `accessory_gap_policy` 处理，默认 `exclude`（部件所占长度不计），项目口径要求计入时设 `include` 并在成果说明。断口本身也是阀件计数的候选位置，计数仍由阀件识别负责。不同系统即使端点重合或只差一个断口，也不自动连接或传播标高。

## 4. 竖向段

管中心标高 = 底标高 + 高/2，或顶标高 − 高/2；缺高度时无法换算，列未决。无标注的管段沿同系统连续管路（直连、断口、支管接头、有交点的管件，不跨上下翻和单端弯头）取最近标注；同距离出现多个不同标高时不取平均，列未决。

| 类型 | 识别 | 长度 | 层级 |
|---|---|---|---|
| 层内上下翻 `in_floor_offset` | 两端同轴的弯头（或同轴弯头对） | 两侧管中心标高差 | 两侧都是标注或由标注传播 → 规则推算；任一侧含方案假定 → 方案暂估 |
| 支管竖向接主管 `branch_to_main` | 已声明竖向转弯，单端弯头有依据的 `plane_center` 落在同层、同系统另一管段的带宽内 | 支管与主管管中心标高差 | 同上 |
| 层间立管 `inter_floor_riser` | 相邻楼层同系统各有一个已声明竖向转弯的单端弯头，有依据的中心按平面偏移对齐后距离 ≤ `riser_match_distance` | (上层层标高 + 上层管中心) − (下层层标高 + 下层管中心) | 同上；缺楼层标高 → 未决 |
| 宿主判定连接 `host_declared_link` | 宿主已从系统图、剖面或现场资料判明的连接，经 `vertical_links` 输入 | 两侧管中心标高差，跨层加层标高 | 两侧标高层级与连接自身层级取最低；输出 `origin: 宿主判定` |
| 单端去向不明 | 以上都不成立 | 不填数 | 待办，查系统图或剖面后补 |

“方案暂估”来自标高本身的假定（例如把无 BL 标注当成顶标高、支管取主管标高）；脚本不加入任何经验比例或默认层高。

**宿主判定的竖向连接。** 脚本只认平面几何能确定的三种竖向关系。宿主已判明去向的单端弯头（例如剖面显示它下翻接某根主管），或两段管之间的竖向连接，写进 `vertical_links`：

- `single_end_to_segment`：`fitting_id` 必须是脚本判为单端的管件，`to_segment_id` 是去向管段；
- `segment_to_segment`：`segment_id` 与 `to_segment_id` 两段管；若与自动识别的同轴上下翻是同一对管段，以宿主声明为准，自动项不再输出；
- 每条必须有 `source_id`（剖面、系统图、宿主核对记录的编号）和 `basis`；`evidence_level` 默认“规则推算”，有图纸明示的竖向尺寸也只说明连接成立，长度仍按标高差算。

声明过的单端弯头不再参与自动匹配；其平面几何等其他未决仍保留。脚本不核对宿主的判断是否成立，只核对引用的管件和管段存在、单端状态相符、不重复声明及同系统边界；跨系统声明报输入错误。

**标高来源与传播优先关系。** 每段管的标高有 `origin`：

| `origin` | 含义 | `evidence_level` |
|---|---|---|
| `tag`（默认） | 本段平面标高标注 | 默认“确认” |
| `system_diagram` / `section` | 系统图或剖面上读到的本段标高 | 必须显式给出 |
| `host_propagated` | 宿主自己沿管路传播得到的标高 | 只能是“规则推算”或“方案暂估” |

`source_id` 写标注、系统图、剖面或宿主传播记录的编号；宿主传播的 `source_id` 指向传播起点的标注，便于回查。凡输入里给了标高的管段，脚本都直接采用，不再用脚本传播覆盖；脚本只为没有标高的管段沿连续管路传播，输出的依据里写明来源（本段标高标注、系统图标高、剖面标高、宿主传播标高、或“沿连续管路传播自 …”）。宿主传播与脚本传播对同一段给出不同值时，以宿主输入为准，但宿主应在依据里说明为何不同。

## 5. 成果与检查

脚本输出 `qto-duct-fitting-vertical-result/1.0`：`straight_segments`（确认）、`fittings[].arms`、`open_taps`、`accessory_gaps`、`vertical_items`、`pending`、`single_end_plane_scenarios`，以及按系统、层级、规格的 `length_summary` 和理论展开面积 `theoretical_surface_summary`（周长 × 长度，按各臂所属管段规格）。`metrics.measured_length_rule` = 直管确认 + 管件规则推算 + 竖向规则推算（+ 计入口径的断口）；方案暂估和未决分列，不相加。

交付前核对：各部分输入合计等于输出合计；每个单端弯头要么进入某个竖向项，要么在待办里；断口数与阀件计数对得上；`business_adoption_allowed` 恒为 false，经专业复核后才进入成果。不在自动范围：剖面/系统图上的竖向尺寸、异形件展开面积、软接长度、支吊架。

  "parameters": {"parameter_basis": "端点吻合 5mm，部件断口 30~2600mm，块范围容差 15mm；依据本图绘制精度", "accessory_gap_policy": "exclude"},
  "segments": [{"segment_id": "1F-S001", "floor_id": "1F", "system": "SME", "start": [0, 0], "end": [9500, 0], "width": 1000, "height": 500,
                "size_evidence_level": "确认", "elevation": {"value": 3.0, "reference": "bottom", "evidence_level": "确认", "source_id": "TAG-1A2B", "text": "SME 1000x500 BL+3.000"},
                "source_ids": ["CAD-1A2B"]}],
  "fittings": [{"fitting_id": "1F-F001", "floor_id": "1F", "system": "SME", "kind": "elbow", "bbox": [9400, -600, 10600, 600], "source_id": "CADINST-...", "block_name": "矩形弯头-...",
                "single_end_geometry": {"source_id": "VIEW-F001", "basis": "已核对连接端、竖向转弯和中心点；示意数据须以本图替换", "endpoint_relation": "at_connection", "turn_plane": "vertical", "centerline_point": [10320, 0]}}],

~~~

`parameters.single_end_plane_policy` 默认 `geometry_evidence`；旧两种读法只作诊断，不作为补量依据。`vertical_links` 可省略；`segments[].elevation.origin` 可省略（视为 `tag`）。

`unit` 必须是可核验的物理长度单位（INSUNITS 为 0 的图先按单位说明确认）；`parameters` 其余键见脚本 `DEFAULT_PARAMETERS`，改动须在 `parameter_basis` 写明依据。
