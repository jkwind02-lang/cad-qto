# 圆弧错缝与椭圆真实等距中线

本能力消费当前冻结中性几何及模型有源识别配置，形成规则推算工作量。它不确认原生载荷全部读出、恒定截面或正式工程量。所有源轮廓、完整实例/part、仿射变换及来源SHA继续保留；曲线读出、模型识别、规则推导和正式采用分开。

## 同心圆弧的全部角域分区

同面圆弧按完整WCS参数识别，圆形判定用几何相对精度，不把半轴差落在配对容差内的椭圆当成圆。截面直径/宽度、源物理单位与显式配对容差沿用既有规则。

把同心圆弧的真实参数域转换到共同平面基底，处理起点旋转、正反向参数以及跨0度缝的角域交集。所有对侧实际端点都传到原part的0～1参数域，直到分区闭合；每个原子区间独立检查双向唯一配对。错缝可一对多，重复轮廓只阻断它实际覆盖的歧义区间。父part只作索引，全部子区间几何/原参数范围/去向保留，子区间原曲线长度之和与父part守恒。曲线中径按真实半径和扫角解析计长，不取弦长。

## 可证唯一的椭圆等距中线

非等比变换后的两条同心圆轮廓一般成为椭圆。平均半轴所得椭圆通常不等距于两侧；不能把它当欧氏等距中线。本入口实际求解 `distance(x, inner) = distance(x, outer)`，中线一般不是椭圆。

当前可证条件是：两椭圆共中心、同主轴、严格嵌套，且最大支撑间隔上界 `D=max(a_outer-a_inner,b_outer-b_inner)` 小于外椭圆最小曲率半径 `reach=b_outer²/a_outer`。`a>=b>0`为真实主半轴。原u/v可以是非正交仿射参数，先从Gram矩阵恢复主轴，不以原u/v长度直接当主半轴。共同中心/主轴只允许被误差预算覆盖的浮点对齐误差，不把真实错位轮廓静默拟合成同轴。

支持完整闭合椭圆（源参数起点可任意、方向可相反）和主轴扇段。有限源弧还支持非主轴起终点和部分错缝：只计算两侧全局最近落足均位于实际源弧内的互唯一区间，详见下一节。三维同面旋转允许，WCS的Z不丢失。偏心/非同轴、交叉轮廓、不满足reach界的厚环，以及依赖有限弧端点形成的专属等距骨架仍未实现；保留完整几何和待办。未满足当前证明条件不等于数学上不存在等距集合，也不能改称项目特例或用平均半轴补量。

唯一性依据：内椭圆是凸体，外部最近点唯一；上述薄环不进入外椭圆内部中轴，外侧最近点也唯一。沿共同中心的每条射线，内距离严格增加、外距离严格减少；其距离差径向导数具有正下界，因此每条射线有唯一等距根。主轴四分区中的最近点仍在相同四分区，有限弧的端帽不会被完整椭圆的区外最近点代替。完整轮廓只是几何依据，不证明物理供装或恒定截面。

## 有限椭圆源弧的最近落足分区

`duct_elliptical_outline.py`接入实际中性建网入口。先从实际WCS的u/v恢复同轴完整支持椭圆，再沿前述可证中线反解每条实际源弧的落足起终界。边界反解沿该源点的精确法线求另一侧距离，不按两侧相同参数或角度硬配端帽。最近落足映射在薄环内单调：中线切向在两侧轮廓切向上的投影同向，内侧投影分母`1+dκ`为正，外侧`1-dκ`由reach界保证为正；等距法向根导数`1+n_inner·n_outer`具有正下界。原弧参数方向、跨零缝和完整源弧自身的参数缝均保留。

所有实际起终界统一转到共同径向角域。最近点/径向根误差纳入落足角误差界；向内收缩的可证域用于计长，向外扩大的可能域用于检测歧义。只有每侧可能候选都唯一、且整个原子角域落在两条源弧的可证域内时，才生成实际中线。重复轮廓仅阻断其可能覆盖区间；不能因端点安全带未进入可证域就认为候选不存在。三组及以上不同支持椭圆整组保留未识别，不从复杂实际轮廓中择二制造局部闭合。

父part只作索引，按中线真实落足参数将原源弧分为计入区间和未识别余段，子行保留`parent_source_part`、`source_fraction_range`、原曲线几何/哈希及`source_fraction_error_bound`；从0到1的子区间完整衔接，原源弧长守恒。中线描述增加`trimmed_arc_domain`，保存两条完整实际源弧、径向区间、两侧落足参数范围及误差，消费时从原弧重算，不信任调用者自填区间。

非主轴端部只覆盖上述全局最近落足都在实际弧内的部分；端点安全边界与仅由有限弧端点形成的等距集合不填量。已计长度是已知小计，不能因局部区间闭合宣称完整风管长度，更不能据此生成面积、支架或正式数量。三组支持轮廓、偏心、厚环、非均匀截面语义和特殊TCH载荷语义仍分别为通用余项。

## 配置与真实计长

在outline规则中显式增加以下对象，并在同一冻结识别证据中原样保存 `equidistant_midline`：

```json
{
  "equidistant_midline": {
    "method": "euclidean_nested_ellipse",
    "distance_tolerance": 1e-8,
    "chord_tolerance": 0.5,
    "length_tolerance": 0.01,
    "basis": "本源双轮廓采用欧氏等距中线计长；非均匀间隔的截面语义另核"
  }
}
```

三个容差均为源WCS绘图单位；示例不是项目默认容差。最近距离容差须覆盖浮点分辨率且远小于可证最小轮廓间隔，显示容差不得超过reach的百分之一，长度容差不得超过尺度的万分之一。预算不足、根未括住、积分未收敛或显示需要超过65536区间时拒绝该求解，不截断、不回退弦长。

真实最近点用拉格朗日乘子单调方程求解，最近点括区的点包络对角线约束最近点误差；内部主轴存在两个等近点的情形明确拒绝。径向等距根结合距离误差区间及正导数下界收敛。由距离梯度求隐式曲线导数并自适应积分，再以更严精度独立积分检查差值。输出长度误差由最近点/径向根误差传播界、积分误差估计和加严复算差组成。积分项是数值误差估计，不宣称已完成任意精度区间算术证明。

`geometry`继续使用 `qto-cad-geometry/1.1`，`parts`为完整显示折线，另带 `derived_midline`（`qto-duct-euclidean-midline/1.0`）保存两条完整源边界及全部求解设置。`checked_geometry`从描述重算，逐项核对显示几何；其 `length` 是隐式曲线积分，不是折线弦长和。两侧原轮廓仍在 `source_geometry_refs` 中，来源覆盖逐part绑定，实际consumer重放冻结生成器防止改写。

实际结果的 `length/length_error_estimate`为输出单位（通常m）；`polyline_chord_length`只作对照。`midline_evidence`记录唯一性条件、实际最近距离残差/最近点误差、根误差、积分误差及加严差。二维和三维均按真实曲线计长，源Z不当作已核绝对标高。

## 显示位置界、端口与工程边界

显示折线位置界由隐式曲线曲率/速度上界控制：若弧长上界为L、曲率上界K，则每个弦区间偏离不超过 `K*L²/8`，再计入根及源参数对齐误差。实际 `geometry_position_error_bound` 与 `midline_evidence.display_chord_error_bound`均用源单位；不能把它们误读成长度误差或输出米数。包围盒在实际平面方向扩大相应位置界。

`source_curve_network`使用真实隐式曲线的端点和端切向；端点单独带 `position_error_bound`（源单位），它通常小于整段显示折线位置界。位置误差跨越吸附容差时，端口保留未决。穿墙等消费方使用显示折线时，必须把该位置界纳入近边界不确定性，不能把显示交点直接升为确定穿墙处。

非均匀WCS轮廓间隔不证明恒定截面。中线长度可独立形成工作量，`source_cross_section_consistency`保留未核，`surface_calculation_allowed=false`且理论面积为null，不能借已算中线长度确认展开面积。当前点位投影未消费该误差界，故 `host_attachment_eligible=false`，生成宿主接收明确拒绝；普通精确直线/曲线宿主及R1接口保持原行为。

含曲线的多个主路或其他歧义端口会输出 `ambiguous_port_nodes/blocked_legacy_endpoint_pairs`。旧直线引擎不能仅看剩余两条直线另建joint而绕过该未决节点传播等高；无曲线的合法两直线弯折和唯一主路分支仍按原有规则处理。开放端、缺物理端口和复杂管件不猜连。

## 特殊原生几何前置边界

基础读取已经输出完整标准WCS line/ellipse_arc参数及变换时，本通用入口直接消费，包括普通ARC、ELLIPSE、bulge以及非等比INSERT后的椭圆；本轮匿名DXF已走实际中性提取和风管CLI。

当前天正专用基础数据中的 `native_path`、`serialized_curves`和 `SERIALIZATION_COMPLETE`应分别核查。`TCH_DBHVACDUCT`的Start/End/R23及附属边的kind_code/parameter仍保留原字段，公共读取层未把这些专用参数映射为完整可测WCS曲线；`geometry_semantics_complete=false`且 `geometry=null`。这属于通用读取/几何语义映射前置缺口，本轮未伪造解码或用Start—End弦长替代。真实载荷未恢复、原生曲线含义未明和专业端口依据不足分别保留，不据字段序列化完整宣称原生风管建网整包完成。
