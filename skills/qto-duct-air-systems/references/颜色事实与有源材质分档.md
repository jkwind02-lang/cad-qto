# 颜色事实与有源材质分档

颜色是CAD源事实，材质是图例或说明确定的专业属性。不得把某个项目的“蓝色为不锈钢”设为通用默认；只有颜色继承输出时，不得声明材质已完整识别。

## 中性颜色与实例来源

新版 `extract_cad_neutral.py` 在布局和块定义图元写入 `raw_color`，保存ACI原值、显式状态、TrueColor和颜色名称；清单保存 `color_schema_version=qto-cad-color/1.0` 及实际层色表。版本不齐或缺层、缺父实例时颜色继续未知，不补默认白色。缺少受支持颜色契约时，即使旧JSON含raw_color并重签图元文件哈希，也不产生已解析颜色，保留unverified_color_schema；几何入口仍兼容。层色为负数表示关闭状态，其色号绝对值仍保留；颜色事实本身不证明图元当前可见或应计量。

`expanded_manifest_rows` 为每个实际实例生成 `color_evidence`：TrueColor优先；ACI 256按有效图层取色；ACI 0从直接父INSERT取色，父INSERT继续按自己的来源解析；块内层0继承所在INSERT的有效层。非0层不因嵌套改成外层。原定义、实例路径、原始/有效层及逐级继承链均保留。同一定义的两个INSERT可能颜色不同，不按定义句柄合并颜色。

风管builder保留逐part来源、分区比例与几何指纹；双色轮廓、不同来源或分段来源颜色冲突时 `material=null`，不按长度、面积占比或多数边线挑选颜色。ACI和TrueColor按原颜色模型分别比较；等价显示色未经声明不自动归并。顶层ByBlock缺父色保持未知。

颜色表和原图元色会对冻结的DXF交换副本复验。该核对只证明本交换副本中的颜色，不证明DWG代理对象在转换前后的显示、视口覆盖、打印样式、外部参照或未恢复原生对象完全一致。

## 同版原文规则

`build_duct_network_from_neutral.py` 的原识别配置可增加 `color_material_rules`。每条规则须给唯一 `rule_id`、明确 `material`、准确颜色、精确源实例列表、同版源SHA、布局/空间/裁剪范围，以及实际TEXT/MTEXT的源键和原文：

```json
{
  "rule_id": "图例材质1",
  "material": "示例材质",
  "color": {"model": "aci", "value": 5},
  "scope": {
    "source_sha256": "填写实际原图SHA256",
    "layout": "Model", "space_id": "填写实际空间", "crop": null,
    "source_keys": ["CAD-填写实际句柄或完整实例路径"]
  },
  "note": {
    "source_key": "CAD-填写实际文字句柄或完整实例路径",
    "expected_text": "蓝色风管为示例材质"
  }
}
```

这是当前工作识别范围绑定，不是人工复核或正式采用。源实例范围由专业识图确定，不自动将图例推广到其他图纸、空间或裁剪范围。不存在的源键、原图SHA/空间/裁剪范围不符会拒收。

当前原文语法只支持完整明示句：`蓝色风管为示例材质`（也支持红、黄、绿、青、紫、白，以及“采用”“材质为”）、`ACI5风管材质=示例材质`、`RGB(10,20,30)风管材质=示例材质`。允许空格、分号/句号分隔、MTEXT的 `\P` 换行；仅颜色名称按标准色名对应到ACI/纯色RGB，不包含任何材质默认值。复杂富文本、仅有色样而无可解析说明、其他措辞及外部PDF图例仍需后续原文适配，不以用户自填JSON映射冒充已核源规则。

图例/说明文字必须在同版实际DXF中存在，原文与规则一致，且完整明示句支持该颜色和材质；仅提供 `basis`、签名、哈希或自填evidence不能替代实际文字。即使调用者只选择同一说明中一条映射，该说明同色不同材质的其他明示句仍造成冲突。多规则同色不同材质也保留冲突，不能按规则顺序覆盖。

## 实际消费及数量边界

真实生产链仍用 `extract_cad_neutral.py → build_duct_network_from_neutral.py → infer_duct_fittings_vertical.py`。原有CLI参数保持不变，builder调用实际consumer并保留退出日志。consumer先按中性清单和配置重建校验，再在 `straight_segments` 和 `drawn_curve_segments` 附加 `color_material` 与 `material`；篡改颜色、材质或规则结果会拒收。在线附件数量接收同时绑定qto_cad_color.py与duct_color_material.py的实际文件字节，任一依赖变化均须重新实际消费；旧收据不能只凭数值相同继续接收。

`material_quantities` 保存实际已绘直管/曲线的原长度、理论展开面积、源ID和完整颜色/图例链。未明材质为null，`classified_length`/`classified_theoretical_surface_area`也为null；原几何量不因材质未明而删除、变零或改动。`material_summary` 保留null材质分组，已知小计和未知项数分列；单位未知时米制长度和面积继续null。

本入口不把材质传播到推算管件、竖向段、投影立管或附件断口；这些范围列在 `material_scope.not_classified`。非均匀等距中线缺截面语义时面积保持null。`complete_material_quantity=null`，不把颜色传递、局部材质分档或图层覆盖闭合提升为完整材质工程量、工程验收或正式采用。

## 保留的通用与项目事项

通用余项：上述未支持的图例语法/色样或外部说明、视口/打印/外参颜色覆盖、特殊原生对象的未恢复颜色语义、单个源part内部的材质边界，以及推算管件/竖向/附件的材质专门依据。不能凭本接口声称任意颜色语义或任意材质计量全覆盖。

原项目仍须核对原图“蓝色为不锈钢”的真实适用范围、实际图元与施工材质；原临时脚本的边线蓝色占比不能作为通用插件判定。原项目全量复跑、工程量核准、人工复核与正式采用另行核验，本批匿名回归不替代它们。
