# 计算与证据流程

1. 按系统编号从设备/竖井/干管到支管和末端建立拓扑，系统图与平面/模型逐端点对账。
2. 直管在截面、材质、板厚、标高或方向变化处分段；平面、竖向和偏移长度分别保留后合成真实中心线。
   原生直段清单每行须有唯一、非空的文本 `id`；同一稳定 ID 不得重复列入。明确同族多件可用 `count`，不同物理段即使几何相同也保留各自 ID；工具不凭几何相同自动合并。
3. 管件作为独立实体，不以直管延长替代；记录接口规格、中心点/端面、角度和来源。
4. 法兰/连接按实际接缝或核定分节实例，风阀按在线节点统计；防火分区和穿墙套管边界另列。
5. 支吊架按明确布置/间距、起止端、弯头阀件和设备附近加固逐实例生成；方案依赖项未明确不计算。
6. 保温和外保护层按实际覆盖外表面，风管、管件、阀件及不保温段分别处理。
7. 向点位 Skill 传递末端接口 ID，只引用风口/设备实例数量，不重复计数。
