# 有源矩形圆弧弯头参考

入口 `scripts/calculate_source_duct_bends_reference.py <输入.json> --output <新结果.json>`，输入 schema 为 `qto-source-duct-bends-reference/1.0`。只处理0至180度、等截面矩形、内外为同心圆弧的光滑弯头。

`source` 使用公共CAD来源描述（path/sha256、可选authoritative_source），实际重读文件与完整实例路径，不消费回填的半径或面积。`unit_evidence` 给 unit、object_id、text_contains，单位须有原图明确物理单位文字；单位说明在另一图时另给 source。默认Model，可显式layout。

`elbows` 每项只接受以下六个字段：

```json
{
  "physical_id": "BEND-unique",
  "inner_arc_object_id": "CADINST-Model/parent/inner",
  "centerline_object_id": "CADINST-Model/parent/centre",
  "outer_arc_object_id": "CADINST-Model/parent/outer",
  "radial_width_note": {"object_id":"CADINST-Model/width","text_contains":"160","pattern":"^(\\d+)$","group":1},
  "transverse_height_note": {"object_id":"CADINST-Model/height","text_contains":"200","pattern":"^(\\d+)$","group":1}
}
```

尺寸数值从当前原图文字正则捕获，按同一有源单位换算。模型必须解释宽度在弯曲平面内、高度垂直该平面；程序不按截面书写顺序或最近文字猜对应。

程序检查三个源弧均为圆、同心、同扇区、同转角，内/中心/外半径有序，`Ro-Ri=w`、`Rc=(Ri+Ro)/2`。支持源实例旋转、镜像及有相应标注的均匀缩放；非均匀缩放产生椭圆时拒绝。物理ID及源弧不可重复或换名重复使用，计数按每个物理实例独立建项，不接受count或数量答案覆盖。

源弧ID与公共查源规则一致，去除首尾空白后执行同项角色去重、跨项去重及结果绑定；更换物理ID或增添空白不构成新源实例。块实例路径不同的真实弯头仍可分别计量。

开口理论壳体四面分别为 `Ri×θ×h`、`Ro×θ×h`、两个 `θ×(Ro²-Ri²)/2` 扇环面；轴长 `Rc×θ`。没有端盖、接口重叠、咬口、板厚偏移、法兰、导流片或损耗。输出保持REFERENCE_ONLY、不可正式采用，不能把理论壳体当采购净下料。

缺半径的其他实例保留未决或独立方案，不能把代表弯头源弧复用到其他位置。三通、矩形变径、内斜线/折线弯头等继续按各自实际展开证据处理。本入口通过也不代表完整风系统或所有管件通过。
