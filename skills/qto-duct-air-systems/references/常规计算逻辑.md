# 常规计算逻辑

## 1. 长度

直管中心线长度为三维端点路径长度之和；矩形和圆形均在尺寸、标高、材质或系统变化处分段。弯头、三通、四通、变径和软接按独立构件计，不把其外轮廓重复并入相邻直管。

## 2. 直管理论展开面积

- 矩形等截面直管：`A = 2(a+b)L`，`a、b` 为用于该口径的风管外尺寸，`L` 为中心线净长。
- 圆形等截面直管：`A = πDL`，`D` 为对应口径外径。
- 椭圆、异形和复合风管：按实际截面外周长 `P`，`A = P×L`。

接口处长度是否扣除、法兰是否另计、板厚/周长采用内外尺寸，必须按当前成果口径明确。以上只是几何参考，不自动等于清单采用面积。

## 3. 管件

- 弯头、三通/四通、变径、天圆地方和异形件按实际展开几何、经核定加工表或模型表面积计量；不得用大端周长×轴线长度统一替代。
- 软接按实际周长×展开长度或成品实例数量，取决于项目口径。
- 导流片、加固框、消声弯头等按明确详图/清单另列。

## 4. 法兰、阀件与支吊架

- 法兰/连接：按物理接缝实例计数或按明确周长/重量输出；成品风管接口已综合时不能重复。
- 在线风阀：按系统拓扑中的唯一节点和规格计 `个`，与风口/设备点位互斥。
- 支吊架：常规数量由每段允许间距、首末支架、弯头/三通/阀件/设备旁附加点以及共享情况形成；只有净跨度和具体布置规则闭合时才生成，重量按明细构件长度×单位质量。

## 5. 保温与保护层

- 未保温直管外表面积按上述展开面积；保温外表面候选式：矩形 `A_ins=2[(a+2t)+(b+2t)]L`，圆形 `A_ins=π(D+2t)L`，其中 `t` 为明确保温厚度。
- 管件、阀件、法兰、软接及不保温段按实际覆盖范围独立处理；外保护层与保温层分材料输出。

## 6. 校核

系统拓扑端点连续；直管端点与管件接口无重复/断口；平面+竖向可回放；各规格长度和展开面积量纲守恒；风阀/风口/设备唯一出口闭合；支吊架布点与净跨度闭合。缺口为 `null`。
