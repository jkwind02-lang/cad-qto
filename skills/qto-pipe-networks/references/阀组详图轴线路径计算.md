# 阀组详图轴线路径计算

用于模型已经读懂主视图、识别供回及旁通路径，但中心线被阀件符号遮断、弯头藏在块定义、三通只有轮廓的情况。先独立从原图形成计算，再与底稿比较。本工具计算可复算的图示轴线，不自动识别整套阀组，不决定适用实例和计量扣减。

## 读图与路径

1. 确定同一典型组的正视、俯视和其他辅助视图，明确唯一主计量视图；典型详图张数不是实际阀组套数。实际套数、位置和所采用详图须由平面、系统与设备表另行对应。
2. 分别追踪外侧管路、内侧管路、旁通、泄水和仪表支管，列出每条路径起止端口。总体高度中可能含支架高度，不能直接作为每条管腿高度。
3. 选中心线及块内中心圆弧，保留实例路径。弯头双线内外轮廓不能累计成管长；圆弧不能用弦长或外接框周长代替。流向箭头即使在中心线图层上，也不是管段或排气阀。
4. 阀件处中心线连续时，原线已包含占位；不要再加阀长。只有确实断开的区段才恢复轴线，并单列恢复值。
5. 三通轮廓的端面、支路中心线与主管中心线可提供端口中点和轴线交点。须先判读它确为连接；二维交叉或轮廓包围不自动证明连通或同标高。
6. 规格以有效标注、图例和连接关系裁决。块名可能来自旧模板，阀门也可能放在标注图层。混合规格路径可先得到几何长度，不能因此把全部长度套主管DN；冲突部位保留分界证据及未决影响。

## 确定性计算

运行 `scripts/measure_pipe_detail_routes.py --input 原图路径输入.json --output 详图路径结果.json`。

输入 `schema_version: qto-pipe-detail-routes/1.0`，依赖现有 ezdxf 及公共几何模块。各坐标均为DXF原始单位；输出米。几何由脚本重新读取源文件，不接受外部填入的计算长度。

| 字段 | 含义 |
|---|---|
| drawing | `{path, sha256}`，当前DXF来源 |
| export_receipt | DWG转换时提供转换凭据的`{path, sha256}`；同时检查凭据绑定的原始DWG及输出哈希 |
| raw_unit | 必须与DXF INSUNITS一致，不支持无单位猜测 |
| join_tolerance_raw | 端点接续容差，换算后不得超过1毫米 |
| views | `view_id`、`role: primary/secondary`、`bounds3d: [xmin,ymin,zmin,xmax,ymax,zmax]` |
| routes | `physical_group_id`、`physical_route_id`、`view_id`、`review_note`、`dimension_paths`、有序`segments` |

每条路径由线性尺寸实体进行标定。仅接受没有文字覆盖、线性系数一致的尺寸；实际应用DIMLFAC一次。比例或单位不明确时继续查图，不能用底稿相等、经验尺寸或“看起来过大”反求比例。当前不处理尺寸文本覆盖、跨块尺寸和非线性尺寸标定。

图元引用为 `{path: [模型空间句柄, 块内句柄, ...], part: 几何段序号}`。脚本逐层校验父子关系，保留旋转、镜像及非均匀缩放。多段线必须给出从零开始的`part`。源点增加`fraction`；直线按端点参数，圆弧按角参数，不是弧长比例。

路径段类型：

- `drawn`：`source`指向原图线段或中心圆弧。按需要给`reverse: true`以连接上一段。
- `restored_axis`：`from`、`to`引用两条相邻同轴直线的端点，给出`component_paths`及`reason`。当前只支持插入点位于断口轴段内的主视图阀件；偏置插入点、弯折断口或未定义端口须补证，不能放大容差硬接。构件仍然包含在恢复轴长中。
- `port_extension`：`from`引用原图管口端面直线中点（`fraction: 0.5`），`to`引用相邻中心直线端点，并给`reason`。检查端面与轴线垂直、中点在轴线上；适用于已判读的管口至缺绘中心线之间。
- `junction_axis`：`from`为`{intersection: [主管轴线引用, 支路轴线引用], enclosure_path: [三通闭合轮廓句柄]}`，`to`为参与求交的支路中心线端点，并给`reason`。检查共面、非平行、交点在轮廓范围内。原图模型判读负责判定它是同标高三通，脚本不自动把轮廓或交叉识别为三通。

脚本拒绝辅助视图新增量、相同物理路径重复、路径断开、越界、重复完整曲线和共线直线重叠。它不能发现所有异名实物重复或所有部分圆弧重叠，模型仍须回图检查。阵列块应先逐实例展开，不能按一个实例处理。

## 结果用途

每条路径分别列出已绘轴长、阀件断口轴长、端口恢复轴长、三通恢复轴长和合计，附原始引用、端点、尺寸标定及输入哈希。状态为模型工作计算，未经人工复核。

`axis_including_components_m`是所选视图路径含阀件的轴长。`billable_pipe_length_m`与`installed_group_count`保持未定，另以有效计量口径和实际对象完成。不得把所有恢复值自动升级成确认管长；未计的泄水、仪表支管、出平面连接、设备接口和现场高差须明列。

事后对照底稿时，先核对它记录的是阀组内配管、阀组至设备、轴网间干管还是某台固定配管。只因备注出现“阀组”不能与典型详图合计相减。按照[阀组接管与人工底稿对应](阀组接管与人工底稿对应.md)完成实例、范围、规格和单位映射后，才形成同口径数值差异。
