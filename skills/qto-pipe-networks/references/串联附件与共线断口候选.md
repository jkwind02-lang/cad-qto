# 串联附件与共线断口候选

本分支使用现有单框适配器、批量图框入口及 `infer_pipe_network.py`，不建立第二套管网计算链。结果均为工作候选，模型识别、数量证据层级和项目正式采用分别记录。

## 几何候选与阻断

- 同系统、同 `space_id` 的两个自由端点须相向，管轴的侧向距离不大于 `snap_tolerance`，不能仅用夹角把斜跨或平行错位管接起来。
- 一侧 DN 未标明不阻断几何候选。两侧及各自无分叉直通链中已有不同 DN 种子时拒绝；明示变径和范围边界仍限制传播。无 DN 种子继续为 `null`，不填零、不借最近文字。
- 多个相容目标不自动取最近一个；断口内有原已绘管线、支路或尚未判明的曲线交越时拒绝或保留待核，不重复补已有长度。跨系统、跨图空间、端点方向不符和侧向偏移均不桥接。
- `parameters.collinear_gap_max` 是共线短断口搜索上限；`serial_accessory_gap_max` 是串联附件证据搜索上限。两者单位都为输入网络输出单位。输出单位为 `m/mm/cm` 时默认分别按 1 m、5 m 换算；其他单位不猜物理尺度，沿用原 `gap_max`，需要显式校准后再扩大。`gap_max` 旧字段仍接受。

## 串联附件覆盖证据

单框和批量入口从当前来源块定义及实例变换生成 `valves[].coverage_bounds`（六值 WCS 外框，网络输出单位）、`coverage_geometry`（实际变换闭合轮廓、源 POINT 候选及完整性）、`coverage_basis`、稳定的 `source_object_id` 及 `source_id`。缺定义、变换失败或存在无法解释的范围备注时不生成覆盖证明。注记按插入点计的备注会保留；不从块名猜尺寸。旧的点状阀件和有据 `connected_segment_ids` 接口仍可使用。

总断口超过普通搜索阈值时，须至少有两个不同实例沿管轴相连。WCS AABB 仅筛选，不能证明旋转附件覆盖：引擎对真实变换闭合多边形逐边求管轴截交并检查源点侧偏，按真实截交区间的并集核验首尾及连续覆盖。保留逐实例轮廓、区间、源点侧偏和来源。曲线、非闭合轮廓或缺源几何时保持未决；不能用外框投影、外框对角线或弦线代替实际轮廓。`accessory_coverage_tolerance` 默认等于吸附容差，不能大于 `snap_tolerance`；不得通过放大单阀附件半径弥补块间缺绘管线或端口侧偏。

源轮廓覆盖完整且源点约束相容时才形成 `automatic_serial_accessory_coverage_candidate` 拓扑桥，默认不补管长。真实截交仍有空段、源点偏轴或只有 AABB 时，只输出 `rejected_gap_candidates[]` 中的“串联附件连接待核候选”，列出总跨距、源轮廓区间、未覆盖区间与条件数量方案。只有外框时实际未覆盖长度为 `null`，外框空段另保存在 `envelope_uncovered_axis_intervals`，不冒充真实截交证明。此类候选进入裁决队列及复核摘要，不因未成桥而静默消失。

## DN 与数量是两个独立出口

唯一桥可以用于候选连通及条件 DN 传播，但不能把依赖候选连接的原已绘管段升级为规则主数。没有独立已绘连接路径时，受影响的 DN、阀件规格、管件规格和数量均限于方案暂估，并保存参与的 `A-GAP-*` 假设；自身直接种子及独立已绘链的原层级不降级。候选角色也单列 `role_assumption_ids`。

`metrics.raw_length` 始终为原已绘几何总长；`independent_drawn_length_summary` 及 `independent_dn_assignments` 是不依赖虚拟桥的分规格基线。`length_summary` 是包含条件 DN 的原已绘分层方案，依赖桥的原段长度通过 `conditional_drawn_segment_length` 单列，不能并入规则/确认主数。两套分层各自与同一原始几何总长守恒，互为替代、不可相加。DN 已赋值数另分独立与条件计数，不代表正式采用覆盖率。复核摘要先展示独立基线，再展示条件方案。

独立基线必须从不可变的原始 DN 种子、种子原层级及不含候选桥的连接重新计算，不能复制已经跨桥传播后的层级。局部只有同 DN 的方案种子时，该段、与其实际直连的无种子段及阀件规格仍为方案；采用这一局部路径不需要附加无关的桥假设。有独立规则/确定种子时才可保留相应独立层级，不把全部连通量统一降级。同 DN 多来源保留各自证据；真正借用跨桥来源时只引用实际足够路径及其桥假设，不能声称使用未列路径的远端强来源。

`bridge_scenarios` 的新增轴长上界和优选方案另列，不与已经绘出的原管段或替代方案重复相加。无阀块的共线短断口默认只形成方案暂估增量；已有项目规定方案不进主数时继续遵守。

已有的 `restore_omission` 是有明确图面长度依据的省略恢复，独立于 T25 自动候选：必须仍在原 `gap_max` 内，不能被默认共线搜索上限放宽。恢复量继续按本条图面证据和两端 DN 的实际层级计入恢复后汇总；两端规格独立闭合时可为规则推算，依赖候选桥获得的 DN 仍只能为方案。不同 DN 时保留 DN 待定的省略量，不猜规格分拆，并以 `connectivity_included=false` 保留待判记录而不接入连通、DN 传播或阀接管。在线附件占位仍阻断恢复。该独立图面数量依据不提升自动候选桥的拓扑层级，恢复后汇总应与重构总长守恒。

超出省略恢复阈值但有完整源轮廓的串联附件，仍可保留独立的 T25 候选及占位阻断诊断；`omission_within_gap_max=false` 禁止把这一较长搜索路径用于恢复量，原声明仍报告未匹配。

附件占位默认只补拓扑、不补净管长。普通 `restore_omission` 遇到附件仍阻断。当前项目有明确“不扣此类附件轴长”的计量依据时，可在该端点对的 `gap_classifications[]` 采用：

```json
{
  "a_segment": "LEFT", "a_end": "end", "b_segment": "RIGHT", "b_end": "start",
  "classification": "串联在线附件占位", "quantity_decision": "项目中心线不扣附件轴长",
  "quantity_action": "include_occupied_axis", "quantity_evidence_level": "inferred",
  "quantity_basis": "当前适用计量条款及其对象范围", "source_id": "EV-计量条款"
}
```

该动作还须已有完整串联覆盖及兼容 DN。只要连接仍是候选，该增加量仍为带桥假设的方案暂估，不能因计量条款为真而升级连接事实；`project_inclusive_accessory_axis_length` 与普通 `restored_omission_length` 分开。含附件轴长不能称净管切割长度。已绘量、恢复后工作量和替代方案不可再次相加。

批量入口按 `gap_classifications_by_frame[frame_id]`、`gap_exclusions_by_frame[frame_id]` 接收逐框声明，避免把一个图框的端点关系应用到其他图框。

## 来源保护与复核边界

适配器将原图、中性包、交换文件、识别配置、识别记录及引用证据路径传入 `protected_source_paths`，推算器保护本输入和这些来源。直接输入也可提供该数组，路径相对于输入 JSON；有模型识别记录时同时保护其 `ledger_path`。显式输出及生成的复核摘要均核对真实路径和文件身份；硬链接、符号链接或目录 junction 不能绕过保护。批量入口还拒绝在包含原始输入/引用证据的输出树内写结果。拒绝使用非零退出，不能用外层成功掩盖子入口失败。

程序检查只证明已编码几何、层级、来源保护与长度守恒；真实局部复验不代替整图工程量、人工复核、交叉行为复测或正式采用。
