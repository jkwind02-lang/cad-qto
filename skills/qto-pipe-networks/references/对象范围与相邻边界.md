# 对象范围与相邻边界

## 主计算链

本 Skill 的唯一主链是：管线中心线 → 系统与规格 → 标高与拓扑 → 管件及在线附件 → 随管道派生的支吊架和保温。对象归属按主要证据链判断，不按专业名称、最终单位或单个关键词判断。

## 本 Skill 负责

| 对象 | 处理范围 |
|---|---|
| 给水、热水、回水、排水、通气、雨水 | 管段、竖向、管件、在线阀门及与管网直接关联的附件 |
| 消火栓和喷淋管网 | 主管、支管、立管、下垂管、管件、阀门；喷头和箱体除外 |
| 暖通水和制冷剂 | 冷冻水、冷却水、采暖水、冷凝水、冷媒或制冷剂管道及在线附件 |
| 工艺及室外管网 | 按介质、压力等级、材质、管径和空间范围形成管网计算链 |
| 管道支吊架 | 能由已确认管道、设计图示、支吊架表或专项方案直接确定的部分 |
| 管道保温、防结露层 | 能由已确认管长、外径、厚度和项目计量口径直接确定的部分 |

普通阀门虽然通常按“个”计量，但与管道拓扑、连接口径和断口处理强关联，归本 Skill。管件、管道支吊架和管道保温同样跟随管道主要对象。

## 相邻 Skill 负责

| 对象 | 应归属 | 本 Skill 的边界 |
|---|---|---|
| 风管、风阀、法兰、风管支吊架和保温 | `qto-duct-air-systems` | 不因“管”字或同属暖通而纳入 |
| 电气导管、穿线管、桥架、电缆、电线、母线 | `qto-electrical-routes` | 按回路与路径计算，不属于流体管网 |
| 洁具、水泵、水箱、喷头、消火栓箱、末端设备 | `qto-components-points` | 本 Skill 只处理其连接管和在线阀门；设备实例不重复计数 |
| 检查井、阀门井、雨水口等独立构筑物或点位 | `qto-components-points` 或相应土建 Skill | 管段到井的边界仍由本 Skill记录 |
| 管沟开挖、回填和土方平衡 | `qto-earthwork-terrain` | 本 Skill 可输出管线路径和埋深证据，不计算土方 |
| 管沟、支墩、设备基础等混凝土构件 | `qto-concrete-formwork` 等 | 不因服务于管道而并入管道量 |
| 单价、报价、成本 | 不属于算量 Skill 体系 | 不套价、不补价、不形成合价 |

## 冲突与拆分

- “喷淋管网和喷头”：管段、管件、阀门归本 Skill；喷头归点位 Skill。
- “冷冻水管和送回风管”：水管归本 Skill；风管归风系统 Skill；保温和支吊架分别跟随各自主对象。
- “水泵房连接管、阀门、水泵和水箱”：连接管与在线阀门归本 Skill；泵、箱归点位 Skill。
- “综合支吊架承载水管、风管和桥架”：不得由本 Skill 独占。读取综合支吊架深化或专项方案；缺方案时保持证据不足。
- “全专业机电工程量”：应由目标体系的协调 Skill 拆分。本阶段若协调 Skill 尚未建立，明确列出需拆分能力，不伪装成全专业已完成。
- “管道工程量并套价”：只有管道算量范围可以独立、用户意图不受报价部分影响时继续算量；报价部分明确越界。

## 不明确请求

“把图里的管线都算一下”不能直接触发深度计算。先确认或从项目资料低成本判断：

1. 是流体管道、风管还是电气导管；
2. 哪个系统、楼栋、楼层或区域；
3. 哪个版本及哪些图纸类型；
4. 需要长度、规格、竖向、管件、阀门、支吊架还是保温。

无法唯一判断的决定性字段写“待确认”，不把未发现写成零。
