# 已识别管网的共线重合审查

本轮显式配置`overlap_review.enabled: true`，并给出适用阈值、单位及来源后，`infer_pipe_network.py`审查输入原路线的直线part，以及本轮实际生成的`topology_bridges`，结果写入`overlap_review`、`*_共线重合.csv`及复核摘要。未显式开启时为`NOT_ENABLED`，缺决定性参数或依据时为`PARAMETERS_REQUIRED`；两者均未搜索，`pairs`与数量为`null`，CSV和摘要明确未执行，不冒充零候选。原路线先于拓扑切分进入审查，同一多段线中往返重复的part也保留；不以切分后的原始线检查代替补连边检查。曲线part保留原几何并列`unsupported_geometry`，不能当作弦线查重或据此写零。

原路线的输入文件定位和全文件SHA在推算输出顶层`overlap_review_source_paths`（独立入口为`source_paths`）；逐part通过`source.input_reference`、`segment_id`和`part_index`引用，路径变化不改变同一几何的审查语义。

项目已有标签断口补连或其他已识别派生边时，通过`overlap_review.imported_edges`导入原始CSV证据。也可单独运行：

```text
python scripts/pipe_overlap_review.py --input 本轮审查输入.json --output 本轮共线审查.json
```

独立输入使用`schema_version: qto-pipe-overlap-request/1.0`、明确的`unit`和`segments`数组；原始管网推算输入也可使用。独立入口只审查输入原路线与导入边；本轮实际拓扑桥由`infer_pipe_network.py`传入。单框识别配置的`overlap_review`传入推算文件，导入文件路径按原识别配置所在目录解析并固化为绝对路径。批量入口各框如需共线审查，应在各框识别配置或推算输入中显式提供本框参数和依据；导入派生边时明确本框来源，不把整张原表默认灌入每框。

## 参数和空间含义

`unit`只按明确的`m`、`mm`或`cm`换算；`overlap_review.unit_source_ids`和`unit_basis`必须说明该单位的来源与适用范围。未知单位返回`UNIT_UNRESOLVED`，未搜索且数量保留空值，不默认米或毫米。启用时`overlap_review.parameters`须显式给出：

- `angle_tolerance_deg`：共线方向夹角容差，有限数值，0≤值<90度；
- `distance_tolerance`：共线垂距容差，非负有限值，使用本输入单位；
- `min_overlap`：最小重合长度，非负有限值，严格超过才出候选；
- `elevation_tolerance`：采用`elevation_mode: source_3d`时必须给出的标高差容差，非负有限值；
- `source_ids`和`basis`：本轮阈值的来源、适用对象与采用说明。

插件不提供角度、距离、最小重合或标高的通用工程阈值。既有项目的阈值只在有源项目配置及其适用范围中采用，不因曾用于实测就变成默认值。`elevation_mode`须显式选择：`source_3d`按真实三维来源及有据Z阈值检查；`plan_only`只适用真实二维来源，`elevation_tolerance`不适用且须省略或为`null`。`plan_only`遇三维边时保留`PARAMETERS_REQUIRED`，不忽略既有Z；原表只有二维端点时，不为凑参数编造Z阈值。启用示例仅展示结构，不提供可照抄的工程数值：

```text
overlap_review:
  enabled: true
  elevation_mode: source_3d 或 plan_only
  unit_source_ids: 本轮单位来源
  unit_basis: 单位说明及适用范围
  parameters:
    angle_tolerance_deg、distance_tolerance、min_overlap: 本轮有据数值
    elevation_tolerance: source_3d时为本轮有据数值；plan_only时不适用
    source_ids、basis: 阈值来源、对象范围和采用说明
```

原`geometry.parts`和桥边均按真实源坐标维度保留。拓扑内部补出的`z=0`不构成标高证据；源part只有二维端点时仍为二维，并列`plan_only_no_elevation_proof`。二维输入只证明平面候选；不同三维标高/方向、系统、`space_id`、`floor`、材质、规格或明确不同`physical_id`分列`separated`及原因，不合并。相同坐标不证明相同实物；缺楼层、空间和同物证据逐项列为不确定。平行实物可逐对`keep_both`并给证据。

## 固定CSV源行导入

`imported_edges`每项结构如下（字段名可按原CSV映射；不执行`producer`、脚本或命令）：

```json
{
  "source_path": "已识别边原表.csv",
  "source_sha256": "完整64位SHA256",
  "source_id": "EV-EDGE-TABLE",
  "format": "csv",
  "unit": "mm",
  "unit_source_ids": ["EV-UNIT-DECLARATION"],
  "unit_basis": "本源坐标单位的明确依据和适用范围",
  "columns": {
    "start": ["x1", "y1"], "end": ["x2", "y2"],
    "system": "system", "space_id": "drawing_space",
    "quantity_level": "level", "handle": "handle"
  },
  "rows": [{
    "row_index": 0, "action": "include", "edge_id": "IMPORTED-001",
    "edge_kind": "label_gap", "source_ids": ["EV-ROW-1"],
    "basis": "本轮确认的标签断口桥，原方案层级保留"
  }]
}
```

`rows`必须唯一、完整覆盖全部源数据行，首行索引为0；不参与审查的行也逐行写`action: exclude`或`unresolved`及依据。缺坐标、立管无端点或不能识别的行保留未决，不补零。`edge_kind`为`drawn`、`label_gap`、`derived`或`topology_bridge`。坐标只从通过SHA核验的源行读取；不接收覆盖源几何的替代坐标。完整原行、索引、SHA、原单位、换算、识别依据随结果保留，原行的楼层倍率、原方案层级等不能省略。可选列`floor`、`material`、`dn`、`physical_id`按源字段传递；未提供就保留未知。源文件和输出别名、硬链接重复、输出路径中的符号链接/reparse组件均在写入前检查。真实项目的源CSV、配置和单位证据保留项目工作区，不进插件Git。

`build_pipe_inference_input.py`在首次创建输出目录或写生成文件前，保留原输出路径检查reparse父链；将识别/审计文件、infer主输出、共线CSV及已有内容哈希摘要路径纳入原输入/输出互别名检查，并提前核验导入CSV的SHA、列、逐行处置及单位。决定性导入无效时直接拒绝，不先留下部分generated文件；未提供审查阈值本身则保留未执行/待核状态，不把缺参写成零。

## 逐对处置与数量边界

`overlap_review.resolutions`逐对使用输出的`edge_id`：

```json
{
  "pair": ["route:PIPE-A:0", "route:PIPE-B:0"],
  "action": "keep_both",
  "basis": "两根并行实物分别敷设",
  "source_ids": ["EV-PHYSICAL-PIPES"]
}
```

未处置及`pending`保持未决；`keep_both`原样保留。`drop_overlap`另须`drop_edge_id`及`same_object_evidence: {basis, source_ids}`，两边空间必须明确，异系统/标高/空间/实物不得扣减。只有近重合不能作为同物依据。多个处置对按重合区间并集核查原有覆盖，循环删空或局部失去全部表达时报告`DISPOSITION_CONFLICT`，保留处置提议并停止扣减方案。

处置只形成`deduplication_scenario.deductions`逐边区间方案，**不回写或扣减主网络原长度、已恢复断口、DN、阀门及原有分层方案**。补连边、实画段、导入派生边及原数量层级分别保留，不能把审查库存长度混加为项目工程量。需要采用扣减时，依据审查方案修订原对象选择或来源边，再运行原计算链；正式采用仍需项目依据。旧项目“已扣”记录不自动转为本轮`drop_overlap`。

真实案例验收逐对列原候选是否覆盖，同时完整列插件多出的候选及分层原因；不能因旧入口不产生补连边而豁免漏检。此项有限来源核对不代表整图识别、DWG单位核准或完整工程量验收。
