# 排水管道规则

## 范围

适用于污水、废水、雨水、通气、冷凝排水等重力或压力排水管段。地漏、洁具、雨水斗、检查井和提升设备作为点位对象另行归属；连接管仍由本 Skill 处理。

## 计算要点

- 污水、废水、雨水和通气分别建网，不因共用立管井或图层相近而合并。
- 斜管和有坡度管道优先使用三维中心线；只有水平投影与起止标高时，按可证明的水平长度和高差计算斜长，并记录公式。
- 平面立管符号只形成候选。立管长度必须由起止标高、跨层关系或一一对应系统图证明。
- 坡度文字只有在引线或区段边界唯一时才能赋给对应管段；不能按最近文字扩散到整网。
- 清扫口、检查口、伸缩节等是否作为在线附件由项目清单和计量条款裁定；图例实例不得计入平面实例数量。
- 检查井或雨水口等点位的中心位置可作为管段端点证据，但其本体数量不由本 Skill 重复统计。
- 洁具、地漏、雨水斗或设备的直接接口规格可约束末端连接管；仅按类型或常规最小管径反推时标为方案暂估。上游横干管、立管和主干管仍需结合下游负荷、系统图、坡度和变径节点。

## 缺失处理

缺少管底标高、坡度、系统图或跨层关系时，分别阻断斜长、竖向或规格进入正式量；已证实平面段、规则推算和可复算的多方案暂估分列输出，无法形成候选才为 `null`，未知不填零。

若当前项目明确采用 GB/T 50856-2024 清单口径，再读取 [现行计量标准摘要](现行计量标准摘要.md) 的 K.1 和 K.9 边界；不得用标准名称替代项目适用性判断。
