# 范围与对象边界

## 最小对象

最小对象是可唯一定位的墙段或二次构件。墙段至少带楼栋、楼层/区域、轴线或空间定位、材料、厚度、长度、高度、端部关系和来源版本；洞口必须以洞口实例及其与墙段的唯一映射表达。

## 唯一出口

| 对象 | 本 Skill | 相邻 Skill |
|---|---|---|
| 砌块/砖墙实体、墙垛 | 定位并输出净面积、净体积 | 面层不在此重复 |
| 构造柱、圈梁、过梁、压顶 | 建墙系对象及相交关系 | 混凝土/模板由 `qto-concrete-formwork` 唯一输出；钢筋由 `qto-rebar` 输出 |
| 门窗/设备洞口 | 消费已确认洞口并集扣减墙体 | 实例、编号、樘数由 `qto-components-points` |
| 墙面、防水、保温、饰面 | 只共享基层边界 | 数量由 `qto-surfaces-envelope` |
| 轻钢龙骨隔墙 | 不纳入砌体实体 | `qto-framing-supports` 计算骨架，面板归围护 |
| 穿墙套管 | 只处理其形成且已确认的墙洞扣减 | 套管实例跟随管网，预留洞位置不得重复计数 |

墙体毛边界、洞口实例和二次构件占位可以被多个 Skill 读取，但每个物理数量只能有一个出口；共享事实编号不等于共享成果项。

## 不得自动推断

- 平面两条线并不自动等于砌体墙两侧边界；
- 门窗编号并不自动证明洞口尺寸、标高和墙段归属；
- “到板底”“到梁底”必须结合构件标高和做法确认有效高度；
- 构造柱、圈梁和过梁不得按经验间距或门窗宽度自动生成；
- 零星墙带不得外推为整层完整墙体。
