# 常规计算逻辑

## 1. 墙段分解

按楼层/区域、材料、厚度、有效高度、轴线/房间边界、耐火或构造类别、版本拆为墙段。长度口径必须统一：中心线、轴线、净长或外边线不能混算。L/T/十字交接处先确定墙段所有权，使实体并集只覆盖一次。

## 2. 砌体墙

- 毛面积：`A_gross = L_effective × H_effective`。
- 洞口扣减：先对与该墙段相交的门窗、设备洞、预留洞形成二维并集 `A_open_union`，重叠部分只扣一次。
- 洞侧附加或不扣小洞：只按当前项目适用规则处理；未锁定规则时不默认阈值。
- 扣洞后面积：`A_after_openings = A_gross - A_open_union`。
- 毛体积：`V_after_openings = A_after_openings × t`。
- 砌体净体积：`V_net = V_after_openings - V_intersection_secondary - V_other_confirmed_deductions + V_confirmed_returns`。

有效高度通常由楼地面/基础顶到梁板底或项目明确控制标高形成。梁下斜墙、变高墙、阶梯基础上的墙体和不同厚度墙必须分段积分，不能用平均高度替代。

## 3. 二次构件

- 构造柱：对象体积参考 `Σ(A_section × H_effective) + 已明确马牙槎并入体积`；马牙槎是否并入、尺寸及模板接触面按项目规则闭合。
- 圈梁/系梁/压顶：参考 `Σ(A_section × L_effective)`；与构造柱、主体梁柱和墙体交接处按实体所有权去重。
- 过梁：参考 `Σ(A_section × L_member)`；`L_member` 必须来自详图/表格或明确的洞口净宽加两端支承长度，支承长度不得经验默认。
- 墙垛、门窗边柱、混凝土带：按其真实材质和构造确定在砌体还是二次混凝土对象中计量。

二次构件对象由本 Skill 定位。混凝土体积/模板面积输出若转给 `qto-concrete-formwork`，本 Skill 只保留对象与相交扣减，不再输出同一数值；钢筋转 `qto-rebar`。

## 4. 其他常规量

- 墙体长度可作为辅助中间量，不等于砌体量。
- 砌筑面积与体积按材料、厚度、墙类别分组；不同砌块、砖或砂浆做法不得静默合并。
- 拉结筋只在本 Skill 建墙段与锚固对象关系，长度/重量由钢筋 Skill 计算。
- 砌筑脚手、运输、损耗、砂浆消耗、单价和报价不进入物理量链。

## 5. 校核

检查 `A_open_union ≤ A_gross`、`V_net ≥ 0`、分墙段汇总与区域实体并集守恒、门窗实例数与洞口映射差异、二次构件占位与相邻 Skill 对账。任一差异无法解释时停止受影响净量。
