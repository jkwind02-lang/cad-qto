# 结果检查与输出

## 必查

- 墙段是否按材料、厚度、高度和范围分组；单位是否统一；
- 洞口是否为真实相交并集，是否重复来自平面、立面和门窗表；
- 构造柱、圈梁、过梁占位是否与墙体重复或漏扣；
- 墙体净面积、净体积、二次构件混凝土、模板、钢筋和门窗樘数是否分成果项；
- 数值是否逐项绑定来源和非候选的采用规则；
- 未知是否使用 `null`，真正零值是否完成覆盖复核；
- 局部成果名称是否避免“总量、合计、完整、全部”等措辞。

## 输出维度

砌体面积用 `m²`，体积用 `m³`；构件实例可用 `个`，但混凝土体积、模板面积和钢筋重量由相邻 Skill 分单位输出。不同材料、厚度、墙体类别、楼层/区域、口径和成熟状态不得静默合并。

建议成果链：墙段清单 → 洞口并集清单 → 二次构件占位清单 → 分材料净墙面积/体积 → 相邻 Skill 交接表 → 未决事项。

否定结论（“图上无”“未见”“不存在”等）是否都附检索记录，反向核对是否写明覆盖的图纸集合并覆盖所有可能含该类对象的图；没有检索记录的否定结论报待确认，不作为不计或判定清单有误的依据。格式见公共[通用成果字段与状态](../../_qto-shared-evidence/references/通用成果字段与状态.md)“否定结论与检索证据”。
