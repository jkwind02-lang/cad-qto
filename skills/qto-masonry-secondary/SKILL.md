# 砌体与二次结构算量

先按用户目标定阶段：范围/能力问答只读相关边界与能力披露；用户仅要求已有明细复核时做表内复核；原始资料算量执行下文。用户要求检验或改进独立算量能力、底稿仅作参照时，执行[原图独立算量实测](../_qto-shared-evidence/references/原图独立算量实测.md)，不得因已有底稿或历史结果改成表内复核。表内复核不核准原图，细则按需见 [分阶段读取](../_qto-shared-evidence/references/按任务阶段读取.md)。

原图算量先读取并执行 [人工思路识图与算量流程](../_qto-shared-evidence/references/人工思路识图与算量流程.md)。模型负责依据图纸识别工程对象并形成可复核工作量，工具负责取证和计算；人工复核与正式采用另列，不以“用户尚未逐对象核定”代替模型识图。

先读墙体材料表、平面和墙身详图，逐墙段确定厚高、洞口和二次构件；按真实相交关系扣减，再按区域回图核对墙段连续性与遗漏。

以“墙段身份—墙体边界—材料厚度—洞口并集—二次构件占位”为主线。当前整体为候选；只有事实闭合时才可形成参考复算，候选规则不得写成项目采用量。

## 先锁定边界

直接读取 [范围与对象边界](references/范围与对象边界.md)。

- 本 Skill 负责砌体墙实体及构造柱、圈梁、过梁、压顶等墙系对象的定位、归属和整体清单。
- 二次构件混凝土/模板只有一个数值出口：用户明确要求时交 `qto-concrete-formwork` 计算已定位对象；钢筋交 `qto-rebar`。
- 门窗洞口实例和樘数由 `qto-components-points` 建立；本 Skill 只消费已确认洞口并集作墙体扣减。
- 墙面、涂料、保温和板材面层交 `qto-surfaces-envelope`；轻钢龙骨隔墙交 `qto-framing-supports`。

## 执行

1. 锁定项目、楼栋、楼层/区域、墙体材料与厚度、图纸和变更版本、物理量/清单量/合同量口径。
2. 原始资料按 [资料提取与来源核对](../_qto-shared-evidence/references/按任务阶段读取.md#原始资料与计算) 选择相应公共资源；未进入提取阶段时不展开其他资料类型。
3. 读取 [计算与证据流程](references/计算与证据流程.md)、[常规计算逻辑](references/常规计算逻辑.md)、[专业规则与成熟状态](references/专业规则与成熟状态.md) 和公共 [推算分层协议](../_qto-shared-evidence/references/推算假定与发布分层协议.md)，为每条规则记录“采用/试用/不适用/证据不足”及成熟状态。未经真实案例升级的规则可形成推算/暂估，不静默进入正式量。
4. 为墙段、洞口并集、构造柱、圈梁、过梁和压顶分别建稳定编号；共享几何事实但保持各专业唯一数值出口。
5. 仅当长度、有效高度、厚度、洞口并集、相交扣减、材料分界和来源身份都闭合时，才按 `墙体净体积=(毛墙面积-洞口并集面积)×厚度-已确认占位体积` 复算。确定性核算可使用 `scripts/calculate_masonry_reference.py`，脚本不判断洞口归属、构造做法或计量规则。
6. 按 [结果检查与输出](references/结果检查与输出.md) 和公共 [通用成果字段与状态](../_qto-shared-evidence/references/通用成果字段与状态.md) 出具结果；读取 [案例与接入清单](references/案例与接入清单.md) 判断成熟度。

## 正式采用停止与局部分支继续

以下条件只阻断受影响结果进入正式量；墙段候选、常规二次构件方案和替代扣减继续输出，无法形成有意义候选才使用 `null`：

- 图纸、变更、墙身详图或材料做法版本冲突；
- 墙中心线/边线口径、有效高度、厚度或墙段连接未确认；
- 洞口与墙段不能唯一映射，重叠洞口未形成并集；
- 构造柱、圈梁、过梁、压顶与砌体的相交扣减未闭合；
- 清单或合同量请求缺适用标准、合同优先级或扣减口径；
- 局部墙带资料被要求代表整层或整栋完整砌体。

受影响结果用 `null` 和待确认/证据不足；安全独立的局部量可单列“部分计算”，不得填零或经验比例。

## 禁止

- 不按最近文字、颜色或图层名自动吸附墙厚、材料和洞口；
- 不把门窗表樘数直接当洞口扣减，未核对尺寸及墙段映射不得采用；
- 不把构造柱圈梁混凝土、模板和钢筋重复并入砌体体积；
- 不把墙面面积当砌体面积，不把报价清单量当物理量；
- 不调用旧 Skill、旧归档脚本或旧结果作为运行输入。

## HTML图面复核交付

原图算量形成对象明细后，默认按公共[HTML交互复核与批注](../_qto-shared-evidence/references/HTML交互复核与批注.md)生成可离线点选的复核页，支持问题分组、成员例外、结论与原因、保存和处理回执。沿用共享生成器，不在项目重写前端；收到意见后由本专业复算并更新采用状态，用户方法意见不自动等于数值确认。纯问答、无图表内复核及用户指定其他形态按实际范围处理。
