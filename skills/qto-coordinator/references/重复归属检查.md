# 重复归属检查

## 唯一出口矩阵

| 共享/易冲突对象 | 事实可共享 | 数量唯一出口 |
|---|---|---|
| 墙体边界与门窗洞口 | 砌体、围护、点位 | 门窗实例：点位；砌体净体积：砌体；面层净面积：围护 |
| 构造柱/圈梁/过梁 | 砌体定位、混凝土、钢筋 | 对象归属：砌体；混凝土模板：混凝土；钢筋：钢筋 |
| 桩、钢筋笼、承台 | 桩 ID 与接口标高 | 桩身/灌注：桩基；钢筋笼：钢筋；承台：混凝土模板 |
| 主体钢件与幕墙骨架 | 构件位置/接口 | 主体承重：钢结构；幕墙支承：骨架 |
| 风管/水管/设备 | 设备接口和系统号 | 风管：风系统；水管：管网；设备/风口：点位 |
| 喷淋管与喷头 | 系统拓扑端点 | 管网：管网；喷头：点位 |
| 桥架/电缆与末端点位 | 路径端点 ID | 线路/通道：电气；点位数量：点位 |
| 道路土方与结构层 | 路床交界面 | 土方：土方；结构层/铺装：道路 |
| 建筑表面与道路铺装 | 边界/标高 | 建筑面层：围护；室外道路场地：道路 |
| 专用/综合支吊架 | 设备管线接口 | 专用支架跟主对象；综合支架按批准方案唯一归组 |

## 检查步骤

1. 每个成果项生成“物理对象 ID + 数量类型 + 口径 + 范围 + 单位”复合键。
2. 相同复合键出现两个输出方即冲突；共享证据引用不算重复成果。
3. 同一物理对象不同数量类型可并存，例如墙体体积与墙面面积，但必须由不同名称、公式和单位明确区分。
4. 设计、模型、清单、合同、采购等互斥/对照口径不得相加。
5. 只有所有冲突被“唯一出口、对照不汇总或证据不足”裁决后，协调验收才通过。

## 单位隔离

仅在对象、范围、口径、单位和成熟状态均一致时形成小计。任何 `m+m²`、`m²+m³`、`kg+个` 或“综合总量”均禁止。
