# 业务专业与算量能力映射

本表用于初分，不替代项目范围和主要物理对象判断。

| 用户业务范围 | 通常需要的算量能力 |
|---|---|
| 给排水 | `qto-pipe-networks`；洁具、泵箱、井类增加 `qto-components-points`；管沟土方按范围增加 `qto-earthwork-terrain` |
| 暖通空调 | `qto-duct-air-systems`、`qto-pipe-networks`、`qto-components-points` |
| 消防 | 按对象选择 `qto-pipe-networks`、`qto-duct-air-systems`、`qto-electrical-routes`、`qto-components-points` |
| 强电/弱电/智能化 | `qto-electrical-routes`、`qto-components-points` |
| 主体结构 | `qto-earthwork-terrain`、`qto-piles-groundwork`、`qto-concrete-formwork`、`qto-rebar`、`qto-structural-steel`、`qto-masonry-secondary`，只取实际对象 |
| 建筑装修 | `qto-surfaces-envelope`、`qto-framing-supports`、`qto-masonry-secondary`、`qto-components-points` |
| 幕墙 | `qto-surfaces-envelope`、`qto-framing-supports`、`qto-components-points`；主体承重钢件另判 `qto-structural-steel` |
| 市政室外 | `qto-earthwork-terrain`、`qto-roads-siteworks`、`qto-pipe-networks`、`qto-components-points`，构筑物按混凝土/钢筋/砌体增加 |
| 洁净/工艺动力 | 按对象选择围护、龙骨、风管、管网、电气线路和设备点位 |

用户只要求一个业务专业时，只拆该业务专业必需能力，不顺带扩展相邻专业。出现“全部”“全套”也要先用图纸范围和合同责任确认其含义。
