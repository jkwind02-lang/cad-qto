# CAD基础读取

只取得来源图纸中的构件基础数据。用户仅要求读取时，完成读取、缺口说明和来源核对后交付，不进入专业算量、数量推导或报价流程。

## 执行

1. 确定原图、所需图页及输出业务目录。优先复用身份可核验、仍保留原生载荷的DXF；只有DWG时由公共导出器在工作副本上转换。不要先转T3或炸开对象，以免失去专用参数。
2. 调用[公共基础读取入口](../_qto-shared-evidence/scripts/read_cad_basic.py)：

   `python read_cad_basic.py --source-dxf <交换副本.dxf> --source-dwg <原图.dwg> --output-dir <新成果目录>`

   只有DWG时省略`--source-dxf`；只有DXF时省略`--source-dwg`。运行脚本路径以当前插件目录为准，不依赖历史任务目录。DWG转换使用本机已有CAD引擎；解析器不需要天正运行模块。
3. 查看`CAD基础读取回执.json`、`CAD读取覆盖与待补读.json`和`CAD原生构件基础数据.json`。普通CAD事实在中性布局/块定义图元文件中。按当前[基础读取输出说明](../_qto-shared-evidence/references/CAD基础读取与天正原生字段.md)解释状态与字段。
4. 核对图中活动实例及其插入路径，分别报告活动实例、未使用定义和配置容器。使用`instances`中的变换后几何；不要把块定义坐标当成图中坐标，也不要把附属曲线另建为独立构件。

## 交付判断

- 分开说明原载荷已保留、参数已解码、原生几何字段已读出和几何语义已核明。专用序列化完整要求数字、文字和引用表全部对齐，不能仅凭保留字节判成功。
- `PARTIAL`、未知类别/版本、缺失引用、无效坐标及转换影响应明确定位。保留其他已读取数据，未知值不写成零，不猜字段的工程名称。
- 保持图纸原单位；单位未声明时不默认毫米。原生接口方向、引用、文字格式和图块图元保持来源值。
- 回执中的模块审计只对应实际读取进程；审计不可用时如实说明，不宣称已证明未加载模块。
- 本入口不调用算量器，也不按图例、工程范围或计量规则筛掉基础对象。用户另行要求算量时，再交给相应专业入口使用这些事实。

## 插件问题

发现插件本身的问题按[插件问题登记](../_qto-shared-evidence/references/插件问题登记.md)处理，不修改插件文件。
