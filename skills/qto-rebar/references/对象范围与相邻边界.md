# 对象范围与相邻边界

## 本 Skill 的对象

以混凝土构件或砌体二次构件中的钢筋组为最小业务对象。钢筋组至少由构件身份、位置、钢筋类别、级别、直径、根数规则、展开规则和来源版本共同确定。

纳入：

- 独立基础、条形基础、筏板、承台、基础梁中的普通钢筋；
- 柱、墙、梁、板、楼梯和后浇区中的纵筋、分布筋、箍筋、拉筋、负筋、附加筋、构造筋；
- 焊接钢筋网片和已明确的成品钢筋网；
- 套筒、机械连接、焊接接头及搭接接头的物理数量或相应钢筋长度影响；
- 设计或批准施工方案明确的马凳、架立、定位等措施钢筋。

## 相邻能力出口

| 对象 | 唯一主出口 | 本 Skill 的关系 |
|---|---|---|
| 混凝土实体、模板接触面 | `qto-concrete-formwork` | 只接收已确认构件尺寸或相交边界，不重复算混凝土模板 |
| 钢柱梁、型钢、节点板、锚栓、栓钉 | `qto-structural-steel` | 不因材质为钢而纳入钢筋 |
| 砌块墙、构造柱、圈梁、过梁对象 | `qto-masonry-secondary` | 墙系对象和归属先确认；已定位钢筋才转本 Skill |
| 桩体、地基处理、成孔 | `qto-piles-groundwork` | 桩身钢筋笼可由本 Skill承接，但桩体数量和桩长来源由桩基能力闭合 |
| 预制构件成品数量 | `qto-components-points` | 预制本体成品统计不展开为现场钢筋；现场后浇钢筋可纳入 |
| 预应力筋、锚具、波纹管、压浆 | 本 Skill 专项候选分支 | 未有代表性案例前不以普通钢筋算法替代 |
| 单价、报价、成本、采购 | 计价或采购能力 | 本 Skill只提供明确口径的工程量或参考量 |

## 混合任务的拆分

- “基础混凝土、模板和全部钢筋”拆成混凝土模板链与钢筋链，分别输出 `m³ / m² / 根 / m / kg`。
- “型钢混凝土柱”拆成钢骨、混凝土模板和钢筋三条唯一数值链。
- “砌体墙及构造柱圈梁钢筋”先由砌体能力锁定墙系构件，再由本 Skill计算已定位钢筋。
- “整栋全专业”只处理钢筋子账；没有协调 Skill 时不得冒充全专业总量。

## 不因名称相似而触发

钢筋混凝土管、钢丝网抹灰、金属栏杆、钢制门、结构钢筋桁架楼承板的钢板部分、钢筋价格或钢筋强度验算，均不能仅因出现“钢筋”二字就进入本 Skill。对象用途和用户要的输出必须同时匹配。
