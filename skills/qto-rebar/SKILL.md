# 钢筋算量

先按用户目标定阶段：范围/能力问答只读相关边界与能力披露；用户仅要求已有明细复核时做表内复核；原始资料算量执行下文。用户要求检验或改进独立算量能力、底稿仅作参照时，执行[原图独立算量实测](../_qto-shared-evidence/references/原图独立算量实测.md)，不得因已有底稿或历史结果改成表内复核。表内复核不核准原图，细则按需见 [分阶段读取](../_qto-shared-evidence/references/按任务阶段读取.md)。

原图算量先读取并执行 [人工思路识图与算量流程](../_qto-shared-evidence/references/人工思路识图与算量流程.md)。模型运用图文理解与工程知识，自主选择取证、判断和计算方法，生成有依据的专业输入及可复核工作量；原生工具负责精确取证和计算。人工方法是可按问题选用的策略，执行顺序可调整；普通识图不等待用户逐对象核定，正式采用另列。

读结构总说明、平法标注和适用节点，按构件逐组识别纵筋、箍筋与附加筋。把“根数、展开长度已明确”当作模型需要主动求解的工程问题：自主查找相关图种、选择证据、解释构造并编制计算输入，不等待用户先给出根数或下料长度。程序核算模型给出的排布与尺寸，模型再用图纸关系解释差异。

以“构件身份 + 钢筋组身份 + 配筋位置 + 级别直径 + 展开与连接规则”为主线。正式采用量须有已闭合的根数、展开长度及适用依据；仅有间距、外形或图集名称时，按推算协议保留事实和显式假定的候选，不能形成有意义候选才输出 `null`。

## 先判定对象边界

直接读取 [对象范围与相邻边界](references/对象范围与相邻边界.md)。

- 纳入基础、柱、墙、梁、板、楼梯及后浇区中的普通钢筋、焊接网片、箍筋、拉筋、附加筋、构造筋和明确的措施钢筋。
- 钢筋机械连接、焊接接头按物理实例单列；连接引起的搭接、锚固或接头错开仍在本 Skill 的钢筋组链内处理。
- 型钢、钢柱梁、钢板、柱脚板、地脚锚栓和栓钉交给 `qto-structural-steel`；混凝土和模板交给 `qto-concrete-formwork`。
- 砌体拉结筋、构造柱和圈梁先由 `qto-masonry-secondary` 确认墙系对象与归属；其中已定位的钢筋量再由本 Skill 计算，保持唯一数值出口。
- 预应力筋、锚具、波纹管和压浆作为专项候选分支；未形成代表性案例前，不用普通钢筋算法代替。
- 单价、报价、损耗率和采购重量不在本 Skill 的工程量采用链；用户明确要求比较时只能另列参考口径。

## 执行顺序

### 1. 锁定范围、来源和结果口径

读取 [图纸与资料范围筛选](../_qto-shared-evidence/references/图纸与资料范围筛选.md)，至少锁定项目、楼栋、楼层或区域、构件类别、图纸及变更版本、采用图集版本、材料级别、输出维度和计量口径。

项目设计、图集、地区、合同和标准规则的采用顺序先按公共 [现行规则来源选择门](../_qto-shared-evidence/references/现行规则来源选择门.md) 判断；图集版本、节点页或项目选用条件未闭合时，受影响正式量保持未决；有依据的替代节点或构造方案按推算协议另列。

先区分：

- `physical_design`：按设计和平法构造形成的钢筋物理根数、展开长度及理论重量；
- `cutting_schedule`：已核定翻样或钢筋表中的下料根数、单根展开长度和汇总重量；
- `standard_boq`：适用工程量清单计量标准闭合后的清单量；
- `project_contract`：合同、签证或结算规则明确后的采用量；
- `procurement_reference`：定尺、损耗、余料利用或采购包装形成的参考重量。

不同口径可以互相校核，但不得相互替换或相加。钢筋根数、长度、重量和接头数量也必须分单位输出。

### 2. 核对资料身份和中性事实

原始资料按 [资料提取与来源核对](../_qto-shared-evidence/references/按任务阶段读取.md#原始资料与计算) 选择相应公共资源；未进入提取阶段时不展开其他资料类型。

缓存只能提供图元、文字、表格、坐标和来源身份等中性事实。空间邻近不能自动证明标注归属；同名图纸、缓存元数据和实体流必须通过哈希、单位、模式版本与逐行守恒闭合。

### 3. 选择直接专业分支

- 构件、钢筋组、配筋位置、标注归属与唯一身份：[钢筋识别与构件配筋规则](references/钢筋识别与构件配筋规则.md)
- 中心线展开、弯折、弯钩、锚固、搭接和节点：[展开长度锚固搭接与节点规则](references/展开长度锚固搭接与节点规则.md)
- 根数、理论单位质量、接头、网片和措施钢筋：[根数理论重量连接与措施规则](references/根数理论重量连接与措施规则.md)
- 清单或合同数量请求：[现行标准与计量口径摘要](references/现行标准与计量口径摘要.md)

再读取 [规则清单与成熟状态](references/规则清单与成熟状态.md) 和公共 [推算分层协议](../_qto-shared-evidence/references/推算假定与发布分层协议.md)，按本次对象核对相关规则及状态；候选、试运行和正式采用保持分层，历史提升依据仅在追溯时展开。

当前只有“根数与单根展开长度已明确的钢筋表/已解析直筋，按理论单位质量复算根数、总长度和重量”达到局部试运行。由平法标注自动推根数、锚固搭接、节点附加筋、措施筋、预应力及完整清单归组仍为候选。

明确首末钢筋中心或实际中心位置后，可在原计算器内用 `count_derivation` 求根数；这只增加算术辅助，不替模型选择首末根规则，也不提高上述专业规则成熟度。

### 4. 主动求解钢筋组并计算

读取 [钢筋识别与构件配筋规则](references/钢筋识别与构件配筋规则.md) 中的短例和 [计算与证据流程](references/计算与证据流程.md)。按当前图纸中最有区分力的线索选择推理策略，无须固定先后顺序：

- 标注明确时，从构件编号、引线及作用范围拆出级别、直径、方向、层位和分区；原位标注只覆盖它实际改变的字段，再找剖面与节点解释首末位置和端部做法。
- 几何与支承关系明确时，先解尺寸基准与构件范围，再沿钢筋中心线追踪主体段和端部段。轴线、构件表面和钢筋中心是不同基准，不能只因数值接近而混用；按需复用共享尺寸指向复核。
- 节点或钢筋表信息更完整时，从其构件、位置和适用编号反向寻找实际实例；节点详图定义构造，不按详图画了几根就直接扩大实际数量。

选择后主动寻找能推翻当前解释的证据，例如相邻原位标注、另一层配筋、洞口、加密区边界或不同端部节点。解释变化时修改相关输入，不用换一个根数来消除算量差额。无法消除的真实歧义可保留有据方案，不能把所有对象统一停给用户。

由模型编制 `scripts/calculate_rebar_items.py` 的输入：采用量保留原证据要求；有实际来源的模型工作解释用 `adoption_role=reference` 与 `working_basis`，候选规则用 `decision=trial`，成熟状态保持原值。根数可来自明确计数、已解释的首末中心和等间距、或实际中心位置列表；由程序计算根数及总长、重量，不能模型口算后回填合计。输入格式及完整钢筋组短例见 [钢筋计算清单格式](references/钢筋计算清单格式.md)。

展开长度需能表达为已求得的中心线展开长度或直段加有依据的逐项增量；复杂弯曲和节点公式由模型据实际选用页准备可复算推导。当前脚本不选择图集页，不推定锚固、搭接和弯曲调整。缺页且没有可说明的替代依据时，相应长度、重量保持 `null`；已独立闭合的根数仍可按计数出口计算，不能用零代替缺失长度。

同一钢筋组的根数、长度、重量和接头分别输出；构件、方向、层位、直径或口径不同则分别处理。套筒、焊接和搭接按真实连接方式避免重复增量；措施筋的有据未批准方案仅列工作参考。小计仅合并同单位、同口径、同采用角色且不重复的实际钢筋组。

### 5. 检查并形成成果

读取 [证据引用要求](../_qto-shared-evidence/references/证据引用要求.md)、[通用成果字段与状态](../_qto-shared-evidence/references/通用成果字段与状态.md) 和 [结果检查与输出](references/结果检查与输出.md)。

- 每条结果包含对象范围、钢筋组、数量种类、数值或 `null`、单位、公式、采用口径、来源、规则、状态和未决事项。
- 根数用 `根`，长度用 `m`，理论重量用 `kg` 或 `t`，连接件用 `个/套`；不得拼接为一个单位字段。
- `reference` 或 `procurement_reference` 不得进入项目采用小计。
- 同一物理钢筋组的设计量、翻样量、模型量和合同量属于互斥或对照口径，不得相加。
- 使用候选平法规则时不得输出采用数值；试运行结果必须显式标识。
- 缺根数、展开长度、节点选用、变更适用范围或完整覆盖时，先按同编号构件、集中标注、通用节点和可复算构造方案形成推算/暂估；无法形成有意义候选才为 `null`，不得用零、隐藏经验系数或其他构件比例补齐。

先运行公共最小成果验证，再用 `scripts/validate_rebar_result.py` 对清单、成果、计算证据和明细做绑定回放。结构和脚本通过只证明已编码不变量，不代表平法专业规则已正式核准。

## 正式采用停止与局部分支继续

以下条件只阻断受影响结果进入正式量；已确认钢筋组、节点候选、规则展开和多方案继续输出，无法形成有意义候选才使用 `null`：

下列情况按上述数量分层处理，不阻断有依据的候选方案；安全且独立的部分继续：

- 图纸、变更、平法图集、节点详图或钢筋表版本冲突且无法裁决；
- CAD 单位、比例、缓存身份或标注与对象的唯一归属未确认；
- 只有间距标注，首末根位置、边距、加密区、截断区或洞口影响会改变根数；
- 构件净尺寸、保护层、弯折位置、锚固、搭接、节点伸入或缩短规则缺失；
- 钢筋级别、直径、单位质量依据或钢筋表列含义不能唯一确认；
- 同一钢筋组可能同时来自集中标注、原位标注、详图和钢筋表，覆盖关系未闭合；
- 套筒、焊接、搭接或措施筋依赖设计、翻样或批准方案，但相应事实未提供；
- 要求清单、合同或结算量，但适用标准、合同优先级或归组规则未确认；
- 真实案例暴露会改变数量的节点遗漏、错误归属、双算或来源身份问题。

## 禁止事项

- 不读取、导入或调用旧 Skill、旧归档、旧项目计算脚本或旧结果作为运行输入。
- 不把孤立的 `Φd@s` 直接换成根数；取得首末位置或排布依据后由模型解释并交程序求值，不用最近文字、同层同色或经验吸附代替标注归属。
- 不以构件外轮廓长度、轴线长度或净跨直接冒充钢筋中心线展开长度。
- 不默认保护层、锚固、搭接、弯钩、弯曲调整、定尺、损耗、接头形式或钢筋级别。
- 不把钢筋表与图上同一批钢筋重复累加，不把搭接长度与接头数量重复计入重量链。
- 不按混凝土体积、建筑面积、含钢率或历史项目比例补钢筋量。
- 不把钢筋重量并入结构钢吨位，不把报价数量、采购重量或损耗量写成设计物理量。
- 不建立统一规则引擎、跨专业状态机、报价或成本模块。

## HTML图面复核交付

原图算量形成对象明细后，默认按公共[HTML交互复核与批注](../_qto-shared-evidence/references/HTML交互复核与批注.md)生成可离线点选的复核页，支持问题分组、成员例外、结论与原因、保存和处理回执。沿用共享生成器，不在项目重写前端；收到意见后由本专业复算并更新采用状态，用户方法意见不自动等于数值确认。纯问答、无图表内复核及用户指定其他形态按实际范围处理。

## 长任务持续执行

需要跨会话接续、并行合并或复杂修改依赖时，按共享[项目作业台账与持续执行](../_qto-shared-evidence/references/项目作业台账与持续执行.md)建立或恢复本任务；普通局部算量可直接调用专业工具。本专业继续主责识图、规则解释和计算，按[各专业持续算量执行路径](../_qto-shared-evidence/references/各专业持续算量执行路径.md)选择合适切入点、处理同族及例外。采用执行器时由模型调整任务并用 `next` 接续；任务文件不代替自主识图和真实计算。

物理对象与应计量项分开登记，结果引用本次原生文件及对象身份；复核视图从同一结果索引绑定。当前任务的有效检查点可恢复，图纸、规则或输入变化则沿依赖重算；独立复测使用新任务身份并隔离旧结果。程序完成不替代专业复核及正式采用。
