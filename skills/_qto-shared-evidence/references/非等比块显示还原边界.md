# 非等比块中的拟合样条与多行文字显示

适用脚本：`scripts/qto_dxf_background.py`。本说明针对经交换 DXF 重建的复核页背景，不产生或修订工程量、测量依据和人工审批。

## 原定义与累计矩阵

- 只有拟合点而无控制点的 SPLINE，先按原始块定义建立曲线，再按 INSERT 的完整累计矩阵变换并在图纸单位容差内离散；不先变换拟合点后重新插值。原定义里的端部切向保留。水平曲线只考察其 XY 平面；带空间拟合点或空间端部切向时同时考察 Z 方向缩放。
- MTEXT 先在原定义里确定各行锚点与文字方向，再施加累计矩阵。存在 `text_direction` 时按该方向处理，优先于同时保留的 `rotation`；MTEXT 插入点和方向属于块定义坐标下的 WCS，不能套用 TEXT 的 OCS 插入点规则。原定义的字高配合 `text_axes` 表达变换后的基线和向上方向。
- 累计矩阵保留各层块的基点、插入点、旋转、带符号缩放和 OCS。非等比缩放、嵌套旋转形成的剪切、镜像不能由最终角度与比例代替。
- 已有仿射丢失检测继续生效；此外，包含上述目标且累计变换不能保持其平面相似形的块走原定义路径。等比正常对照仍沿用既有路径。相关顶层块不使用炸开后的不可靠外包框预筛选，而由最终图元检查图页范围。

## 阵列与未显示边界

- 原定义路径中的 MINSERT 先逐元素展开原始阵列，再与父矩阵相乘。阵列间距按原 INSERT 的 OCS 和旋转确定，不先受该 INSERT 自身比例缩放；父级变换仍正常施加。零间距导致的重合元素沿用 ezdxf 的唯一位置语义。展开失败或元素数量不足时不输出不完整阵列，显式记为 `proxy`，须回原图。
- 本轮新增路由覆盖包含目标 SPLINE/MTEXT 的 MINSERT，以及已有仿射丢失路径中的 MINSERT；没有本轮目标、也未丢失仿射的其他普通阵列不借此声明完整支持。符号核对和量算计数没有修改。
- 原定义路径不实现 XCLIP 裁切。启用裁切的 INSERT 或无法可靠读取裁切状态的 INSERT 不输出未裁切外观，显式记为 `proxy`，须回原图；缺省位置为未知，避免插入点在图页外时告警被过滤。禁用的裁切不阻止正常绘制。普通路径的既有裁切问题仍需单独跟踪。
- 缺失块、超深嵌套等继续按原定义路径已有的 `xref_missing` / `proxy` 边界处理；隐藏层及大块层白名单仍适用。未知或未显示不是零工程量。

## 验证和近似排版

匿名测试从原始 SPLINE 构造工具求曲线采样，并独立累乘原始 INSERT 矩阵；MTEXT 用原方向与法向推导行轴和锚点，不采用炸开结果作为正确答案。覆盖单层及多层非等比、旋转、镜像、倾斜 OCS、阵列和合法等比对照。

MTEXT 仍采用现有纯文本逐行近似：行步长为字高 × 1.667 × 行距因子，保留显式换行和空行占位，按上/中/下锚点计算。字体替换、行内格式、自动折行、列、精确原生字形排版和遮挡不承诺与原生 CAD 一致。数学几何与离线绘图检查不等于真实 DWG、浏览器或原生 CAD 的视觉验收；原生 CAD 尚未验收。
