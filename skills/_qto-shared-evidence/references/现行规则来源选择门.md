# 现行规则来源选择门

本文件只规定规则来源的选择与证据门，不提供任何专业公式。

## 优先级

1. 用户当前明确指令与已确认任务范围；
2. 当前项目合同、补充协议、经批准清单说明及其优先级条款；
3. 当前有效设计图纸、设计说明、变更、会审、经批准深化/施工方案及厂家成套边界；
4. 项目所在地、项目类型和计价阶段适用的现行国家、行业、地方工程量计算或计量标准；
5. 现行设计/施工/验收标准和标准图集，仅用于其明确覆盖的构造事实；
6. 经复核的项目实测、施工记录、翻样/加工表或模型明细；
7. 常规公式和历史经验只作候选参考，不能越过以上来源形成项目采用量。

## 状态核验

- 国家标准号、名称、状态、发布日期、实施日期和替代关系在使用当次通过全国标准信息公共服务平台核验：<https://std.samr.gov.cn/>。
- 住房城乡建设领域国家/行业标准公告、局部修订和实施日期通过住房城乡建设部官方公开渠道核验：<https://www.mohurd.gov.cn/gongkai/zc/wjk/>。
- 地方规则必须使用项目所在地主管部门或地方标准官方平台；第三方网页、培训课件和软件内置表只作检索线索。
- 只写“按规范”不构成来源。运行清单必须记录标准号/文件名、版本/日期、适用章节或条款、获取位置和本次适用结论。

## 冲突处理

项目合同、清单、设计、地方规则与通用标准冲突时，不按经验自动排序。记录冲突双方、影响对象和所需裁决；受影响结果保持 `null`。物理设计参考量可以独立保留，但不得改名为清单量或合同采用量。
