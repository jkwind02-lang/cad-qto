# 符号普查与有据处置

本接口在基础读取之后使用，不改变基础图元。适用于阀件、风阀等符号的块型普查、不同块名的同形候选、同行图例文字对照，以及管道层散线符号的逐对象处置。形状、块名、图层和图例同行关系都不直接确定专业类型、规格、数量或“图上无”。

## 稳定入口

```powershell
python skills/_qto-shared-evidence/scripts/census_cad_symbols.py --request 普查请求.json --output 符号普查.json
```

退出码：`0` 为指定布局普查完成；`3` 为已输出但存在读取或展开限制；`2` 为输入、来源、范围或证据非法。`0` 也不是实物数量、类型否定检索或工程量验收。输出包含每一已读布局对象和可展开实例的处置出口，不完整对象仍保留；不能展开的阵列保留容器和限制，不伪装为一个实物实例。

写输出前按规范化路径和实际文件身份双重核对所有受保护输入，包括原图、交换副本、清单、各中性文件、请求和图面证据。输出若为这些输入的符号链接或硬链接别名，同样返回 `2` 并保留输入字节；普通新输出及已有正常报告可正常写入。

## 请求 qto-symbol-census-request/1.0

```json
{
  "schema_version": "qto-symbol-census-request/1.0",
  "sources": [{
    "source_id": "SOURCE-A",
    "manifest": {"path": "中性清单.json", "sha256": "实际清单SHA256"},
    "layouts": ["Model"]
  }],
  "connectivity_tolerance": 0.001,
  "legends": [{
    "source_id": "SOURCE-A", "layout": "Model",
    "bounds": [0, 0, 100, 100],
    "row_tolerance": 0.1, "max_left_distance": 10
  }],
  "evidence": [],
  "object_dispositions": []
}
```

所有坐标和连接容差均使用中性记录的原始绘图单位，跨源签名归一化不证明实际尺寸相同。`sources` 与 `layouts` 必须显式列出，不接受通配范围。清单、原图、交换副本、中性流必须仍存在且匹配哈希；记录来源、实体身份、块定义清单和已声明数量相互核验。相对清单路径相对于请求文件；清单内相对文件路径相对于清单。

块变换复用 `qto_cad_geometry`，实例采用既有 `CADINST-根对象/块名/定义对象` 路径。源标识、源图哈希、清单哈希、定义对象、实例路径和外参缓存链共同保留。缺块、循环、深度上限、缺阵列位置参数、动态求值未核验和外参身份未核验保留限制。非等比或剪切变换的可读几何仍保留，但不作相似变换的同形签名。未放置定义单列，不当作图上实例或零数量证明。

逐对象还独立检查原生未支持、需重新取证、完整参数曲线缺失及全部退化为零的几何限制，并将后代的限制传至上层 INSERT。即使上游清单汇总误标 PASS，这些对象仍使普查保持 PARTIAL，且不能据其快照认领或排除。其他完整对象仍可正常形成候选并作显式处置。采样规模上限或签名算法的保守限制单列在 shape 中，不自动等同于原始几何缺失；已有完整几何的空块定义也不当作缺块。

自动连接组仅合并同一布局、同层、端点在容差内的顶层曲线，圆弧保留完整参数。组过大、曲线不可用或无法分组时仍保留原对象。签名使用图元种类、相对长度与归一化采样点间距，可对照旋转、平移、等比缩放和镜像；几何碰撞和采样误差仍可能存在，结果永远是候选。单根直管、真弯管、单个圆弧和未匹配散线都不自动排除。

`block_instance_groups` 按源、布局、块名保存全部 INSERT 对象清单及记录数；`quantity_count` 留空，因为阵列、容器和原生状态不能由记录数直接换算成实物量。`source_definition_records` 单列每一输入定义对象；指定布局以外的原始对象逐条记为 `outside_requested_layouts`。`signature_groups` 保存完整同形候选集合，各 shape 中的 `same_shape_candidates` 仅为最多8条预览，须按 `same_shape_candidate_group/count` 回查完整集合，不能把预览当作全部普查结果。

每个图例范围内，文字与左侧同排所有可能块均输出来源对象和快照哈希；多个可能符号为 `ambiguous`，没有符号为 `unpaired`，唯一配对也只为 `candidate_pair`。同形对应不同文字（含不同规格文字）保留全部候选并标记 `legend_conflict`，不选定一项覆盖其他项。文字不解析为正式阀型或DN。

## 显式认领和排除

先运行无处置普查，从 `objects` 取得当前 `source_id/object_id/row_sha256`。每条证据引用一个真实的当前对象；每条处置只针对一个对象。不得以整层、块名或签名替代对象清单。

```json
{
  "evidence": [{
    "evidence_id": "EV-1", "source_id": "SOURCE-A", "object_id": "CAD-10",
    "row_sha256": "当前objects中的快照哈希",
    "kind": "cad_property", "basis": "对象及其同行图例已核对，见具体定位"
  }],
  "object_dispositions": [{
    "source_id": "SOURCE-A", "object_id": "CAD-10", "row_sha256": "同一快照哈希",
    "decision": "exclude", "professional_owner": "qto-pipe-networks",
    "evidence_ids": ["EV-1"], "recognized_by": "实际识别者",
    "recognized_at": "实际识别时间", "basis": "本对象为何是符号轮廓",
    "scope_basis": "适用布局及对象范围", "identity_basis": "原图和定义及实例路径",
    "cross_check": "实际进行的图面或属性核对"
  }]
}
```

证据 `kind` 为 `cad_property`、`cross_view` 或 `drawing_view`；图面证据还须提供 `view:{path,sha256}`。处置必须引用本对象证据，跨图图例等其他证据可追加。`claim` 只表明专业归属，`exclude` 只表明当前专业的明确排除；都输出为 `adoption_scope=working/review_status=unreviewed/decision_origin=model`，不构成人工审批。源对象本身不完整时拒绝认领或排除。未处置对象继续 `pending`，不写零、不推导“无该类型”。

## 管道入口接入

在单入口 profile 或批入口 mapping 中增加：

```json
{"symbol_census_report": {"path": "符号普查.json", "sha256": "实际报告SHA256"}}
```

报告相对路径以CAD清单目录为基准。仅支持 `--cad-manifest`，不接受脱离原图清单的裸中性流。消费前按报告绑定的请求，从当前原图、交换文件、中性流和实际证据重新生成普查并逐内容核对；自报哈希本身不是批准依据。来源或证据过期、对象越界、身份不符、改报告后重算其哈希均失败。

逐曲线排除还在实际消费位置比对完整的当前来源行快照，包括参数几何、端点、长度、图层、变换和实例身份。逐框预扫描索引是缓存；即使篡改同ID对象后重算索引哈希，也不能续用原曲线的旧排除凭据。比对发生在路线清理、单位换算之前；合法索引行与正常展开行须保持相同的来源快照。仅属于 INSERT 的范围包围盒注记不作为曲线排除证据。

管道只使用明确归属 `qto-pipe-networks` 的逐曲线 `exclude`；对单个 INSERT 的专业所有权继续用已有裁决接口，不能借此隐式吞并后代。候选只附到逐对象处置记录，保留原管段选择和计量出口。批入口保留被排除对象在逐框中性流中，让单入口输出明确处置；未归框对象的有据排除单列计数。旧配置未提供该字段时行为不变。

`type_absence_proven` 和 `quantity_acceptance_proven` 固定为 false。本接口完成共享形状取证、候选和显式处置机制；真实DWG完整读取、阀型或风阀专业认定、原项目复跑与采用量须另行核对。
