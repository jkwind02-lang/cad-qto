# 无坐标单位声明时的几何单位推定

原有 `unit.declaration` 仍引用原图真实说明。无适用坐标单位声明时，可另走 `geometry_evidence`；不得伪造说明、把材料/标高单位当坐标单位，或覆盖非零 INSUNITS。

`scripts/qto_geometric_unit_evidence.py` 为通用原源核验器，不计算专业工程量。它重开已验 SHA 的 DXF；请求只选择真实句柄及用途，自填幅面两数、跨度或比例不是凭据。

## 成熟范围与证据含义

- 当前 Model 外框为同一 XY 平面内的一条闭合矩形 LWPOLYLINE 或四条 LINE。支持 XY 等比、旋转/XY镜像、非阵列的真实 INSERT 链并检查归属与变换；不支持非等比、非XY、Z镜像或阵列。标准幅面核对使用真实矩形四边长度，不用旋转后的 WCS 包围盒边长；消费 scope 的四角须均在真实矩形内部。原外框、图签比例、图名、尺寸及其 INSERT 链须可见；图层关闭/冻结、隐藏源对象和注释性尺寸不得作当前页尺度证据。原尺寸渲染文字也须可见，不因匿名渲染块有数值便自动准入。
- 图签源文字必须唯一 `1:N`。代码按 ISO 216 A0–A4 标准两边逐轴核对外框×比例，允许纸边交换；每轴相对候选物理单位误差≤1%，两轴互差≤1%。不以一边吻合猜幅面。
- 原图名须含平面语义。合法“火灾自动报警系统平面”仍为平面；系统图、原理、示意、不按比例拒绝按图长计量。纸空间及 viewport 比例未支持。
- 第二类支持直接 Model 或完整真实 INSERT 链内的原线性 DIMENSION。独立定义点须在同框内部，不重用图框边或图签。原匿名渲染块已有唯一纯数值文字，与类型正确的局部定义点实测一致（1%）；局部定义点和渲染位置按实际 INSERT 链变换，世界几何实测再与未改写的源显示数值核对（1%）。INSERT 倍率只变换几何，不能无依据乘在标注物理值上；净倍率非1而显示数/世界几何不自洽时仍未知，不能统称支持所有等比块内尺寸。DIMLFAC=1，文字不覆盖/抑制/带模板，缓存与定义点不冲突。正 DIMSCALE 只控制显示，不乘长度。
- 默认 XY OCS 下，克隆线性尺寸的有限 XY `DIM.insert` 只平移原匿名渲染块，再经真实父 INSERT 链；定义点不加该向量，源显示数不改写，物理单位系数不乘该向量。单位文字搜索对同一尺寸渲染内容使用相同平移；非XY、非有限向量或非零Z偏移仍未支持。不生成/重绘原尺寸，也不删除/改写原 `insert`。该含义见 [ezdxf Dimension.dxf.insert](https://ezdxf.readthedocs.io/en/stable/dxfentities/dimension.html) 和 [Autodesk 线性尺寸 group 12](https://help.autodesk.com/cloudhelp/2020/ENU/AutoCAD-DXF/files/GUID-F0004556-493C-48D5-8619-61D6ADF05C04.htm)。
- 选中尺寸还核验其匿名渲染块的 BLOCK_RECORD/BLOCK 可见性上下文，不只检查 DIM 本体和渲染文字。TEXT/ATTRIB/ATTDEF 用真实对齐放置点判范围；FIT/ALIGNED 两端都须在真实图框内，不能只凭 group10 在框内就接受中心对齐后实际在框外的比例、图名或尺寸文字。
- 全布局/全块定义的编码文字作为完整搜索索引，再按 Model 实际实例及当前外框判断适用。未使用定义不冒充本框声明；已证包围框在框外的文字或不透明载体排除并留定位。局部数值（如 `-0.9m`）、明确材料/图例/标高文字单列，不作坐标单位依据。当前框或无法定位的 OLE、栅格、代理、未读外参、表格/引线文字仍须读清。
- 所选 INSERT/块记录含 XCLIP/空间过滤字典、动态块标记或未恢复注释上下文时拒收；当前保守范围也包括残留的已停用裁剪字典及未核验的 `*U` 匿名动态候选。源文字搜索遇到本框/无法定位的此类实例同样保留未知，不从缓存定义或包围盒宣称文字已读完。未实现原生裁剪渲染/动态可见性恢复；图层开启、未冻结和实体未隐藏只是必要条件。

第二类尺寸只证明独立几何自洽，不独立证明 SI 单位。物理单位依赖“选定边是标准纸幅外框、原图签比例适用于当前平面”的规则假设，层级固定 `inferred / 规则推算量`，不表示人工复核或正式采用。

## 请求和消费

单框管网用 `unit.geometry_evidence`；批量用 `unit.geometry_evidence_by_frame[frame_id]`，每框明确给出，不沿用相邻比例。不得与 `unit.declaration` 混填。`unit.raw_unit/factor_to_output` 仍经物理单位核验，不夹入根数、损耗或单双线倍率。

~~~json
{
  "schema_version": "qto-geometric-unit-request/1.0",
  "raw_unit": "Millimeters",
  "measurement_semantics": "plan_to_scale",
  "frame": {"entity_refs": [{"handle": "FRAME", "insert_handles": []}]},
  "scale_text": {"handle": "SCALE"},
  "view_text_refs": [{"handle": "TITLE"}],
  "dimension_refs": [{"handle": "DIM"}],
  "basis": "原外框、同图签比例、当前平面图名和内部原尺寸的选择依据"
}
~~~

句柄来自原 DXF，不能填中性 `record_id`。INSERT 链从 Model 最外层到实体所属块，不能省略。独立 scope 文件须含 `layout: Model`、`boundary_policy: contained`、`bounds: {xmin,ymin,xmax_exclusive,ymax_exclusive}`，不得越出所引外框。

~~~text
python scripts/qto_geometric_unit_evidence.py --cad-manifest 原CAD清单.json --request 几何请求.json --scope 本框范围.json --output 几何单位核验.json
~~~

Python API：`verify_geometric_unit_evidence(request, manifest, scope)`。成功为 `qto-geometric-unit-evidence/1.0`；CLI 另绑定清单绝对路径/SHA。其他专业必须用 `verify_geometric_unit_credential(credential, expected_scope)` 重核原源和范围，不能信自报状态或系数；公共凭据不等于电气/风管等专业数量接入完成。

原图框及尺寸通过，但适用声明冲突或不透明载体未读清时，抛 `GeometricUnitUnresolved`，`partial_evidence` 仅为 `qto-geometric-scale-corroboration/1.0`。CLI 返回2并保存该诊断；单位、米/绘图单位、换算系数和长度均 null，`allows_length_measurement=false`，不能被凭据消费接口接收。仅一类证据或其他前置不足也拒绝，不补零。

管网不足时保存 `单位未决.json`，不产可计长度输入。成功时把凭据及 `measurement_scope` 交 infer；infer 重核原源/范围、检查实际管段未越界，将受单位推定影响的长度最高定为规则推算，在摘要说明假设。原显式声明行为保留。

公共凭据还固定 `runtime_dependencies`：当前实际单位核验模块、单位来源契约和原源几何模块的路径/字节 SHA。依赖集合由执行代码决定，凭据不能自行删项、改 schema 或关闭 replay 绕过；旧凭据缺该绑定或任一模块字节变化须重新核验和实际消费。相同字节的代码副本可复验，仍保留原生产代码位置以便冻结结果重放。

管网几何单位路径还必须有可回读且 SHA 固定的实际识别台账；`recognition_basis` 或适配器保留的真实台账引用须指向该文件。台账的原始图 SHA 必须与单位凭据一致，且活动识别记录实际使用的证据须绑定本次 CAD 清单或确切交换 DXF。只写相同原 DWG SHA、scope、drawing_id、相同句柄或自列中性流不足以证明交换副本/重提版本相同。实际管段的 CAD record_id 和 INSERT/块/叶对象归属链也须在同一已验源对象流可回读；缺识别来源、版本或对象链不出量。批量入口自动将实际读取的 CAD 清单版本加入其生成的工作识别台账；单框外部台账须已有上述真实来源证据。

实际在线附件接收凭据在几何单位模式写入当前 `producer_dependencies`，生产前后核对字节；接收方无论 `replay=True/False` 均重新核对输入、实际结果和接收凭据的完整单位核验依赖。它不会因主 `infer_pipe_network.py` SHA 未变而接受发生变化的单位核验模块。

`verify_pipe_consumption` 保留 `replay` 参数仅为调用兼容；`False` 也始终实际重放 infer 并逐对象比较完整结果，不降低接收核验。私有生产阶段同样重放，不能靠删除几何单位字段或接收依赖字段选择快检路径。确定性重放失败、超时或与冻结结果不同均拒绝接收；不以自报字段替代实际生产结果。

## 未支持范围

非A系/加长幅面、非等比/非XY/阵列框、纸空间/视口、世界尺度与源显示数值不自洽的块内尺寸、DIMLFAC非1、带覆盖/复合单位/注释性尺寸、非XY或含Z偏移的尺寸渲染上下文、权威构件尺寸作第二类证据，以及当前框不透明文字读取/消歧均未支持。真源只能按实际证据说明通过或阻断；匿名回归不替代原项目复算、跨宿主复测或人工采用。

## 局部工作台与电气消费

`verify_geometric_unit_consumption(credential, manifest, scope, factor, output_unit='m')` 是新增专业消费接口。输入须为公共CLI绑定CAD清单路径/SHA的原凭据、专业当前实际读取的完整CAD清单、显式同一scope和换算倍率；返回 `qto-geometric-unit-consumption/1.0`，含原凭据、回源checked_evidence、scope、factor_to_output、output_unit、dependency_fingerprints和formal_adoption=false。它固定完整公共代码、CAD清单、原始/交换/转换及全部artifact依赖；不采信凭据自报单位、状态或倍率。

现阶段新增消费接口要求独立适用坐标SI。公共请求可增加 `coordinate_unit_refs: [{handle,insert_handles:[]}]`，引用本框当前活动、可见、明确单一的“坐标单位：毫米”等真实原文；尺寸/标高/材料单位不适用。所引声明通过源实例搜索后，仍保留其余冲突和未读载体的阻断。只有图框与DIM自洽的既有结果仍为规则假设佐证，`physical_unit_basis=null`、`allows_length_measurement=false`，不能进入这条新增专业消费路径。

局部工作台 `prepare_pipe` 的 operations 接收 `geometric_unit_evidence`、`measurement_scope`、`factor_to_output`。须按同一scope重建局部索引，再实际回源重放索引、核对权威/交换来源、所选对象空间及实际换算。转换时保留索引对象ID，同时从原完整实例链生成中性清单可回读的源身份，交既有infer唯一数量出口；不再把工作台内部 `CADINST-Model/句柄` 冒充中性实例链。索引外/未定位对象仍按原未决契约处理，局部有量不证明全图完整。

电气的实际字段、容差与消费重放见[电气计算与证据流程](../../qto-electrical-routes/references/计算与证据流程.md#公共几何单位的专业实际消费第十三批)。真实项目没有新增坐标SI时，即使已解码更多活动载体，也不能将其未知单位或物理长度改为mm、0或候选长度。

### 生产契约与源位置（R2）

infer先回源重建几何单位事实，再判断当前物理坐标SI分支的必要生产契约，不以输入中可删的 `workbench` 标签决定是否重放。该分支当前接收工作台实际生产契约，必须从同源局部索引、真实实例链和原操作重新形成完整输入；删除标签/消费凭据、同时修改长度/端点/几何、或生产代码漂移均不能降级成可信原始管段。旧显式单位路径及既有无坐标SI的几何假设层级分别保留，不通过此门替代其原有边界。

来源内容身份与文件位置分列：索引实际源位置和单位凭据源位置分别核对现存文件SHA，权威源及交换DXF的内容身份必须一致；同字节副本可在另一目录重建同scope索引并实际生产、消费。位置变化本身不算源版本变化；文件内容变化、scope不同、台账或真实实例不一致仍拒收。
