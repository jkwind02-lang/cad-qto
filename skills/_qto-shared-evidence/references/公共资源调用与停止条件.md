# 公共资源调用与停止条件

## 定位

本目录提供项目资料范围筛选、中性事实提取、缓存身份核验、证据定位、通用成果契约，以及供专业/协调入口调用的文件依赖、执行检查点和对账机制。它不是用户可触发的 Skill，不自行决定专业路由、工程对象归属或计算规则，不替专业计算器生成工程量，也不决定正式采用、成本报价或发布。持续执行机制见[项目作业台账与持续执行](项目作业台账与持续执行.md)。

未来各算量 Skill 与本目录保持同级安装。消费者必须从自身 Skill 根目录使用以下相对位置直接读取所需文件：

~~~text
../_qto-shared-evidence/references/<文件名>
~~~

不得使用当前电脑的绝对路径，不得连接或导入旧 Skill、旧归档或退役源。

## 按任务读取

每次任务只读取实际需要的文件：

1. 所有任务先直接读取 [图纸与资料范围筛选.md](图纸与资料范围筛选.md)。
2. 处理 CAD/DWG/DXF 或中性图元缓存时，直接读取 [CAD中性事实提取.md](CAD中性事实提取.md) 和 [缓存身份与复用条件.md](缓存身份与复用条件.md)。
3. 处理 PDF、扫描图、图片或表格时，直接读取 [PDF图片与表格提取.md](PDF图片与表格提取.md)；复用既有提取结果时同时读取缓存要求。
4. 处理设计说明、合同计量条款、计算书或项目规则文档时，直接读取 [项目文档条款提取.md](项目文档条款提取.md)。
5. 形成任何工程量成果前，直接读取 [证据引用要求.md](证据引用要求.md) 和 [通用成果字段与状态.md](通用成果字段与状态.md)。

不得因为存在本目录就默认读取所有项目资料，也不得把本文件当成多层路由器替代上述直接链接。

## 先限定范围

范围未锁定前，允许低成本目录、图纸总览及相关图例/说明的观察，由模型识别专业和范围；不默认启动全项目 CAD 深度解析、PDF 全页 OCR 或全部表格重建。用户已限定图纸/楼层/区域时可以在此范围继续，不以系统和对象尚未识别为由要求用户代填。至少需要确定或在识图过程中补齐：

- 业务专业；
- 主要物理对象；
- 系统；
- 楼栋、楼层或区域；
- 图纸类型；
- 图纸版本；
- 输出维度；
- 是否需要设计说明、系统图、详图、材料表或项目计量规则。

## 缺失即停止

当前任务要求读取的任一公共文件缺失、不可读或版本不明时，消费者必须：

1. 停止依赖该文件的资料提取或计算；
2. 将结果状态标为“待确认”或“证据不足”；
3. 记录缺失路径、受影响范围、已经完成的安全部分和所需补充；
4. 不复制记忆中的旧规则，不读取旧归档，不用模型常识静默替代；
5. 不把受影响数量写成 0。

只有与缺失资源无关且证据完整的独立部分可以继续，并必须单独列示。

## 中性边界

公共资源可以记录“图层原名为 W-GS”“块原名为 VALVE-01”“文字内容为 DN50”“某条线长度为 12.3”，但不能判断：

- 该线是否属于给水管；
- 该块是否应计为阀门；
- 文字应传播给哪些对象；
- 某个洞口是否扣除；
- 某段构件采用何种重量或计量规则。

这些结论只能由当前算量 Skill 根据专业规则和项目证据作出。
