# CAD 中性事实提取

## 适用范围

用于 DWG、DXF 及其可追溯中性缓存中的几何、图层、块、文字、布局和坐标事实。只提取当前任务范围需要的事实，不解释专业含义。

## 提取前身份

至少记录：

- 来源文件规范路径、大小、最后写入时间和 SHA-256；
- 图号、图名、版本、修订号及其定位；
- 读取工具、版本、读取方式和关键参数；
- 模型空间、布局或视口范围；
- 图纸单位、坐标系、比例和必要的变换关系；
- 是否存在代理对象、外部参照、动态块或无法展开对象。

身份或单位不明确时，可以建立对象目录，但不得形成依赖真实长度、面积或坐标的结论。

## 可提取的中性事实

- 原始实体类型、句柄或稳定对象编号；
- 原始图层名、颜色、线型及可见状态；
- 原始块名、有效块名、块实例位置、旋转、比例和属性文字；
- 线、弧、多段线、圆、样条、面域和实体的原始几何；
- 端点、顶点、包围盒、坐标、长度、面积等由几何直接得到的值；
- 文字原文、位置、方向和所属布局；
- 布局、视口和外部参照的原始关系；
- 提取失败、不可展开和几何异常记录。

“原始块名”“原始图层名”和“文字原文”都是事实，不等于对象的专业分类。

## 范围过滤

过滤条件必须来自已锁定范围，例如指定布局、楼层框、坐标窗口、用户明确图层或选定图号。不得先用未经专业 Skill 判断的图层关键词把对象直接归为管道、风管、阀门或构件。

如果仅能依据文件名或模糊文字建立候选集合，输出应标为“候选事实”，交由当前算量 Skill判断。

### 递归块和大图提取效率

- 先锁定布局、图窗或选择集，再展开与该范围相交的块实例；不要为一个楼层任务先序列化整张DWG的全部递归实例。
- 块定义几何只解析和缓存一次，实例通过嵌套路径与变换引用；除非当前专业确实需要，不重复写出相同定义的全部展开几何。
- 优先流式筛选、按对象类型补提和范围级压缩缓存。记录顶层实例数、递归展开数、去重后对象数、输出字节数和耗时。
- 递归展开量或缓存体积与当前范围明显不成比例时，停止继续膨胀并改为“范围内实例路径 + 被引用块定义”的定向提取；说明未展开对象及影响。

## 对象级证据定位

每条供计算使用的事实至少保留：

- 来源资料编号；
- 模型空间或布局名；
- 实体句柄、稳定对象编号或可复核的坐标范围；
- 原始图层、块名或文字；
- 原始数值和单位；
- 提取工具及参数；
- 已知限制。

只给汇总长度、面积或数量而没有对象定位，不满足可追溯要求。

块展开、外部参照、坐标变换或曲线离散产生的新几何，还必须保留源句柄、嵌套路径、变换关系和转换方法，使结果能够回到原始对象。

## 几何与单位检查

- 保留原始值和换算后的值，说明换算因子。
- 圆周、二维竖管符号、引线和标注线不得自动当作实际构件长度。
- 闭合状态、自交、重复实体、零长度、异常比例和视口重复必须记录。
- 外部参照缺失、代理对象不可读或动态块状态不明时，标明受影响对象和范围。
- 插入单位不明时保留图纸原始单位，不自动换算为米、平方米或立方米。
- 几何可以证明长度或面积，但不能单独证明计量归属、规格或扣减规则。

## 运行入口与输出边界

读取结果按[读取覆盖与补读](读取覆盖与补读.md)区分可测几何、标注或定位证据、专业适配器待办、未支持对象及读取失败。`supported` 不等于已经取得工程数量；同时查看能力字段与 `CAD读取覆盖与待补读.json`，逐对象处理与本次范围有关的待办。面域适配器待办导致的 `PARTIAL` 与底层读取异常分别报告，不能把未读数量填为零。

原生 DWG 先运行 `scripts/export_dwg_exchange_dxf.ps1`：脚本只把临时工作副本交给 AutoCAD，并在结束时核对源图哈希、大小和修改时间。COM 忙时自动改走隐藏的 Core Console；需直接使用后备路径可加 `-ExportBackend coreconsole`。已有可追溯 DXF 时跳过。再运行：

转换器退出码为0或DXF非空不能证明转换完成。发布交换文件前检查ASCII组码对、SECTION/ENDSEC闭合及EOF；失败不发布目标DXF，保留排障日志。每次成功转换同时保存`<文件名>.dxf.export.json`，绑定原图和交换副本哈希。

已有ODAFileConverter时可显式选择`-ExportBackend oda`。发现损坏对象后，只有在任务工作副本上可选择`oda-audit`修复转换；该选项不修原始DWG，并标记`exchange_geometry_review_required=true`。中性提取器读取并核对相邻转换记录，将修复影响继续列入PARTIAL和专业识别报告；文件结构完整不代表工程对象无损。不得删除转换记录来升级状态。原图已变、转换记录不匹配或关键对象缺失时重新取证，受影响量不得按零处理。

~~~text
python scripts/extract_cad_neutral.py --source-dxf <交换副本.dxf> --source-dwg <来源.dwg> --output-dir <中性取证包>
~~~

产物固定为布局图元流、唯一块定义流、失败对象表和 `CAD中性取证清单.json`。清单必须枚举全部布局、块定义及失败数；`PARTIAL` 只能继续不受影响范围。公共层不得生成管道、阀门、钢构件等专业分类或工程量。

用于人工复核的CAD叠加图必须采用可显示中文的字体、按任务对象范围裁切，并使标签在常规缩放下可读。按本次对象形态分别保留纳入、排除、未决、几何或属性推算的代表性样本；只有坐标全图而对象挤在局部、标题乱码或标签不可辨认的图片不算有效视觉验证。

## 1.1 几何契约修订

新提取器保留 `qto-cad-geometry/1.1` 完整WCS参数曲线、原始顶点/bulge、三维包围盒和块实例矩阵。折线/弧线不得按首尾弦长复算；非均匀缩放后的圆弧按仿射参数曲线测量。数值积分给出误差估计，无法满足精度时明确失败。旧清单无 geometry_schema_version 时重新提取，不回填新版本标识掩盖旧数据。未知包围盒不作范围外排除；只有完整保守范围可预筛。样条、网格、阵列块等未覆盖表达保留事实与未决，不把锚点当完整几何。
