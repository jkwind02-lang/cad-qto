# AI 理解工程关系、计算与重算

本说明衔接现有《AI 运用人工算量方法》，保留原文件名供既有链接引用。只在实际算量、关系复核或修改重算时读取相关段落。各节说明可用的计算接口和成立条件，模型按当前问题选择、交错使用，不要求按本文目录完成整套识图。

## 将当前工程解释交给合适的计算器

说明、图例、平面、系统、剖面和详图提供不同证据，模型自行判断本次需要哪种信息。当前对象已具备足够依据时即可测量或试算，计算中的冲突也可推动下一次观察；不等待全图所有关系识别完毕。每项结果保留可定位的对象、实物身份、图页、系统及实际来源，一个实物多个图示只增加证据，不增加数量。

任务范围已经明确就执行，局部未定事项单列。未完成识图时继续读图，不以“缺少用户核准清单”代替工作。物理量、按已确定规则推算量、方案暂估和未决分别交付；不同单位、不同计量口径不混加。

## 管网：完整路线到有依据的分段

现有 `infer_pipe_network.py --input ... --output ...` 已自动调用共享 `qto_pipe_topology.py`，不用另跑一次分段再将结果重复切分。

每条源路线保留 `segment_id/system/space_id/source_ids/start/end/length/geometry`。CAD适配器负责换算完整WCS参数几何；手写无geometry输入只允许真实直线，声明长度必须与两端实长一致。不同图页/楼层坐标空间用不同space_id，不能为强行连通改成同一值。

接管、明确交叉或分离位置使用 `junctions`。例如10m主管中部接3m支管：

```json
{
  "junctions": [{
    "junction_id": "J-01", "decision": "connect",
    "members": [
      {"segment_id": "MAIN", "point": [5, 0, 0]},
      {"segment_id": "BRANCH", "end": "start"}
    ],
    "basis": "本轮图例和局部详图确认三通，非跨越",
    "source_ids": ["本项目局部图证据编号"]
  }]
}
```

`decision`可为`connect/separate/unresolved`，均保留依据和位置，只有connect建立该接点的跨路线连通。也可用`part_index`和0～1的`parameter`定位原曲线。检测到端点落他管中部、直线内交叉或共线重叠时只提示候选，不自动作工程裁决。曲线—曲线内部交叉仍需模型回图补定位，不能把未提示理解成不存在。

原几何拐点与明确变径处分段；保持源路线到派生管段的 `parent_map` 和总长度守恒。原路线分段后的DN种子须补`point`或参数作用位置；若确实全段同规格，可声明`applies_to_entire_object: true`并给`scope_source_id`，不能仅为通过校验扩大范围。

## 跨层与跨图：先对应，再计量

局部取样或范围裁剪必须回查范围外接管。已知外接关系未纳入当前网络时，在识别配置或推算输入中声明 `scope_boundary_nodes`；每项包含 `boundary_id/system/space_id/point/source_id/evidence_level`，坐标使用网络输出单位，可显式带 `coordinate_unit`。`segment_id`可绑定源路线，并支持在有依据的位置分段。模型负责识别范围边界；程序不把所有几何端点自动当作边界，也不凭裁剪后度数恢复范围外管件。

已有 `root_role: scope_interface` 的根节点同时作为范围边界保护，兼容旧输入。边界绑定后停止跨该节点的DN传播；没有完整外接证据时输出“边界管件未决”，不按两条范围内连接输出弯头。外接图元可以仅作为连接上下文：按管网输入格式提供external_ports、connections_complete和管件归属后，可恢复三通等候选，同时不增加范围外管长。未绑定或跨图位置不唯一时保留未决。普通 `change_nodes` 只表示规格分界，不等于范围裁剪；不能只为消除未决而声明完整。

`cross_view_links`分别记录`link_id/physical_id/a/b/basis/source_ids`，a/b按上面源路线定位。两侧系统相同、space_id不同。对应关系不是新增测量直线。

明确竖直时增加 `route_is_vertical: true/from_elevation/to_elevation/elevation_unit/height_source_ids/height_level`。高度单位须与网络单位一致，height_level为confirmed/inferred/scenario。DN另有依据时填写dn。缺高度或非纯竖向路径继续保留接口未决，不能用图纸排版距离补长。

若已在一条源路线中计算该实物，用`quantity_owner_segment_id`引用与physical_id一致的已有计量出口。接口本身不再重复计量。跨图DN连续须有`dn_continuity: true`及`dn_continuity_source_id`；没有则不跨接口传播。

设备台数与端口数分开。交接1.1中的`source_physical_instance_count`是实物数量，`source_endpoint_port_count`是端口数量，旧字段`source_instance_count`保留为端口数量别名。每个端口的space_id、坐标单位及明确管段绑定应透传；多图场景无可靠对应的端口保持未决。

点位配置端口有局部坐标时，明确`point_coordinate_space`：`block`按完整实例矩阵再换单位，`drawing`仅按当前图纸单位换算，`output`表示已经是输出坐标。省略仍兼容旧的output约定，不把旧坐标偷偷当块内坐标。块插入点不能无依据当实际连接端口。

## 电气：通道、路径、回路分开

新输入`qto-electrical-path-ledger/1.0`可通过现有 `calculate_electrical_routes_reference.py <输入.json>`，也可直接 `calculate_electrical_paths.py <输入.json> --output <新版本.json>`。旧route_items参考格式继续支持。

输入包含`project_id/unit: m/paths/channels/circuits`。paths逐段给`id/from_node/to_node/length_m/role/source_ids`；role为horizontal/vertical/offset。channels给实际桥架、线槽、导管或母线，circuits给电缆或电线；每项含`id/physical_id/kind/system/spec/start_node/end_node/path_ids/parallel_count/source_ids`。路径编号按实际经过顺序排列，节点在项目范围内稳定且唯一。

附加长度逐项列extras：`id/node_id/length_each_m/basis/source_ids`，只定位本项起终端；中途预留单独分段。芯数`cable_core_count`只作规格，不参与电缆根数乘法。回路引用channel_ids时程序检查其路径是否真的由所声明通道覆盖；没有全覆盖的出桥架支线应分项，不虚构通道。

同一桥架路径承载多个回路时，桥架按自己的物理通道数计一次；电缆、电线按各自根数计量。未被任何对象采用的路径不能隐藏，输出unused_path_ids供模型检查。当前只是已识别路径参考复算，不替代原图回路识别和清单口径确认。

## 明确算式的依赖重算

```text
python skills/_qto-shared-evidence/scripts/recompute_qto_dependencies.py --input 计算依赖.json --output 本轮重算.json
python skills/_qto-shared-evidence/scripts/recompute_qto_dependencies.py --input 修改后的计算依赖.json --previous 本轮重算.json --output 下一轮重算.json
```

台账schema为`qto-calculation-graph/1.0`，包含project_id、sources、rules、nodes。sources/rules各给id和真实内容sha256。每个事实节点有id、unit、value及source_ids；计算节点有id、unit、expression、variables（变量名映射其他节点ID）、rule_ids。用null表达尚未确定，不能补0。

只执行本轮已明确算式的安全数值运算并核对量纲，不执行任意Python，不自动找规范、不生成专业规则。支持范围内的m/mm、面积体积、质量、单位质量以及明确的数量单位；不支持单位先由专业给出有依据的换算。数量因子用无量纲`1`，设备台数等独立成果用相应单位，不能直接混加。

源图给出“取较大值／取较小值”时，可用 `max(a,b,...)`、`min(a,b,...)`，至少两个标量参数且量纲相同；参数先按各自单位换算到共同 SI 量再比较。原文的 MAX/MIN 或大括号记法由模型明确转写为上述形式，原公式和对象适用范围仍须保留。梁高、跨度、分母等必须各有本轮对象与规则依据，不能把同编号的其他跨尺寸或已算最终答案当输入。所有分支均纳入依赖与证据层级；有一个候选未决时不拿已知候选充当结果。改变未控制的候选也会触发相关结果重算和复核失效。

输出changed_inputs_or_rules、affected_nodes、stale_reviews、removed_nodes和逐项值/式/依赖值，同时生成可读Markdown。即使受影响结果数值碰巧没变，其来源或规则变化也应重新复核。旧输入、旧成果不覆盖；正式采用始终由专业成果及用户实际复核另行判断。

台账中的来源哈希是声明绑定，工具不会自行读取所有源文件核验；沿用共享证据提取和来源核对。复杂几何并集等仍调用专业计算器，其新输出以真实来源重新输入依赖台账，不能拿过期值当新事实。

## 回图与交付

管网引擎输出分单位、分层级的复核摘要，水平已绘量、竖向、断口方案、阀门管件候选和未决事项分别列出。使用原有HTML进行定位及批注，保持本轮结果指纹，重算后旧数字确认不能自动成为新数字确认。

逐系统/支路/构件核对：范围是否全走完、对象是否重复、规格是否作用正确、竖向或节点是否遗漏、附属量是否有依据。抽选正常、边界、排除及未决对象回图，不能只展示正确样例。部分成果既要保留可用量，也要明确未覆盖内容，不用零表示未知。
