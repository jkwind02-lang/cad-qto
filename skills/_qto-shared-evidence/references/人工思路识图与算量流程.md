# AI 运用人工算量方法

适用于从原始图纸开始的全部专业算量，不扩大已有明细复核或范围问答。目标是让当前模型运用自己的图文理解、工程知识、比较和推理能力，自主形成有依据的工程量。模型主导问题分解、资料选择、对象解释、参数推导和纠错；插件提供可观察的图纸、精确事实、确定性计算及约束检查。计算器要求的对象、根数、长度和关系，原则上由模型从资料中求得并准备，不转交用户填写。

本页提供解题策略和成果要求，不规定必须照走的思考顺序。模型可从系统、典型节点、表格、构件或空间区域切入，合并或重排取证、判断与计算；已明确的事项直接推进，有实质歧义时才比较解释、补读或试算。不要为简单任务机械生成多方案、七步回执或项目台账。专业公式、来源身份、单位、重复归属和正式采用边界仍须满足。

用户要求实测独立算量能力且提供人工底稿作参照时，先执行[原图独立算量实测](原图独立算量实测.md)的参照隔离与封存要求。是否表内复核由用户目标决定，不由目录里有没有Excel决定。

## 按当前问题选用算量策略

先形成一个简短的工程判断：本次算什么、哪些资料可回答、主要数量由什么决定、目前哪个不确定点会改变结果。可直接利用已有工程知识提出解释；最终保留可复核的结论、证据、算式及必要的替代解释，不要求输出内部逐步思考。

| 遇到的问题 | 模型可采取的判断与行动 | 何时可以继续计算 |
| --- | --- | --- |
| 还不知道图上有哪些系统或构件 | 看图签、图例及总览，结合符号、文字、空间和工程用途建立工作解释；随后选择相关专业 | 用户给定的图纸/楼层/区域足以限定任务，已识别部分有依据；系统名称不必由用户预填 |
| 相似图形可能有不同含义 | 比较图例、属性、局部连接和所在区域；选择最能区分解释的观察，而非把所有候选都送审 | 当前证据支持一种工作解释，残余疑点及影响已保留 |
| 平面没有表达完整构造 | 主动查系统、剖面、节点或选用表，区分同一实物的不同视图与实际重复实例 | 找到适用对象、测点和构造关系；示意图比例不用于替代设计尺寸 |
| 多个同类对象重复出现 | 从一个代表对象理解做法，按本项目编号、类型、接口及范围推广，重点看变形、边界和冲突实例 | 每个实际实例都在适用范围内，例外独立处理；详图本身不增加安装数量 |
| 标注不等于计算尺寸 | 判断轴线、净边、中心、顶底、完成面及端部关系，组织尺寸链或公式，再用程序求值 | 测点、单位及扣增范围明确，没有在净尺寸上重复扣减 |
| 长度或面积已有，但附属量可能遗漏 | 从实际端口、节点、洞口、构造层及设计条款反查应计内容，并核对已绘同件 | 适用条件成立且身份唯一；无依据的设计补充只能列明确方案 |
| 工具或结果出现异常 | 判断是输入表达、几何支持、工程解释还是项目资料问题；按原因改输入、换取证方式或局部重算 | 有可复核的替代方法；不能为了通过校验而修改证据身份或采用级别 |

这些策略可以交错使用。例如先从设备表找到某型设备，再回平面定位和查接管详图，同样可以完成从系统起点追踪的任务。对已有足够证据的判断无需人为增加第二种解释；对会改变数量的冲突则主动验证。

## 原图到数量需要闭合的内容

1. **读图定范围**：先读图名、设计说明、图例和本次相关平面/系统/剖面/详图。列出楼层、系统、材料做法、计量口径、图纸对应关系及排除范围。目录名不是楼层依据；缺哪张图以及影响哪部分要明确。
2. **认识系统或构造**：在可见图面中找到起点、终点、编号、支路、分区、标高和典型构造。形成简短识图说明与定位。不能先全图抓某图层再把其长度当专业量。
3. **识别工程对象**：将符号、文字/引线、几何、编号及连接关系组合判断。模型给出“是什么、在哪里、为什么这样认、量哪一段/哪一面”的工作识别，建立稳定对象编号。中性图元只是证据，不是工程对象标准答案。
4. **沿工程关系逐段/逐件计算**：按系统、支路、回路、构件组或构造区推进；先完成一个可独立复核的小区段，再扩到同类对象。相同块族可以批量处理，但需限定适用实例、检查例外，不可无边界整层套用。公式、扣减及数量出口仍由对应专业负责。
5. **补齐隐藏在图纸表达中的数量**：回到系统、剖面、详图核对竖向、转折、接口、端部、洞口、相交和附属构造。图上未画出的内容只能由可定位规则或显式方案推算，不能凭空补设计。
6. **回图对账并纠错**：用编号标记图或等效可视化逐区域核对已计、排除、未决；核查遗漏、双算、系统错配、规格分界及接口守恒。普通重复族采用有代表性抽查，变形/嵌套/边界/冲突对象重点查；注明实际查看范围，不能把渲染完成当作视觉复核完成。
7. **汇总交付**：数量按系统、规格、区域、单位和证据层级分列，同时交付可回到图面的明细/算式及少量真正未决事项。形成数字不能只交JSON或日志；“全未决”只能是尚未完成识图的阶段结果，不能作为已完成首轮算量。

上述七项是任务完成时需要覆盖的内容，编号不强制执行顺序。全图中性索引可以因性能需要先建立，但不能用图元统计替代工程判断。遵循[推算分层协议](推算假定与发布分层协议.md)。

## 由模型把工程解释变成真实计算输入

- 根据本专业原生输入格式，把当前对象、所量部位、来源尺寸、已判断的连接/适用关系写入输入。先查现有工具支持的字段；程序能直接读取的源坐标、曲线、数量和数组由程序取用，避免手抄或口算回填。
- 输入要求“根数/净长/洞口并集已明确”时，模型主动求解这些条件：从图纸取得布置范围、尺寸和边界，选择适用计算方法，用现有量测、区间、面域或明确算式工具算出，再引用结果。不能把这一句话解释为用户必须提供已经完成的清单。
- 若已有工具缺少字段转换，可在当前任务工作目录写读取源文件、筛选明确对象、映射字段或计算明确算式的小型辅助脚本。保留实际来源和方法，复用已有精确几何模块；不硬编码项目答案、默填工程参数或另写绕过证据/重复归属检查的计算器。通用算法确实不支持的部分，说明具体缺口和已尝试替代方法。
- 原生工具返回候选或工作参考量时，继续形成可查看明细并回图核对；正式采用检查和工作计算分开。错误消息提示证据/规则不够时，先区分真实资料缺失与程序尚未支持该工作层级，不能将模型判断伪写成已核定依据。
- 计算后用与生成输入不同的信息检查：从末端回查支路、从房间回查边界与洞口、从节点回查构件端部，或将分段结果与整体尺寸关系比对。检查应能发现遗漏或错误解释，不只是重复相同乘除。

## 模型识别与人工复核分开

- 模型可依据本轮图纸作工作纳入、工作排除、系统归属、规格绑定和唯一实例判断，并继续调用计算器。识别记录保存实际模型/工具、图面或对象定位、判断依据、适用对象、冲突检查及未决。
- “已识别”“已计算”“确认量”都不自动等于人工签认。数量证据强度、识别者、复核状态、通用规则成熟度和正式发布资格分别记录；不能为通过校验把模型伪装成核定人或权威文件责任主体。
- 直接几何、尺寸和唯一标注可以支撑事实量；关系推导、方案参数分别列为规则推算量、方案暂估量。现有专业能力披露要求候选/试运行的继续保留，不因本轮流程调整升级成熟度。
- 未复核的模型工作识别允许计算、提交用户查看，不自动进入正式量。需要正式采用时，另记录实际责任方复核及项目规则、授权，不能把工作识别改名成独立裁决。
- 可用工具继续判明的普通识图事项由模型处理；只有资料确缺、冲突不能消解、设计需答疑或合同/方案确需选择时才提问。未决须写已尝试的核对、影响对象、数量影响（能算则算）和最少所需输入。
- 工程常识和模型已有知识可用于解释图形、寻找依据、判断异常和选择算法。具体项目参数、当前标准条款及适用节点仍须有可核对来源；知识帮助模型解决问题，不自动证明本项目采用了某项做法。

## 工具选择与常见误判

- 以 CAD 为主要基础资料时，优先在同一有效版本的原生实体、文字、属性、标注及外部参照中继续取证。先核对总说明、安装选用表和典型详图，再将缺少的标高或构造写成未决。CAD 中的 PDF 底图、图像和外部参照是显式资料依赖：登记文件、页码或布局、变换与可读状态；原生文字搜索无命中不表示依赖页没有条款。必要时读取所引用文件并说明真实来源，不把转入 CAD 的底图冒称原生文字，也不因优先 CAD 而丢弃更新或更权威的正式设计。
- 从 CAD 表格取得高度、规格或做法时，一起保留行对象、列标题、单位、基准定义与适用条件；分散 TEXT/MTEXT 需依据表线、同一行列及上下文重新组织。先核实例型式与表中类别，不能仅因同为洗手盆、门或柱就跨型式套值。阀门安装高度、器具顶高、管底和管中心分别解释，转换到计算测点须有连接或偏移依据；表内数值明确不等于所有实例的匹配已经成立。
- 跨专业图形尺寸更新时，将设计尺寸、可量图面轮廓和拓扑关系分开。端点落在有限线段上、投影邻接和图形比例可支持工作解释，但不等于 CAD 中存在参数约束或设计变更授权。需要维持门宽、柱面邻接等关系形成候选位置时，记录原位置、控制尺寸、所保留的关系及重建结果；原图冲突与采用条件继续保留。
- 需要定位局部、选择同类实例或把本轮识图判断变成计算输入时，按[局部识图与对象操作](局部识图与对象操作.md)使用范围索引、邻域查询和操作记录；大图先限定布局与范围。索引、模型判断与专业计算分别保留来源，未识别对象不能从覆盖清单消失。
- 平面、系统、剖面及典型详图之间的对应，按[跨图对象候选对应](跨图对象候选对应.md)枚举约束和候选。唯一候选仍需核对图面依据；同一实物多视图、跨层接续、多个实例共用典型详图分别处理。
- 说明或详图提出逐设备、逐端口、逐节点的附属构造要求时，按[逐实例构造要求与附属量](逐实例构造要求与附属量.md)将原条款、适用条件、例外与实际实例对应。先核对系统图和详图中已画出的同一附属件，再形成唯一数量出口；条件未知不能当作不适用，长度、面积和支架布置仍交专业计算器。
- 尺寸起点、终点或起算基准会改变数量时，按[尺寸指向与尺寸链复核](尺寸指向与尺寸链复核.md)记录原尺寸、实际指向对象、视图和测点角色。核对尺寸链连续、方向与重复扣减；算式闭合不能替代对尺寸含义的识别，示意图的图面距离不能直接替代设计标注。
- 按问题选择总览或局部，CAD属性/坐标用于精确测量。需要查看线型、颜色、符号构形或文字排布时，按[CAD图样观察与模型识图](CAD图样观察与模型识图.md)生成有来源的图样视图，并实际查看图像；现有工作台编号SVG主要用于定位。必要时采用原生CAD视图、可靠PDF或含关键上下文的裁图。OCR提取文字不等于识别连接关系，渲染成功也不证明模型已看图。
- 判断图上对象用实际可见几何及上下文。块插入基点不一定落在对象处，动态块定义不等于当前可见状态；父块、子块、详图和系统图不等于多个物理实例。
- 图层、块名、颜色及最近文字只是线索。经过本项目图例/引线/系统关系核对后可形成有范围的识别规则，不能禁止模型使用这些证据，也不能把单一线索当充分结论。
- 程序不支持某种表达时，先尝试可复核的工具测量或对象清单输入；说明替代方法与误差。只有确实缺决定性事实才停止该分支。禁止另写绕过证据、重复归属或正式采用约束的项目捷径。

## 过程可见性与试验评价

用户问执行过程或Skill使用情况时，按“读了什么图 → 如何识别 → 量了哪些对象 → 如何复算/回图 → 哪些仍未决”给出可点击证据。Skill调用、脚本退出成功、字段守恒分别说明，不能冒充识图准确率。独立重算不读取历史专业分类/数量作为输入或预期答案。

维护测试既要覆盖有证据的模型识别能实际进入计算，也要覆盖无证据、来源漂移、规则冲突、重复实例和假冒复核被拦截。空识别配置/全未决只测试缺输入处理，不评价完整算量能力。

能力实测必须让模型实际读原图并自行生成输入；人工预先指定对象、规格、根数或关系的算例只属于程序回归。保存原图身份、实际使用的技能/模型、观察与工具调用、模型生成的输入、原生结果及人工介入，再与隔离的参照比较对象/量项覆盖、误纳、重复、关系和逐项数量误差。合成任务与真实工程、首次独立结果与揭示答案后的回归分别报告。修复识图错误时提炼适用条件和反例，不将一个项目的数值答案写成通用知识。

## 统一复核交互

原图算量交付默认使用[HTML交互复核与批注](HTML交互复核与批注.md)提供点选回图、同类问题整组批注、成员例外、保存恢复和处理回执。各专业提供自己已计算的对象、单位及依据；共用界面不替代专业重算，不把未定位对象移到假坐标，也不把已保存方法意见当成已确认数量。

## 分段、跨图与修改重算的执行接续

进入管网分段、跨层接口、电气共用路径或参数修改时，按[按人工算量顺序执行与重算](按人工算量顺序执行与重算.md)对应小节执行。复用本轮对象和证据，不另要求用户逐项填写；模型负责完成读图和输入准备。合成测试通过不代表原图识别或专业采用条件已闭合。
