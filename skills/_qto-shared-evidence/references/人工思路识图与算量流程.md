# 人工思路识图与算量流程

适用于从原始图纸开始的全部专业算量，不扩大已有明细复核或范围问答。模型承担识图、专业判断、测量组织和回图复核；工具提供看图、查询、定位、测量、计算和对账。不能把“脚本不识别语义”误解为“必须用户先识别完才能算”。

## 主线与每步可检查的产物

1. **读图定范围**：先读图名、设计说明、图例和本次相关平面/系统/剖面/详图。列出楼层、系统、材料做法、计量口径、图纸对应关系及排除范围。目录名不是楼层依据；缺哪张图以及影响哪部分要明确。
2. **认识系统或构造**：在可见图面中找到起点、终点、编号、支路、分区、标高和典型构造。形成简短识图说明与定位。不能先全图抓某图层再把其长度当专业量。
3. **识别工程对象**：将符号、文字/引线、几何、编号及连接关系组合判断。模型给出“是什么、在哪里、为什么这样认、量哪一段/哪一面”的工作识别，建立稳定对象编号。中性图元只是证据，不是工程对象标准答案。
4. **沿工程关系逐段/逐件计算**：按系统、支路、回路、构件组或构造区推进；先完成一个可独立复核的小区段，再扩到同类对象。相同块族可以批量处理，但需限定适用实例、检查例外，不可无边界整层套用。公式、扣减及数量出口仍由对应专业负责。
5. **补齐隐藏在图纸表达中的数量**：回到系统、剖面、详图核对竖向、转折、接口、端部、洞口、相交和附属构造。图上未画出的内容只能由可定位规则或显式方案推算，不能凭空补设计。
6. **回图对账并纠错**：用编号标记图或等效可视化逐区域核对已计、排除、未决；核查遗漏、双算、系统错配、规格分界及接口守恒。普通重复族采用有代表性抽查，变形/嵌套/边界/冲突对象重点查；注明实际查看范围，不能把渲染完成当作视觉复核完成。
7. **汇总交付**：数量按系统、规格、区域、单位和证据层级分列，同时交付可回到图面的明细/算式及少量真正未决事项。形成数字不能只交JSON或日志；“全未决”只能是尚未完成识图的阶段结果，不能作为已完成首轮算量。

上述步骤允许往返补证和局部重算，不是七道等用户逐一批准的门。全图中性索引可以因性能需要先建立，但不能跳过识图、对象判断和回图检查。遵循[推算分层协议](推算假定与发布分层协议.md)。

## 模型识别与人工复核分开

- 模型可依据本轮图纸作工作纳入、工作排除、系统归属、规格绑定和唯一实例判断，并继续调用计算器。识别记录保存实际模型/工具、图面或对象定位、判断依据、适用对象、冲突检查及未决。
- “已识别”“已计算”“确认量”都不自动等于人工签认。数量证据强度、识别者、复核状态、通用规则成熟度和正式发布资格分别记录；不能为通过校验把模型伪装成核定人或权威文件责任主体。
- 直接几何、尺寸和唯一标注可以支撑事实量；关系推导、方案参数分别列为规则推算量、方案暂估量。现有专业能力披露要求候选/试运行的继续保留，不因本轮流程调整升级成熟度。
- 未复核的模型工作识别允许计算、提交用户查看，不自动进入正式量。需要正式采用时，另记录实际责任方复核及项目规则、授权，不能把工作识别改名成独立裁决。
- 可用工具继续判明的普通识图事项由模型处理；只有资料确缺、冲突不能消解、设计需答疑或合同/方案确需选择时才提问。未决须写已尝试的核对、影响对象、数量影响（能算则算）和最少所需输入。

## 工具选择与常见误判

- 先总览再局部放大，CAD属性/坐标用于精确测量；必要时采用原生CAD视图、可靠PDF或含关键上下文的裁图。OCR提取文字不等于识别连接关系。
- 判断图上对象用实际可见几何及上下文。块插入基点不一定落在对象处，动态块定义不等于当前可见状态；父块、子块、详图和系统图不等于多个物理实例。
- 图层、块名、颜色及最近文字只是线索。经过本项目图例/引线/系统关系核对后可形成有范围的识别规则，不能禁止模型使用这些证据，也不能把单一线索当充分结论。
- 程序不支持某种表达时，先尝试可复核的工具测量或对象清单输入；说明替代方法与误差。只有确实缺决定性事实才停止该分支。禁止另写绕过证据、重复归属或正式采用约束的项目捷径。

## 过程可见性与试验评价

用户问执行过程或Skill使用情况时，按“读了什么图 → 如何识别 → 量了哪些对象 → 如何复算/回图 → 哪些仍未决”给出可点击证据。Skill调用、脚本退出成功、字段守恒分别说明，不能冒充识图准确率。独立重算不读取历史专业分类/数量作为输入或预期答案。

维护测试既要覆盖有证据的模型识别能实际进入计算，也要覆盖无证据、来源漂移、规则冲突、重复实例和假冒复核被拦截。空识别配置/全未决只测试缺输入处理，不评价完整算量能力。

## 统一复核交互

原图算量交付默认使用[HTML交互复核与批注](HTML交互复核与批注.md)提供点选回图、同类问题整组批注、成员例外、保存恢复和处理回执。各专业提供自己已计算的对象、单位及依据；共用界面不替代专业重算，不把未定位对象移到假坐标，也不把已保存方法意见当成已确认数量。

## 分段、跨图与修改重算的执行接续

进入管网分段、跨层接口、电气共用路径或参数修改时，按[按人工算量顺序执行与重算](按人工算量顺序执行与重算.md)对应小节执行。复用本轮对象和证据，不另要求用户逐项填写；模型负责完成读图和输入准备。合成测试通过不代表原图识别或专业采用条件已闭合。
