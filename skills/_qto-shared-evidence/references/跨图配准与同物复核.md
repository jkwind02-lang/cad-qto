# 跨图配准与同物复核

运行入口：`python -B scripts/qto_cross_drawing_registration.py --input 请求.json --output-dir 新结果目录 --build-review`。
这是中性源实体的配准、几何候选和模型工作解释工具，不改物理 ID、工程量、人工核准或正式采用状态。

## 输入与身份

顶层 `schema: qto-cross-drawing-registration/1.0`；`sources`、`registration`、`objects`、`candidate_tolerance_m` 必填。
使用 `--build-review` 时另填 `project_id/review_id/title/revision`。全部相对路径按请求 JSON 所在目录解析；输出目录必须不存在。

- `sources`：每行 `source_key` 是本次图源或图框键，与 CAD 实体 `source_id` 分开。填 `drawing_id/version/floor/scope_id`、`neutral_manifest/manifest_sha256`、`layout`、`unit: {factor_to_m,basis}`、必要的 `expand_blocks`。验证中性清单、布局流、块定义流、原始 DXF/DWG 权威来源 SHA；拒绝旧几何、身份冲突、未知单位及不符单位倍率。配准图源版本由图源登记，观察不能覆盖该版本。原始资料版本含义仍由调用方依据正式资料核实，软件不认证自然语言版本标签。
- `objects`：每行 `observation_id/source_key/source_id/instance_path/object_id/object_type/kind`。`kind` 为 `point` 或 `line`；前者须有原始插入/POINT 位置，后者当前只支持单一直线。`source_id` 和 `instance_path` 必须是与 03 对象绑定一致的完整实例身份，如 `CAD-40/外块/CAD-35/内块/CAD-32`，不能只给块定义末端句柄。可保留 `physical_id`，工具不改值。`version/floor/scope_id` 默认图源声明；缺失值保持 null。对象类别与楼层/范围须由调用方有证识别，阈值不能制造这些事实。

清单存在 `exchange_dxf` 时另核验交换副本实际文件SHA，并与权威源一同纳入计算前后来源指纹及 `verified_source_files` 输出；交换副本已变更即受控拒绝旧几何。未提供交换字段时兼容原合法直接源流程，权威源及中性流仍须校核。

点源记录、直线 WCS 起终点直接从冻结中性流回取。输出并列保存 `original_points/original_unit/original_length_m` 和 `comparison_points_m`；配准仅变换比较坐标，不能将比较坐标当作原图坐标。

## 配准与候选

`registration` 填 `from_source_key/to_source_key/model/max_residual_m/control_pairs`。`model` 为 `translation` 或 `rigid_2d`，均不隐含缩放、镜像。`control_pairs` 每行填 `from_ref/to_ref`（`source_id/instance_path/locator`，locator为 `point/start/end`；直线端点可填 `part_index`）及 `basis/from_basis_source_ids/to_basis_source_ids`。控制点对应是显式工程判断，控制点坐标不由用户另填。平移至少两对不同点；二维刚体至少三对，拒绝重复点和空间跨度退化。每对残差、最大残差、RMS及允许值完整输出；超过允许值返回退出码3，候选搜索不执行，同物工作解释不交接。输入非法返回2，配准满足本轮残差限制返回0；退出码0只表示计算链完成。

近邻和直线共线重叠只出 `candidates`。`candidate_tolerance_m` 是米制非负几何筛查阈值，不是同物证明。点比较 XY 距离，直线比较垂距及正长度投影重叠；等长、相似、近邻、平面投影重叠均不能自动扣量或移交数量出口。不同已知对象类别不组成同物几何候选。版本、楼层和范围冲突仍保留为复核差异并列 `context_conflicts`；未知列 `missing_context`。

## 有证工作解释与线并集

可选 `interpretations`：`interpretation_id/observation_ids[两侧]/basis/decision_origin:model/source_refs`。两侧引用各自完整 `observation_id/source_key/source_id/instance_path/basis_source_ids`。仅类别、版本、楼层、范围均明确且一致并有各侧真实工程依据时可输出 `pairings`。工具校验来源绑定，依据文字与对应语义由模型负责；该工作解释不认证人工审批，`same_physical_proven/automatic_merge_allowed/official/business_adoption` 都为 false。

可选 `line_union_requests` 需引用上述 `interpretation_id` 和 `collinear_tolerance_m`。两侧必须为直线，且各有 `parallel_count:1/elevation_m/multiplicity_elevation_basis_source_ids`，标高相同。未知根数、多个实际根数、未知/不同标高均拒绝；不把未知写为0。输出比较坐标的区间并集长度和各侧原图长度，明确 `working/reference_only`、`quantity_mutation_allowed:false`。它不调用电气/点位计数器，不改变任何项目采用量。

## 实际复核页与既有接口

`--build-review` 复用公共 `qto-review-view/1.0`、scene 和 HTML。每个图源一张保持原单位的原始坐标页；另给米制配准对照页，标题写明非原图量测。对象属性保留完整源身份、原始坐标与候选，数量表为空。

既有比较图生成器自动给同图页、同类别、容差内不同编号的点添加 `attributes.suspected_number_drifts` 和报告 `suspected_number_drifts`。既有单位容差为1mm、0.1cm或0.001m；未知单位不推断。详情可切换对方记录，并显示版本/楼层/范围冲突或缺失。候选不合并标记、不改编号、不改物理 ID、不扣数量，原同编号合成逻辑向后兼容。

09 实例输出的 `source_id` 是图源编号（如 SYN），`source_record_id` 是实体记录身份，`instance_path` 是完整实例路径。08 输入的 `source_key` 接09原图源 `source_id`；08实体 `source_id` 接完整 `instance_path`，不能把09图源编号冒充实体。映射保留 `upstream_identity` 中原 `source_id/source_record_id/instance_path/physical_id` 四值，09原 `physical_id` 不变。每个08观察的 `source_key + 完整instance_path` 必须唯一，另起观察编号不能重复登记同一源实体。09的米制point只与中性流原坐标按单位换算作一致性核查，不重算数量，不新增数量出口，也不回写09。

`profile.scope` 中 `drawing_id/floor/scope_id/version/source_id` 映射为图源/上下文；观察不能用自填版本、楼层或范围覆盖明确的图源声明，未知观察值仍保留null。已有比较页所有上下文字段缺省时保持兼容；提供对象类别、版本、楼层或范围后，这些字段参与列表与同编号标记归组。不同上下文的同编号分别保留。不从设备名称相似或 ATTDEF 默认值相等推定重复。点位适配器仍是独立计数出口。

既有复核页允许上下文属性为列表或字典；展示比较使用保留类型、层级和数组顺序的规范键，字典键序不影响归组，JSON数值1与1.0、0与-0.0同语义，布尔与数值区分，未知null与未提供相容。规范键只用于展示比较，不扁平化或改写原JSON业务值，不改变工程量。

## 数值与验证边界

米坐标必须有限且绝对值不超过1e9m；直线原图长度须大于1e-12m。单次请求只配准两个图源/图框，候选为逐对完整枚举，未截断业务数据。当前不拟合缩放/镜像/非刚性变形、不自动识别墙柱轴号、不解析项目词典、不声称找到全部图纸对象；多段线须先有证拆成独立观察。匿名原始 DXF 经正式中性提取器、CLI、scene、HTML 和离线 Edge 交互复验；不构成真实项目 DWG、交叉宿主、人工验收或安装发布。
