# 线段连通图

公共模块 `scripts/qto_segment_graph.py` 把一张图（一个布局）的线条建成连通图，供引线追踪、已画走线追踪、按图层取长度、共线重叠检查共用。它只做几何：不判断一条线是电缆、桥架还是引线，也不给线定系统或规格，这些由调用的脚本按各自规则做。

## 取哪些线

- LINE、LWPOLYLINE、POLYLINE、ARC 按中性取证里的几何部件取，一个部件一段。多段线的每条边、闭合多段线的闭合边各算一段；弧段长度按弧长算，不按弦长。
- LEADER 的顶点连成直线段收进图里，类型记 `LEADER`。MLEADER/MULTILEADER 目前不支持，按类型计入 `unsupported`，不静默丢弃。
- 图层用正则过滤（`layer_pattern`），不写就取全部图层。
- 块里的线只在调用方声明要展开的块（`expand_blocks`）里取。编号沿用点位的实例路径：`CAD-<顶层句柄>/<块名>/CAD-<块内句柄>`，即点位实例号去掉 `PT-` 前缀。块内 0 层的线归到插入它的图层。
- 长度为 0 的部件（重复顶点等）不入图，记 `degenerate_parts`。没有可用几何的行记 `geometry_problems`；声明展开但块定义缺失、循环引用、超过 16 层，记 `expansion_problems`。这三类都要在成果里如实列出，不当作"图上没有"。

## 范围

给了范围就逐段用部件的精确包围盒判断，判据和点位适配器相同（`qto_cad_geometry.bounds_intersect`）。完全在范围外的段不入图，只计数；跨过范围边的段保留，标 `crosses_scope_edge`。按长度合计时，跨边段要另行裁剪或单列，不能整段计入。

## 怎么连

- **端点并点**：端点间距不超过 `snap_tolerance` 才并成一个节点。并点有上限：一串依次相近的端点不会把两个相距超过容差的端点并到一起，被拒绝的合并记 `refused_snaps`。容差为 0 时只有坐标完全相同的端点相连。
- **交叉不连**：两段在中间相交不产生节点；自交的多段线也不在交叉处断开。
- **T 接只列候选**：自由端点落在另一段中间（距离不超过 `t_tolerance`，默认等于 `snap_tolerance`），列进 `t_contacts`，写明落在哪一段、在该段上的位置比例。不自动连通，由调用方按专业规则决定是否采用。端点只是靠近另一段的端头，不算 T 接。
- **缺口桥接**：两个自由端点相距在 `gap_tolerance` 以内（且超过并点容差），并且两端各自的延伸方向都指向对方、夹角不超过 `gap_angle_deg`（默认 10°），才桥接，记 `gap_bridged`（含缺口长度）。垂直或错开的端点不桥接。一个端点同时有两个及以上可桥接的对象时一律不桥接，记 `ambiguous_gaps`。桥接只连通分量，缺口长度不计入段长。

容差一律按图纸单位，由调用方换算：毫米图里 1 mm 写 1，米制图里写 0.001。

## 输出

- `segments`：段号 `SEG-<来源路径>:<部件号>`、来源路径、句柄、类型、图层、起止点、长度、包围盒、是否跨范围边、起止节点、所属分量。
- `nodes`：节点号、坐标（并点端点的平均值）、度数、汇入的端点。
- `components`：分量号、段、节点、桥接、总长、图层、悬挂节点。
- `dangling_nodes`：度数为 1 的节点（计入桥接后）。
- `t_contacts`、`gap_bridged`、`ambiguous_gaps`、`refused_snaps`，以及各项计数 `counts` 和所用参数 `parameters`。

## 不做的事

不按最小生成树或就近原则补连线；没有画出来的线不推测。不解析 MLEADER 的内容。不判定线的用途、系统和规格。
