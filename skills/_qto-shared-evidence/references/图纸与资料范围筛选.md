# 图纸与资料范围筛选

## 目标

先用最低成本锁定本次任务真正需要的资料，再决定是否进行深度提取。文件名、目录名和修改时间只能作为候选线索，不能单独证明专业、版本或适用范围。

入口确定后、高成本取证前读取入口 Skill 根目录的 `capability.json`；协调任务还要读取已确认工作包的对应文件，并向用户披露其中六项能力字段。档位不因路由成功或本轮脚本运行自动升级。

## 低成本目录

范围尚不明确时，先低成本收集以下信息，并允许查看图纸总览、图例及相关说明以自行判断范围：

- 相对路径、文件类型、大小和最后写入时间；
- 图签、标题、版本号、修订号、发布日期等可直接读取的身份字段；
- 页数、布局名、工作表名或模型空间/图纸空间等低成本结构信息；
- 已有缓存的元数据文件，不读取其专业结论；
- 重复文件、可能的旧版和缺少身份信息的候选项。

不得在此阶段默认解析全部 CAD 图元、OCR 全部 PDF、重建全部表格或遍历所有项目中性缓存。

## 范围锁定表

本次任务保留以下范围信息，已有且未变更时直接复用，不要求每次工具调用重填：

| 字段 | 要求 |
|---|---|
| 业务专业 | 用户已明确的专业，或模型根据本轮图纸识别的专业及依据；尚未识别时继续读图 |
| 主要物理对象 | 本次完整计算链的主要对象 |
| 系统 | 给水、排水、风系统、回路等；不适用时明确写“不适用” |
| 楼栋、楼层或区域 | 允许组合，但不得静默扩大 |
| 图纸类型 | 平面、系统、剖面、详图、说明、材料表等 |
| 图纸版本 | 图签或文档版本；仅有文件时间时标为弱身份 |
| 输出维度 | 对象、系统、规格、楼层、区域、单位等 |
| 补充资料 | 是否需要说明、详图、表格、合同计量规则或方案 |

用户已限定整张图、某层、某区域或整套项目时，可以据此启动总览和专业识别；对象类别、系统和所需详图可由模型在过程中确定，不要求用户预先列齐。范围中的决定性字段未知时，先从现有资料形成可执行的初步范围；只有资料无法回答、不同选择会实质改变任务时才询问最少问题。尚未读图与资料确缺分别记录。

## 资料选择台账

每份候选资料必须记录：

| 字段 | 内容 |
|---|---|
| 资料编号 | 本次任务内唯一编号 |
| 路径 | 项目内可定位路径 |
| 资料类型 | CAD、PDF、图片、表格、说明、计算书等 |
| 版本身份 | 图签/修订号/日期/哈希等 |
| 选择结论 | 已选择、已排除、暂不确定 |
| 原因 | 与任务范围、版本和拟提取事实的关系 |
| 拟提取中性事实 | 例如图层、几何、文字、表格单元格 |
| 未使用影响 | 对完整性和未决事项的影响 |

禁止仅按文件名静默排除，也不得因为资料多就全部选用。

## 版本与冲突

- 不默认“修改时间最新”就是有效版本。
- 同名、同图号或不同格式资料发生版本冲突时，保留全部身份并标为待确认。
- 设计说明、系统图、平面图、详图和材料表相互补充，不得任选一份替代其他资料的独有事实。
- 用户明确指定版本时优先遵从，但仍记录与项目现存版本的差异。
- 无法裁决的版本冲突必须进入未决事项，不得自行拼接。

## 输出

范围筛选输出只包括范围锁定表、资料选择台账、待确认资料及其影响。它不输出专业对象归属或工程量。
