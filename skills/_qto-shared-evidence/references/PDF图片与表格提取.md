# PDF、图片与表格提取

## 适用范围

用于当前范围内的 PDF、扫描图、图片和表格，提取页面文字、图形区域、表格单元格和版面位置等中性事实。是否构成专业对象、规则或工程量由当前算量 Skill 判断。

## 提取前记录

- 来源路径、大小、最后写入时间和 SHA-256；
- 文档标题、图号、版本、修订号和页数；
- 目标页、目标表或目标区域；
- 提取方式、工具版本和关键参数；
- 页面尺寸、旋转、裁剪、缩放和坐标口径；
- 是否为数字文本、扫描图、混合页面或嵌入附件。

## 最小充分提取

1. 先按任务范围选页、选表或选区域。
2. 有可靠数字文本或表格结构时优先保留原始结构。
3. 只有扫描图或结构失真时才进行 OCR、表格重建或图像识别。
4. OCR 或重建结果必须保留置信度、疑似字符、合并单元格和缺失边界。
5. 不为寻找可能信息而默认处理全文件。

原始文字和规范化文字必须分开保存。低置信字符、跨页续表、空白继承和合并单元格向下填充只能标为待判断，不得用上下文静默改成“最合理值”。

## 证据定位

- PDF：资料编号、页码、页面坐标或边界框、原文或单元格；
- 图片：文件身份、像素坐标或框选区域；
- 表格：工作表/表号、行列或单元格地址、表头层级；
- OCR：原图区域、识别文本、置信度和人工复核状态。

跨页表、重复表头、合并单元格、裁切列、旋转页和图例重复必须单独记录。

从页面图形量取的长度只能保留页面坐标或页面单位；在比例、尺寸标注和实际单位未证明前，不得换算为实际工程尺寸。标注文字与页面几何测量应分别记录。

## 中性边界

可以记录“第 3 页坐标框内文字为 DN50”“表 2 第 4 行数量为 6”“某图例图形与文字相邻”，但不能由公共层判断该文字应赋给哪条管线、该数量是否应计取、该图例是否代表实际安装对象。

## 失败处理

页码、比例、表头、单位、版本或 OCR 结果不足以支撑事实时，将该项标为待确认并说明影响。不得把空白单元格、未识别字符或未见对象解释为 0。
