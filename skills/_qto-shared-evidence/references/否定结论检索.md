# 否定结论检索

“图上无”“未见”“不存在”一类结论要附检索记录（《通用成果字段与状态》“否定结论与检索证据”）。本脚本在中性取证包里检索，按条目出记录，供成果和覆盖台账引用。

- 引用方式：成果项写 `否定结论`、顶层带 `否定结论检索记录`，见《通用成果字段与状态》；点位覆盖台账的零实例行写 `search_record_id`、输入给 `search_records`，见点位《点位覆盖台账》。两处都按同一个函数 `record_problems` 核对记录。
- 脚本只检索、定位和列出，不判命中是不是同一对象，也不判该挂哪一项。
- 已有成果里的同写法、同截面行，只列为候选。

## 命令

```
python scripts/search_negative_evidence.py --input 否定结论检索输入.json --output-dir <新目录>
```

- 输出：`否定结论检索记录.json`（`qto-negative-search/1.0`）和 `否定结论检索记录.csv`（人读的表，一条结论一行）。
- 输出目录里已有记录时拒绝覆盖。
- 输入有问题时退出码 2，状态为 `INPUT_REQUIRED`，列出全部问题。

## 输入 `qto-negative-search-input/1.0`

路径都相对输入文件。

**drawings**（图纸，每张一个中性取证包）
- `id`：图纸编号。
- `neutral_dir`：取证包目录，要有 `中性布局图元.ndjson`、`中性块定义图元.ndjson`。
- `group`：报告里的分组名，如本楼栋、公共、相邻楼栋、其他专业。
- `role`：
  - `scope`（缺省）：本次范围，命中改变检索状态；
  - `context`：只作参照，命中照列，不改变状态。
- `sheets`：图页表。
  - `path`；
  - `columns`：标准键 `sheet_id`、`title`、`sheet_kind`、`x1`、`y1`、`x2`、`y2`，可选 `layout`；
  - `kind_map`：把项目写法换成标准图页类型。
- `exclude_sheet_titles`（可选）：正则。本次范围的图上，图名命中的图页按参照处理，用于公共图里他楼栋的图页。
- 标准图页类型：平面、系统图、表与说明、图例、详图、其他。不在图页范围内的命中记为“台账外”。

**drawing_set**（可选）：应覆盖的图纸集合。缺省为全部 `scope` 图纸。集合里没检索到的图列为“未覆盖”。

**items**（一条否定结论一项）
- `item_id`：成果项或清单项编号，记录编号为 `NS-<item_id>`。
- `conclusion`：结论原文。
- `kind`、`term`：检索类型和原词，见下表。
- `aliases`：型号、名称别名，如 BTTRZ / BTTZR。
- `patterns`：补充正则，写在“统一写法”上：大写，乘号一律写 X，去掉空格、连字符、下划线和直径符号（`%%C`、Φ、Ø 等）。
- `exclude`：排除正则，同样写在统一写法上。
- `secondary`：次级检索，可写 `description`、`patterns`、`exclude`。例如“同截面任意型号，限电力电缆”，排除 `KVV` 等控制电缆和 `BV` 类穿线。
- `block_names`：块名正则，`block` 类必填。
- `secondary_judgments`：专业对次级命中的判定，看过检索记录后填，再重跑。
  - 每项写 `judgment`（`非同一对象` 或 `同一对象`）和 `basis`（依据）；
  - 指定命中二选一：`handle`（顶层句柄，可再加 `drawing`、`inner_handle`），或 `text_pattern`（统一写法上的正则，一次判一类写法，依据要说明为什么这一类都不是）；
  - 一条命中按第一条对上的判定；没对上任何命中的判定判输入问题（写错或已过时）。
- 可带 `package`、`building`、`bill_no`、`name`、`features`、`bill_quantity`，原样写进记录。

| kind | term 写法 | 主检索 | 次级检索（缺省） |
|---|---|---|---|
| `spec` | 型号加规格，如 `ZBN-YJV-4x150+1x70` | 型号（含别名）后接完整规格；乘号 x × * X 通用，可带并联 `n(…)`。规格要写全：是更长规格一部分的（4x150 之于 4x150+1x70）不算 | 同截面任意型号，含更长规格的一部分 |
| `tray` | 宽×高，如 `200x100` | 完整规格，含块属性里的值 | 更长规格的一部分 |
| `box` | 箱号，如 `AL1-2` | 大小写、连字符、空格、下划线不分 | 近似编号（数字不同） |
| `model` | 型号，如 `ZBN-BV-2.5` | 同上 | 无 |
| `pipe` | 管材加管径，如 `SC20` | 同上；管材与管径之间可带直径符号或 DN（`SC%%C20`、`SCΦ20`、`SC DN20` 都算） | 无 |
| `text` | 关键词 | 字面匹配（统一写法） | 无 |
| `block` | — | 块名正则命中的插入 | 无 |

- 数字两侧有边界：`4x150` 不命中 `4x1500`，`AL1` 不命中 `BAL12`。
- 统一写法会让一些不同的编号相同，如 `AL-12` 和 `AL1-2`。这时多出来的命中留给专业判，宁可多列，不漏。

**existing_results**（可选）：已有成果表，如各包成果汇总、清单对照。
- 每项写 `label`、`path`、`id_column`、`text_columns`；
- 同写法、次级写法的行列为候选。

**non_drawing_pattern**（可选）：印章、水印类图层的正则。缺省 `印章|签章|水印|签名|会签|STAMP|SEAL|WATERMARK|SIGNATURE`。

**unread_overrides**（可选）：人工核定未读对象性质。
- 写 `drawing`、`class`（`non_drawing` 或 `may_contain`）、`basis`（核定依据，必填）；
- 可再限定 `entity_type`、`layer`、`handles`。

## 怎么读

**三层**
- 布局图元的文字（TEXT、MTEXT，去掉格式码）；
- 块属性值（布局上的插入和块里的插入都读）；
- 块定义里的文字。

**块里的命中**
- 按这个块从布局实际插入的次数计，含嵌套。位置按逐层插入变换落到图页。
- 从没插入过的块定义里的命中，单列“未插入块定义命中”，不计入命中数。
- 标注块（`*D…`）只有标注值，不检索。
- 没有插入记录的其他匿名块（表格、多重引线），按世界坐标计一次。
- 取证清单里没序列化的未引用块定义，内容读不到，记录里列出个数，不计。

**未能读取**
- 代理对象、嵌入对象、图片、底图参考、缺失的外部参照，按图纸、图层计数。
- 图层或块名像印章、水印的，标“非图面内容”，其余标“可能含图面内容”。

**印章、水印图层上的文字**：命中时单列，不算命中。

## 检索状态

| 状态（`status`） | 条件 | 成果里怎么写 |
|---|---|---|
| 全覆盖未命中（`no_hit_full`） | 本次范围主命中 0；应覆盖的图都检索了；本次范围没有“可能含图面内容”的未读对象；本次范围的次级命中为 0，或已逐条判为“非同一对象” | 可作“已确认零值”的检索依据，零值复核记录引用这条记录 |
| 待确认（`no_hit_partial`） | 主命中 0，但有未覆盖的图、可能含图面内容的未读对象、未判定的次级命中，或判为“同一对象”的次级命中 | 写“待确认：在所列范围内未检索到”，登记未决，不进已确认零值。原因列在 `status_reasons` |
| 有命中（`hit`） | 本次范围主命中大于 0 | 不能写“图上无”。命中是不是同一对象、属不属本楼栋，由专业判 |

- 次级命中要判：同截面、换写法的命中最容易藏着重复计量或漏计。判为“同一对象”的，结论要改，记录照旧是待确认。
- 参照图的命中、已有成果候选不改变状态，只在记录里列出，供专业看要不要改结论。

## 记录字段

**JSON**：每条记录有以下字段。
- `record_id`、`item_id`、`conclusion`；
- `targets`：写法、模式、读了哪几层；
- `secondary`、`method`；
- `drawings_searched`、`sheet_kinds_searched`；
- `result`：
  - 主命中按图页类型和分组的数目，参照图命中，前 10 处样例（图纸、图页、图页类型、句柄、图层、原文、经由）；
  - 印章水印图层命中，未插入块定义命中；
  - 次级命中和样例，已判、判为同一对象、未判的个数，未判的样例；已有成果候选，未能读取；
- `secondary_judgments`：输入的判定，各对上几处；
- `uncovered`、`status`、`status_text`、`status_reasons`（待确认的原因）。

另有：
- 顶层 `reverse_check`：条目数等于记录数，应覆盖的图与实际检索的图对账；
- `scope`：每张图检索了几页、各类图页几页，取证包哈希。

**CSV**：15 列。
- 检索记录编号、对应条目、结论、检索图纸、检索对象、方法、结果、命中样例；
- 未插入块定义命中、次级检索、已有成果比对、未能读取、未覆盖、检索状态（待确认的写原因）；
- 次级命中判定：已判、未判各几处，每条判定的对象、结论、依据。

## 限制

- 只检索中性取证包，PDF、扫描页不在内。这类图要另外检索，写进记录的未覆盖。
- 动态块按块定义里的全部文字检索，没有按可见状态筛。
- 近似编号、同截面、已有成果候选，都要专业判断，脚本不出“维持”“疑点”。
