# 尺寸指向与尺寸链复核

当尺寸数值已读到，但还需要判断“指向谁、从哪量到哪、是否可用于本次长度或净边界”时，使用 `scripts/qto_dimension_semantics.py`。本工具复用现有 `dimension_measurement_facts` 和原图实例索引；不再实现另一套尺寸数值提取，也不从图层名或最近对象自动决定轴线、柱面、切口等工程含义。

## 使用顺序

1. 模型回图观察尺寸线、尺寸界线、原文与对应对象，列出候选解释及源对象完整路径。
2. 工具重新校验源 SHA、读原 DIMENSION 与目标几何，将块定义点按完整实例变换一次变成 WCS。
3. 检查尺寸界线定义点是否落在选择的**有限**源线段或指定源端点；XY 相同但 Z 不同、仅落在延长线上、跨实例同句柄均不能通过。
4. 模型显式选定解释。几何吻合仅支持这一解释的几何部分，不证明所声明的工程角色正确。
5. 加入需要的有向尺寸链、组成段包含约束。约束不成立时，涉及尺寸不再作为可消费工作事实。
6. 专业公式消费可用的米制设计尺寸。未决尺寸继续补读或保留未决，不能补零、改底稿答案或写已复核。

## 输入与 Python API

`review_dimension_semantics(document, base_dir=None)` 返回复核记录。CLI 按输入 JSON 所在目录解析相对来源路径；Python API 通过 `base_dir` 指定。

顶层结构：

```json
{
  "schema_version": "qto-dimension-semantics/1.0",
  "adoption_scope": "working",
  "review_status": "unreviewed",
  "sources": [{"source_id": "S", "path": "drawing.dxf", "sha256": "实际源哈希", "view_basis": "当前有效平面图", "raw_unit": "mm"}],
  "targets": [
    {"target_id": "A", "source_id": "S", "view_id": "PLAN", "physical_object_key": "支承A", "reference_id": "轴线与本构件交点", "role": "axis", "object_id": "CADINST-Model/源父块句柄/目标源句柄", "selector": {"kind": "on_line"}, "basis": "原图尺寸界线指向该轴线"},
    {"target_id": "B", "source_id": "S", "view_id": "PLAN", "physical_object_key": "支承B", "reference_id": "轴线与本构件交点", "role": "axis", "object_id": "CADINST-Model/源父块句柄/另一目标源句柄", "selector": {"kind": "on_line"}, "basis": "原图另一端界线指向该轴线"}
  ],
  "dimensions": [{
    "dimension_id": "SPAN", "source_id": "S", "view_id": "PLAN", "object_id": "CADINST-Model/源父块句柄/尺寸源句柄", "basis": "当前视图中本构件支承轴距",
    "candidates": [{"candidate_id": "AXIS_SPAN", "measurement_kind": "aligned_length", "basis": "两端尺寸界线分别落在支承轴线", "endpoints": [{"target_id": "A"}, {"target_id": "B"}]}],
    "selected_candidate_id": "AXIS_SPAN", "selection_basis": "回图核对两端与构件的对应关系"
  }],
  "constraints": []
}
```

这是契约形状，示例中的句柄和 SHA 必须换成原图实际值。不会按示例名称搜索或生成对象。

- `sources.raw_unit` 可选，但提供时必须与 DXF `$INSUNITS` 一致。无可靠源单位时保持未决；不把视口比例、倍数、数量混入单位。
- `targets.role` 支持 `axis/surface/cut/object_point`；角色属于模型解释。每个 `target_id` 表示同一对象的**固定测点**，不能在不同尺寸中沿同一条轴线漂移。若尺寸指向的是不同位置，分别登记引用身份并明确其关系。
- `selector` 支持 `{"kind":"endpoint","part_index":0,"end":"start"}` 或 `{"kind":"on_line","part_index":0}`。只支持 LINE 或折线中的直线段，不接受手写坐标，也不把曲线弦长当作边长。
- 候选的两个 `endpoints` 严格按源 `defpoint2/defpoint3` 顺序，只接受 `target_id`，不能在候选里覆盖角色。
- 原生 `dimtype=1` 使用 `aligned_length`；`dimtype=0` 使用 `projected_length`。投影尺寸的定义点连线与量测轴可能不同，不能相互替换。
- `selected_candidate_id` 和 `selection_basis` 必须显式给出。可以保留多个解释及其各自失败原因；没有选择的唯一候选也不自动升级为量。
- 几何指向容差默认 `1e-6 m`，可显式提供 `tolerance_m` 与 `tolerance_basis`，最大 `0.01 m`。不能用扩大容差解决角色、实例或投影口径冲突。

### 从源矩形中心复核投影尺寸

当尺寸界线与矩形对象中心沿量测方向对应，但二者并非同一空间点时，目标可显式选择 `{"kind":"rectangle_center_projection"}`。本模式只用于 `projected_length`，仍须绑定一个完整源实体路径；不接收手写中心、手工顶点或外包框。

工具要求该源对象在实例 WCS 中由恰好四条有序直边构成闭合矩形，逐项检查端点连续、非零边、相邻正交、共面与共同对角线中点；自交、凹形、曲边、开口、多段轮廓均不接受。非均匀变换后已成为斜平行四边形的轮廓也不冒充矩形。尺寸定义点及量测方向必须落在源矩形平面内；测站匹配使用逆转置后的量测协向量，按空间长度容差检查投影差。

输出保留真实 `source_center_wcs`、四个 `source_vertices_wcs`、`definition_point_wcs`、平面法向、投影偏移向量和偏移距离，并明确给出 `match_mode: measurement_projection`、`verification_mode: source_rectangle_center_projection`。当界线定义点横向偏离中心时，`point_coincident` 为 `false`；`geometry_points_match` 仅表示该显式匹配方式通过，不能解释为中心与界线定义点空间重合。模型提出的轴线、柱面等角色仍为工作解释，几何通过不证明工程语义真实。

同一目标在不同尺寸中始终使用同一个源中心，不能随界线位置漂移。旧 `endpoint/on_line` 的空间共点行为保持不变，并输出 `match_mode: spatial_coincidence`。钢长度消费使用实际所选源测点或中心判断构件轴向；横向不共轴的两个中心即便都与水平界线投影相符，也不能由此取得实际斜构件长度。

## 图面比例、设计值和文字覆盖

输出分开保存原尺寸定义点、实例 WCS 点、尺寸类型、原文、DIMLFAC、图面实例距离和设计尺寸候选。

`DIMLFAC` 非 1 时，必须提供该尺寸的 `design_unit`、`design_unit_basis` 和 `annotation_scale_basis`，说明显示单位及详图缩放含义。程序保留该说明为工作解释，不以文件哈希证明单位解释正确。父 INSERT 的显示缩放只改变图面，不再次乘到标注设计长度。

文字覆盖尺寸不会自动消费。可在尺寸条目内提交：

```json
"model_design_observation": {
  "value": 450,
  "unit": "mm",
  "raw_text_excerpt": "450",
  "locator": "本 DIMENSION 的覆盖文字",
  "basis": "模型独立读取该尺寸原文"
}
```

`raw_text_excerpt` 须精确对应源 DIMENSION 覆盖文字或尺寸图块中的原文。数值仍为候选，输出 `observed_candidate_m`；不能替换几何距离或把审核状态改成正式。需要后续解释、交叉证据解决的内容留在候选记录中。

PDF/扫描件的模型识读条目使用 `evidence_kind: document_observation`，包含 `source_id/view_id/basis/locator/observed_value/unit`。源文件仍核 SHA，但明确标记 `non_geometric_review`，绝不伪造 CAD 定义点验证。候选数字可用于发现“组成段大于总段”等数值矛盾，不能由此认为工程含义已经成立。

## 有限约束

`constraints` 每项必须有唯一 `constraint_id` 和非空 `basis`。

### 有向尺寸链

```json
{"constraint_id":"CHAIN", "kind":"directed_chain", "total":"TOTAL", "parts":[{"dimension_id":"LEFT","direction":1},{"dimension_id":"RIGHT","direction":-1}], "basis":"同一视图同一量测方向下的首尾连续区段"}
```

`direction` 只接受 `1/-1`，表示按尺寸定义点顺序或反向沿链行进。检查测点身份连续、投影轴一致、沿总尺寸起止方向向前、来源和视图一致、区段不重复、设计值之和闭合。不能用总尺寸自身“证明”自身，也不能把两条数值相加正确但位于不同构件的尺寸拼成链。

非均匀 INSERT 变换时，图面方向向量与原尺寸的投影量测方向分开保存。投影符号和有限区间使用逆转置变换后的量测协向量，钢构件轴向判断保留普通变换后的几何方向；不能因图块横纵缩放不同而改变设计值或误放行越界区段。

这是直线或同一投影轴的链约束。转折管路、三角形斜边、跨图高程等须建立各自适用关系，不使用这个加法替代空间几何。

### 组成段包含

```json
{"constraint_id":"PART", "kind":"contained_length", "whole":"TOTAL", "part":"LOCAL", "basis":"同一实物同一方向的局部段包含在总段内"}
```

检查设计值不超过总段，源范围、对象身份、量测类型及投影方向一致。对齐尺寸检查三维共线与范围；投影尺寸按同一量测轴的有限源投影区间检查。不同墙面的门联窗展开总宽不能直接作为一面墙的局部宽，跨层高窗也不能直接作为本层净墙洞口高度。此类对象应先建立逐墙面或逐高度区间的适用关系，再由饰面专业执行相交扣减；本模块不擅自裁切或分摊。

## 钢专业消费

`steel_length_derivation(document, mapping, base_dir=None)` 重新做完整复核，返回现有 `steel_dimension_derivation.derive_dimensions` 可直接消费的 `length_derivation` 和证据映射。

```json
{"span_dimension_id":"SPAN", "basis":"由两端已定位的轴线至切口尺寸推导本构件净长", "ends":[{"end_id":"start","dimension_ids":["START_AXIS_FACE","START_FACE_CUT"]},{"end_id":"end","dimension_ids":["END_AXIS_FACE","END_FACE_CUT"]}]}
```

跨度两端必须统一为轴线、支承面或切口。端部是从起算测点向构件内部沿轴向的连续尺寸路径，路径角色依次为 `axis→surface→cut`，或已从支承面、切口起算的相应子路径。任何自由扣减、同一区段用不同 ID 重扣、从另一端借用区段、把水平投影当实际斜长均会被拒绝。未到切口的路径不能给净长。

输出证据保持 `fact_status:candidate`、`working/unreviewed`；现有数值推导可复算工作量，正式计算器仍须执行自身证据采用规则。不得为了通过正式计算器而把候选改成已核实。

## CLI 与结果边界

```powershell
python -B qto_dimension_semantics.py --input 输入.json --output 尺寸复核.json
python -B qto_dimension_semantics.py --input 输入.json --steel-mapping 钢长度映射.json --output 钢长度工作输入.json
```

输出已存在即拒绝覆盖。`WORKING_CONSISTENT` 只表示输入范围内的源点及已声明有限约束没有发现矛盾，仍是 `working/unreviewed`、`semantic_truth_verified:false`、`formal_adoption_allowed:false`。`PARTIAL_BLOCKED` 中可继续读取候选、冲突和原始事实并补证。动态块、外参状态、重复句柄、交换审阅问题传递到相关尺寸，不能靠子线可读或文件 SHA 正确绕过。

当前不自动解决：从普通炸开文字重建尺寸、从示意图猜尺寸、任意跨图配准、曲面测点、门窗展开分配、多专业通用净量公式、由扫描文字证明数值正确。需要这些能力时，以现有事实辅助模型继续识图；不得把未实现的检查写成已通过。
