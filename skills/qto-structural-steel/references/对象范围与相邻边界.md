# 对象范围与相邻边界

## 本 Skill 的主要对象

纳入以下以承重钢构件及其完整节点关系为主的对象：

- 钢柱、钢梁、桁架、支撑、系杆、檩条、墙梁和永久承重钢平台；
- 钢楼梯的梯梁、梯柱、结构平台梁、钢踏步板和明确属于结构范围的连接件；
- 柱脚板、底板、隔板、横隔板、加劲板、连接板、牛腿和局部加厚板；
- 高强螺栓连接副、普通螺栓、锚栓、栓钉及图纸明确的连接件；
- 结构用楼承板或压型钢板；
- 由上述钢构件直接产生且处理范围已确认的防腐、涂装和防火面积；
- 由永久对象和明确设计要求可唯一推导的措施量，或有专项方案支持的钢结构措施量。

## 相邻对象的唯一数值出口

| 混合对象 | 本 Skill 负责 | 相邻能力负责 |
|---|---|---|
| 钢管混凝土柱 | 钢管、节点板和连接件 | 管内混凝土归 `qto-concrete-formwork`，钢筋归 `qto-rebar` |
| 型钢混凝土构件 | 型钢骨架及钢节点 | 混凝土和模板归 `qto-concrete-formwork`，钢筋归 `qto-rebar` |
| 钢楼梯与混凝土平台 | 钢梯梁、梯柱、钢踏步和钢节点 | 混凝土平台、平台梁和钢筋归对应结构能力 |
| 幕墙或轻质围护 | 仅在结构设计明确为主体承重钢构件时纳入 | 幕墙立柱横梁、室内轻钢龙骨归 `qto-framing-supports`；面板归 `qto-surfaces-envelope` |
| 压型钢板 | 结构楼承板及结构图明确的压型板 | 以防水、围护或饰面为主要功能的屋面墙面板归 `qto-surfaces-envelope` |
| 机电支吊架 | 不纳入 | 跟随管道、风管、电气线路或设备对象 |
| 栏杆、扶手、装饰钢件 | 只有明确进入结构构件表和承重范围时纳入 | 成品构件数量或装修范围归 `qto-components-points` 或 `qto-surfaces-envelope` |

同一物理对象只能有一个重量出口。跨 Skill 可以共享位置、轮廓或构件编号，但不得重复汇总。

## 容易误触发但不属于本 Skill

- 梁柱钢筋、钢筋网、锚固、搭接和措施筋；
- 轻钢龙骨隔墙、吊顶龙骨、幕墙铝型材或装饰骨架；
- 钢管给排水、消防管、风管法兰、桥架和机电支架；
- 金属屋面围护板、保温夹芯板、幕墙面板或金属饰面；
- 钢材、螺栓、涂料单价，报价、成本或采购清单；
- 仅统计设备、门窗、栏杆等完成品实例数量的任务。

## 混合请求处理

用户要求“主体结构全部算量”时，本 Skill 只承担钢结构链。混凝土、模板、钢筋、砌体等分别列明目标能力；协调 Skill 尚未建立时，不得把本 Skill 当作全专业入口。

若用户只要求节点板、螺栓、压型板或涂装，可以单独执行相应分支，但必须同时说明主构件是否在本次范围内，避免把局部量写成完整钢结构总量。
