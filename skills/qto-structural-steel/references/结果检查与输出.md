# 结果检查与输出

## 对象级检查

- 来源文件存在且 SHA-256 与运行清单一致；
- 构件、节点和零件编号唯一，视图副本已排除；
- 长度口径、截面、材质、单位重或密度均有证据；
- 主构件、节点板、局部加厚和牛腿没有重叠计量；
- 节点实例、构件端点和板件/连接件数量守恒；
- 未配对标签、异常跨、变标高、坡长和深化排布均进入未决清单。

## 数值检查

- 数值为有限非负数，中间值不先行四舍五入；
- 型钢重量、净截面重量和板件重量公式与单位换算复核；
- 连接件数量为整数或有明确批次口径；
- 压型板面积说明投影/实铺、洞口和搭接；
- 涂装面积说明处理范围、暴露面和排除面；
- 措施量有方案或结构化零值证据；
- 条件或替代口径允许形成明确命名的数值参考项，但必须标为 `采用角色=reference`、`结果用途=reference_only` 和“进入永久钢质量小计=false”；质量型参考量另标 `质量归属=separate_reference`，连接件或面积参考仍保持各自非质量归属。正式采用量另列，未裁决时为 `null`。

## 汇总检查

- 不同单位没有进入同一个结果字段；
- 主构件、节点钢件、连接件、压型板、涂装、措施用钢和参考质量分别汇总；
- 汇总成员明确且没有重复；
- 同一对象身份签名的不同 `physical_object_id` 或 `measurement_basis` 没有被相加；
- 有未决成员时只称“已证实部分”或“已证实下限”；
- 参考质量和敏感性值不进入永久钢结构小计；
- 第三方清单仅作后验差异分析。

## 未决状态

| 情形 | 状态 | 数值 |
|---|---|---|
| 本项范围和公式闭合 | 已计算 | 数字 |
| 已证实部分可独立成立，但范围不完整 | 部分计算 | 已证实数字，并关联未决事项 |
| 正式采用量缺决定性项目输入 | 待确认；有依据的候选按推算协议另列 | 正式量为 `null` |
| 来源或专业证据不足 | 证据不足 | `null` |
| 经范围审查确定不适用 | 不适用 | `null` |

未知、缺失和表格空白都不是零。真正零值必须记录覆盖范围、覆盖方法、全部对象编号、`coverage_complete` 直接证据、采用规则和“已确认零值”结论；元数据不能冒充覆盖证据。

## 验证顺序

1. 使用 `_qto-shared-evidence/scripts/validate_minimum_result.py` 验证公共最小成果契约；
2. 使用 `scripts/validate_structural_steel_result.py --calculator <计算器> --binding <成果> <计算证据> <运行清单>` 做绑定校验：复核清单、生成器、成果、明细 CSV 的哈希并重新计算；可重复 `--binding` 验证多个案例；
3. 人工复核来源定位、截面表版本、节点覆盖、归属和实际业务范围；
4. 真实项目完成后再与旧成果或第三方清单对照。

`--schema-only` 只做成果结构检查，不能作为业务验收。绑定校验 PASS 也不证明图纸识别、节点判断或工程量完整，只证明提交成果确由指定清单和指定计算器重放得到，并满足已编码不变量。
