# 面层与建筑围护算量

先定阶段：范围/能力问答只读相关边界与能力披露；用户仅要求已有明细复核时做表内复核；原始资料算量执行下文。若用户要求用图纸检验技能、底稿仅作参照，执行[原图独立算量实测](../_qto-shared-evidence/references/原图独立算量实测.md)，不得因为有底稿而改成表内复核。表内复核不核准原图，细则按需见 [分阶段读取](../_qto-shared-evidence/references/按任务阶段读取.md)。

原图算量先读取并执行 [人工思路识图与算量流程](../_qto-shared-evidence/references/人工思路识图与算量流程.md)。模型运用图文理解与工程知识，自主选择取证、判断和计算方法，生成有依据的专业输入及可复核工作量；原生工具负责精确取证和计算。人工方法是可按问题选用的策略，执行顺序可调整；普通识图不等待用户逐对象核定，正式采用另列。

先将房间/立面平面与做法表、剖面对应，逐表面逐构造层识别边界、侧别和洞口；计算扣减与展开，再回图检查上翻、收口和未覆盖区。

以“唯一物理表面 + 构造层 + 侧别 + 计量基准”为主线。清晰的单一面积任务直接执行；多层构造、洞口、坡面、幕墙和完整性始终分链表达。

## 先判定对象边界

直接读取 [对象范围与相邻边界](references/对象范围与相邻边界.md)。

- 纳入直接覆盖建筑基层的楼地面、墙柱面、天棚、屋面、防水、保温、隔热、涂饰和围护面板。
- 面层可以附着于混凝土、砌体或轻质隔墙，但基层实体工程量不在本 Skill 重算。
- 幕墙面板在本 Skill；幕墙立柱、横梁、轻钢龙骨和吊顶龙骨在 `qto-framing-supports`。若合同清单把骨架综合在面板项目内，另建清单归组说明，不覆盖物理分账。
- 门窗和开启扇的实例数量在 `qto-components-points`；本 Skill 只消费已闭合的洞口边界或开启扇面积作扣减。
- 结构钢构件涂装跟随 `qto-structural-steel`；道路、场坪和室外铺装交给 `qto-roads-siteworks`。

## 执行顺序

### 1. 锁定范围、来源和口径

读取 [图纸与资料范围筛选](../_qto-shared-evidence/references/图纸与资料范围筛选.md)，至少锁定项目、楼栋、楼层或立面、装修区域、图纸版本、设计变更、材料做法表和输出维度。

项目、地区、合同和标准规则的采用顺序先按公共 [现行规则来源选择门](../_qto-shared-evidence/references/现行规则来源选择门.md) 判断；规则版本或适用条件未闭合时，只形成不依赖争议规则的物理面积或明确命名的候选参考量。

先区分：

- 物理表面积、材料净覆盖面积、采购展开面积和合同清单量；
- 设计表面、水平投影、轴线投影、饰面外围尺寸和实际坡面；
- 基层、找平层、防水层、保温层、饰面层和面板层；
- 已证实部分、完整范围和条件性参考量。

这些数量可以相互校核，不得相互替换。需要清单量时读取 [现行计量标准摘要](references/现行计量标准摘要.md)，核对项目地区、资金性质、招标或合同日期、合同约定及地方补充规则；适用门未闭合时只形成物理量或明确命名的参考量。

### 2. 核对资料身份

原始资料按 [资料提取与来源核对](../_qto-shared-evidence/references/按任务阶段读取.md#原始资料与计算) 选择相应公共资源；未进入提取阶段时不展开其他资料类型。

只能复用中性图元、文字、表格、文件身份和坐标事实；不得继承旧专业分类、旧公式、旧数量或旧通过状态。来源身份、单位、比例、视图归属或材料表版本未闭合时停止受影响计算。

### 3. 读取直接规则分支

- 楼地面、墙柱面、天棚和建筑涂饰：[楼地面墙面天棚规则](references/楼地面墙面天棚规则.md)
- 屋面、坡面、防水、保温和隔热：[屋面防水保温规则](references/屋面防水保温规则.md)
- 墙面板、屋面板和幕墙面板：[围护板与幕墙面板规则](references/围护板与幕墙面板规则.md)
- 门窗洞口、设备孔洞、重叠扣减和边界完整性：[洞口扣减与面域边界](references/洞口扣减与面域边界.md)

再读取 [规则清单与成熟状态](references/规则清单与成熟状态.md) 和公共 [推算分层协议](../_qto-shared-evidence/references/推算假定与发布分层协议.md)，按本次对象核对相关规则及状态；候选、试运行和正式采用保持分层，历史提升依据仅在追溯时展开。

本 Skill 各分支成熟度不同，执行前必须读取 [案例成熟度与建设门槛](references/案例成熟度与建设门槛.md)。只有青海真实资料已覆盖的局部机制允许作为试运行分支；室内装修、完整防水保温和完整幕墙仍是候选分支，不得因等效测试通过而自动采用。

### 4. 建立表面清单并计算

读取 [计算与证据流程](references/计算与证据流程.md)，按以下顺序执行：

原图有吊顶/饰面填充时，可按[填充面域识别与去重](references/填充面域识别与去重.md)提取和对应面域，不能把逐填充面积相加或依图层名直接套做法。

没有可靠填充、边界由普通线网表达时，按[普通线网面域与房间对应](references/普通线网面域与房间对应.md)提取闭合候选、孔洞及未闭合边界。门口等计量分界须显式引用源端点和图面依据；不得自动连接所有缺口，也不得把每个闭合面自动分配给最近房名或做法。

尺寸及洞口标签需跨平面、立面或门窗表对应时，按[尺寸指向与尺寸链复核](../_qto-shared-evidence/references/尺寸指向与尺寸链复核.md)核对所指表面、方向和范围；转角或连续门窗的总宽不能整段扣给其中一面墙。完整房间测试须在计算前列出适用构造层、柱突出、洞口侧壁与收口，以及门窗实例和骨架的相邻数量出口，不能在计算后删除尚未完成的量项。

1. 为每个物理表面建立唯一编号、楼层区域、视图、侧别和边界来源；
2. 为每个构造层单独建立层编号、材料做法、覆盖范围和计量基准；
3. 选择设计表面、水平投影、坡面或合同明确口径，不以轴线面积替代设计表面；
4. 先形成毛表面，再扣洞口并集和其他明确排除，最后增加有设计尺寸的侧壁、翻边或回边；
5. 坡面使用三维坡面或已证实坡度换算；局部折面、天沟、泛水、女儿墙上翻分别展开；
6. 基层、找平、防水、保温、饰面和面板分别输出，即使单位相同也不跨层相加；
7. 只对同对象类别、同构造层、同计量基准和同采用角色形成小计；
8. 缺材料适用范围、洞口边界、坡面、搭接或完整覆盖事实时，正式量保持未决；有依据的边界/构造方案按推算协议另列，不能形成有意义候选才用 `null`。

只有对象、边界、单位、层次、侧别、洞口并集和口径已由项目证据明确时，才可使用 `scripts/calculate_surfaces_envelope.py` 做确定性复算。输入格式见 [表面与构造层清单格式](references/表面与构造层清单格式.md)。脚本不识别图纸语义、不判断做法表适用范围，也不补设计内容。

矩形面积项的局部定位需要交接或随尺寸修订时，按输入格式建立 `frame_binding`：把坐标系、有限源边区间、正反向和竖向范围显式绑定到本表面的来源事实，再核对局部原点、轴向和输入长高。一个面可以只占源边的一段，不用整条边长强行替代。来源仍须由模型读图确定；未绑定的旧定位只能披露为未验证，面积数值相同不代表位置正确。

### 5. 检查并形成成果

读取 [证据引用要求](../_qto-shared-evidence/references/证据引用要求.md)、[通用成果字段与状态](../_qto-shared-evidence/references/通用成果字段与状态.md) 和 [结果检查与输出](references/结果检查与输出.md)。

- 每条结果必须有物理表面、构造层、侧别、计量基准、数值或 `null`、单位、公式、来源、规则、状态和未决事项。
- 洞口扣减必须引用去重后的并集证据；相交洞口不得直接相加。
- 轴线投影、局部可定位面积和采购展开敏感性默认作为参考，不进入采用小计。
- 零值只有在目标范围已完整检查且确实不存在对象时成立；未知、未提取或范围冲突不得写零。
- 使用试运行规则的成果必须标识为试运行结果。

先运行公共最小成果验证，再用 `scripts/validate_surfaces_envelope_result.py --calculator <计算器> --manifest <运行清单> --binding <成果>` 做绑定复算。通过只证明来源绑定、公式复算和已编码不变量成立，不替代项目专业复核。

## 正式采用停止与局部分支继续

以下条件只阻断受影响结果进入正式量；已确认表面、候选边界、构造层方案和洞口/坡面替代方案继续输出，无法形成有意义候选才使用 `null`：

- 图纸、装修表、材料表、设计变更或合同计量口径冲突且无法裁决；
- 单位、比例、坐标变换、视图归属、表面法向或坡度未确认；
- 房间、立面或屋面边界不闭合，洞口仅有符号或标签，无法形成唯一并集；
- 同一表面不同构造层、不同侧别或不同做法区域无法唯一分配；
- 轴线尺寸与设计外轮廓不一致，却要求完整面板或屋面净量；
- 天沟、泛水、女儿墙上翻、设备基础、采光顶、变形缝或局部折面会改变结果但未确认；
- 幕墙开启扇、面板和物理骨架边界未分清；
- 搭接、拼缝、附加层、损耗或采购展开量没有设计或合同依据；
- 项目适用计量标准和合同优先级未确认，却要求正式清单量。

## 禁止事项

- 不读取、导入或调用旧 Skill、旧归档、旧项目计算脚本或旧结果作为运行输入。
- 不把楼板面积自动当楼地面、天棚、防水、保温和饰面所有层的面积。
- 不把房间文字、材料编号或最近做法跨边界传播；不把门窗标签次数当洞口覆盖。
- 不把相交洞口逐个相加，不把投影面积冒充坡面或折面，不用轴线面积补外轮廓差。
- 不把幕墙面板与立柱横梁、墙体实体与饰面、钢构件涂装与建筑涂饰合并。
- 不按默认损耗率、搭接率或经验比例增量，不建立统一规则引擎、报价或成本模块。

## HTML图面复核交付

原图算量形成对象明细后，默认按公共[HTML交互复核与批注](../_qto-shared-evidence/references/HTML交互复核与批注.md)生成可离线点选的复核页，支持问题分组、成员例外、结论与原因、保存和处理回执。沿用共享生成器，不在项目重写前端；收到意见后由本专业复算并更新采用状态，用户方法意见不自动等于数值确认。纯问答、无图表内复核及用户指定其他形态按实际范围处理。

## 长任务持续执行

需要跨会话接续、并行合并或复杂修改依赖时，按共享[项目作业台账与持续执行](../_qto-shared-evidence/references/项目作业台账与持续执行.md)建立或恢复本任务；普通局部算量可直接调用专业工具。本专业继续主责识图、规则解释和计算，按[各专业持续算量执行路径](../_qto-shared-evidence/references/各专业持续算量执行路径.md)选择合适切入点、处理同族及例外。采用执行器时由模型调整任务并用 `next` 接续；任务文件不代替自主识图和真实计算。

物理对象与应计量项分开登记，结果引用本次原生文件及对象身份；复核视图从同一结果索引绑定。当前任务的有效检查点可恢复，图纸、规则或输入变化则沿依赖重算；独立复测使用新任务身份并隔离旧结果。程序完成不替代专业复核及正式采用。
