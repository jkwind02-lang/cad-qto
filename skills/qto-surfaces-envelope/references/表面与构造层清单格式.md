# 表面与构造层清单格式

运行清单版本为 `qto-surfaces-envelope-manifest/1.0`，顶层包含 `task`、`sources`、`evidence`、`rules`、`unresolved` 和 `items`。

## 资料与证据

每项资料声明：

- `source_id`、`path`、`sha256`；
- `file_role`：物理文件角色；
- `source_role`：项目图纸、中性实体流、元数据、项目文档、批准方案、覆盖报告、标准或测试夹具；
- `selection`、选择原因、拟提取中性事实和未使用影响。

CAD 元数据必须断言图纸哈希、实体流哈希、适配器、schema、单位和守恒状态。中性实体流必须绑定图纸与元数据并声明预期行数，复算时逐行核对来源 SHA 和 schema。

每项证据声明 `evidence_class`、`fact_status`、定位、事实、提取方式、质量状态和对象键。实体句柄必须真实存在于绑定实体流。

## 数量项字段

```json
{
  "item_id": "QTY-WALL-01",
  "name": "东立面外墙板轴线口径参考面积",
  "object_type": "facade_panel",
  "physical_surface_id": "SURF-FACADE-EAST",
  "layer_id": "LAYER-EXTERIOR-PANEL",
  "side_scope": "外侧",
  "measurement_basis": "axis_projection",
  "method": "rectangle_net",
  "unit": "m²",
  "scope_status": "partial",
  "adoption_role": "reference",
  "quantity_role": "physical_area",
  "result_use": "几何复核，不作为完整采用量",
  "evidence_refs": ["EV-SOURCE", "EV-GEOMETRY", "EV-OPENINGS", "EV-LAYER"],
  "rule_refs": ["R-SURFACE", "R-OPENING"],
  "unresolved_refs": ["U-OUTLINE"],
  "opening_union_evidence_ref": "EV-OPENINGS",
  "inputs": {
    "length_m": 10.0,
    "height_m": 3.0,
    "side_factor": 1,
    "opening_union_area_m2": 4.0,
    "other_deductions_area_m2": 0.0,
    "reveal_or_return_area_m2": 0.0
  }
}
```

`complete` 还必须声明 `coverage_evidence_ref`。采用轴线口径时必须有 `basis_approval_evidence_ref`。洞口扣减大于零时必须有 `opening_union_evidence_ref`。零值还必须声明 `zero_meaning`。

## 运行

```powershell
python scripts/calculate_surfaces_envelope.py --manifest <运行清单.json> --output <成果.json>
python ../_qto-shared-evidence/scripts/validate_minimum_result.py <成果.json>
python scripts/validate_surfaces_envelope_result.py --calculator scripts/calculate_surfaces_envelope.py --manifest <运行清单.json> --binding <成果.json>
```

结构校验和绑定复算不能证明材料表适用范围、合同口径或项目完整性，仍需专业复核。
