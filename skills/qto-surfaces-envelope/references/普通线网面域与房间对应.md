# 普通线网面域与房间对应

图纸没有可靠 HATCH 时，用 `scripts/extract_surface_linework.py` 从模型已选定的墙面、柱面或面层分界直线建立中性面域。它补的是线网分析和源定位能力，不把闭合图形自动解释成房间，不读取人工底稿，不依据图层名分配做法。

## 输入与调用

`python scripts/extract_surface_linework.py --input <本轮识图输入.json> --output <新轮次面域.json>`

输入 `schema_version: qto-surface-linework/1.0`，主要字段如下：

| 字段 | 内容 |
|---|---|
| `drawing` | 当前 DXF 的 `path`、`sha256`；前后核验源未变化 |
| `unit`、`unit_evidence` | 物理单位和本图依据；与 INSUNITS 相容；单位为零不能省略依据 |
| `scope` | `view_id`、`interpretation`、`bounds_raw: [xmin,ymin,xmax,ymax]`、`plane_z_raw`、`plane_tolerance_m` |
| `segments` | `[{path:[父块句柄,...,实体句柄],part:可选段索引}]`；不指定 `part` 时选择该多段线所有段 |
| `label_paths` | 可选房间文字完整路径，仅返回落面候选关系，不自动建立房间或做法归属 |
| `precision_grid_m` | 可选，默认 0，不归整；非零须有 `precision_evidence`，逐项记录前后坐标变化 |

普通块路径为句柄字符串；MINSERT 父节点为 `{handle, row, column}`，从零开始，必须明确物理单元。解析每一级父子所有权，应用块的平移、旋转、镜像、非均匀缩放及 OCS 变换。未受控读取的外部参照不作为已完整块。

父块的匿名/动态可见状态未核验时，已取得几何可以继续作为候选，但 `source_context_issues` 和逐边来源保留父实例路径与后续处理要求，总体降为部分读取；不能因为子线段能组成面就消除父块待核状态。多段线逐段处理，一条零长、重复或不支持的段保留失败段编号，不吞掉其余合法段。

源文件读取时另保留 `source_identity_issues` 和 `source_read_warnings`。即使重复句柄位于未引用块中，当前局部能成面也不证明全文件源身份有效；遇到冲突总体保留部分状态。文件哈希未变只证明未修改原图，不等于重复句柄已解决。HATCH 面域入口也使用同一读取诊断，存在源身份冲突时将各区域降为 `candidate_source_identity_conflict`，归组仍保留候选区域编号。

当前支持 LINE、直线 LWPOLYLINE/POLYLINE；曲线明确列为失败，不按弦线近似。范围边界仅用于检查，跨范围线段列入 `excluded`，不裁切后借视图边框封闭成面。不同 Z 的线段不投影混层。大坐标先转局部米坐标计算，再返回原坐标定位。

## 面域和异常的含义

程序对真实相交线段节点化、合并同位重线后调用 `polygonize_full`，输出：

- `faces`：几何分区，每个面保留外环、内环、面积、周长以及逐边源实例路径。所有面均待模型解释，不能整批合计为房间量。
- `cut_edges`、`dangles`、`invalid_rings`：割边、悬边、无效环及对应源线；它们是所选线网的诊断，不直接等于施工错误。
- `pre_noding_invalid_rings`：保留节点化之前的源自交等异常，避免交点切开后看似正常就遗失问题。
- `failures`、`excluded`、`precision_changes`：不支持实体、范围排除和精度归整分别记录。不能因已有部分面就忽略这些对象。

嵌套环会产生“外圈带孔的面”和“孔内的另一分区”；柱子、墙体、房间可能各自成面。先按房间文字、墙柱关系、图面及构造层选出需要的物理表面，孔内分区不能又作为同一房间面积增加。相邻房间共享线不把两个房间合成一个；落在共享边上的文字仍显示多个候选。

## 模型解释的计量分界

门窗开口在平面表达中可能使内墙边界断开。程序不自动补门洞；模型回看平面、门窗表和构造后，可以针对本表面的计量用途声明 `interpreted_links`：

```json
{
  "id": "OPENING-LIMIT-01",
  "from": {"path": ["父块句柄", "左侧源线句柄"], "part": 0, "end": "end"},
  "to": {"path": ["父块句柄", "右侧源线句柄"], "part": 0, "end": "start"},
  "purpose": "房间地面在门口内墙面处的计量分界",
  "basis": "本视图门洞两侧墙内面和相应门窗表的位置及尺寸",
  "surface_scope": ["本房间地面"],
  "max_length_m": 1.2
}
```

上限是该条边的本图证据约束，不是通用门宽。两个端点必须能从源实体读取，属于本次已选线网，且满足平面、范围、长度约束；重复或重叠补边拒绝。任意坐标不能冒充源端点。解释边在输出中始终为 `origin: interpreted`，与 `drawn` 区分，使用范围不能传播给其他表面、构造层或其他专业。

选择这类边界后可以计算可复核工作量，无需用户逐点批准；模型仍须报告边界用途与适用条件。若采用微小精度网格消除 CAD 浮点误差，保留变化；不得借加大网格跨门洞或跨缺失墙段成面。

## 连接后续算量

模型为选中的面分配唯一物理表面与构造层，然后交给现有面层计算器。地面、吊顶和不同防水层的适用范围分别核对，不能只复制面积。墙面需要展开边界、有效高度、洞口定位与并集；踢脚长度要从相应实际墙面路径扣除适用开口。面域脚本给出的是所选图面几何，不自动保证完整房间装修量。

参考 API：[Shapely polygonize_full](https://shapely.readthedocs.io/en/stable/reference/shapely.polygonize_full.html)。
