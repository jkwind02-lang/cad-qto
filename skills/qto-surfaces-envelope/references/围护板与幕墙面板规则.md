# 围护板与幕墙面板规则

## 墙面板与屋面板

1. 先锁定材料做法对立面或屋面分区的适用范围；材料名称存在不等于覆盖全楼。
2. 由设计外轮廓或三维坡面形成毛面积；轴线面积必须另标为轴线口径。
3. 扣除门窗、百叶、采光带、开启扇和其他不由该面板覆盖的面域并集。
4. 阴阳角、收边、包边、天沟、泛水、女儿墙和局部上翻只有设计展开尺寸闭合时单列。
5. 净覆盖面积、成品板展开、搭接和采购损耗分开，不能以默认比例互换。

## 幕墙面板

- 构件式、单元式、点支承玻璃、石材、金属板和人造板幕墙按面层材料及系统分区。
- 开启扇若单独列项，面板净面积必须扣除开启扇面域；开启扇实例和规格由 `qto-components-points` 提供。
- 物理幕墙立柱、横梁、埋件和连接关系属于 `qto-framing-supports`。项目合同若将骨架综合在幕墙清单项目内，清单归组说明可以包含其价格责任，但物理工程量仍保持分专业子账。
- 玻璃采光顶和金属板幕墙顶按屋面表面处理，不能与垂直幕墙面板混算。

## 双计保护

- 同一面板不得同时按立面外轮廓和分格单元累加；两种方法只可互校。
- 同一开启扇不得既保留在幕墙毛面又作为独立面板面积重复计入。
- 一体板中的面板和保温层可以按项目需要分别形成物理覆盖面积，但小计必须按不同构造层分组，不能相加成一个“总面积”。

## 停止条件

材料表适用范围、立面外轮廓、分格、开启扇、洞口、局部包边或骨架归属不明确时，正式采用量保持 `null`。允许输出明确命名的轴线口径或局部参考面积，但不得称为完整围护量。
