# 对象范围与相邻边界

## 本 Skill 的主要对象

| 对象 | 主要事实 | 主要输出 |
|---|---|---|
| 楼地面 | 房间或区域边界、洞口、做法区、台阶或坡道表面 | 各面层及直接覆盖层面积 |
| 墙柱面 | 墙段、柱面、侧别、高度、洞口、踢脚或吊顶边界 | 抹灰、块料、饰面板、涂饰面积 |
| 天棚 | 房间边界、吊顶轮廓、标高、折面、独立梁面 | 天棚及梁面装饰面积 |
| 屋面 | 投影边界、坡度或三维表面、洞口、天沟和上翻 | 屋面覆盖、刚性层、防水等面积 |
| 防水保温 | 基层表面、层次、翻边、附加层、做法范围 | 分层面积 |
| 围护及幕墙面板 | 立面或坡面、面板范围、开启扇和洞口 | 面板净面积 |

面层附着于混凝土、砌体或轻质隔墙时，可以消费同一边界和洞口事实，但不得把基层实体量作为本 Skill 的面层量。

## 相邻能力出口

- `qto-masonry-secondary`：墙体实体、厚度、体积、构造柱、圈梁和过梁。
- `qto-framing-supports`：轻钢龙骨、吊顶龙骨、幕墙立柱横梁、连接和支承系统。
- `qto-components-points`：门窗、开启扇、设备、洁具和其他实例数量；可向本 Skill 提供已闭合洞口边界。
- `qto-structural-steel`：承重钢构件、节点、连接件、结构用压型板和钢构件涂装。
- `qto-concrete-formwork`：混凝土体积和模板接触面；模板面积不等于装修面面积。
- `qto-roads-siteworks`：道路、场坪、室外铺装、路缘石和多层场地构造。

## 容易冲突的归属

- 结构楼承板按结构用压型板处理；以防水、保温或围护为主要功能的金属板进入本 Skill。
- 幕墙物理面板进入本 Skill，物理骨架进入 `qto-framing-supports`。合同清单可能综合骨架，只能另建清单归组，不得覆盖物理子账。
- 建筑墙面涂料进入本 Skill；随钢柱、钢梁产生的防腐和防火面积跟随钢结构。
- 建筑台阶或坡道面层可进入本 Skill；道路和场地坡面仍属于道路与场地构造。

## 不同口径不得替换

- 物理表面积 ≠ 材料采购展开面积 ≠ 合同清单量。
- 设计完成面 ≠ 基层投影 ≠ 轴线投影。
- 毛面积 ≠ 扣洞后的净面积；局部已证实面积 ≠ 完整范围。
- 同一表面的基层、找平、防水、保温、饰面和面板是不同构造层，不因单位相同而合并。
