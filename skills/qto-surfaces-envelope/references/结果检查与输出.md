# 结果检查与输出

## 逐项必查

- 表面编号、构造层、侧别、楼层或立面、图纸版本和来源 SHA；
- 设计表面、水平投影、坡面、饰面外围或轴线口径；
- 毛面积、洞口并集、其他扣减、增加面和净面积守恒；
- 材料做法与区域映射，不以材料表存在代替适用范围；
- `complete / partial / unresolved / not_applicable` 与覆盖证据一致；
- `adopted / reference` 分开，小计不混合构造层、口径或采用角色。

## 典型异常

- 同一表面、构造层、侧别、口径和采用角色出现重复项；
- 洞口逐个相加导致重叠双扣，或洞口面积大于毛面积；
- 楼板投影被复制为所有装修层面积；
- 轴线面积被写成外轮廓完整面板量；
- 平面投影未换算坡面，或单一坡度覆盖多坡屋面；
- 幕墙面板和骨架合成一个物理面积；
- 局部面积名称出现“总量、合计、完整、全部、全量”；
- 未知值写成 0，参考量进入采用小计。

## 成果表达

每条成果必须包含：范围、名称、数值或 `null`、单位、公式或说明、来源、规则、状态、未决事项和试运行标识。建议同时保留专业字段：对象类别、物理表面、构造层、侧别、计量基准、计算方法、范围完整性、采用角色和对象身份签名。

只对同对象类别、同构造层、同计量基准、同采用角色和同范围完整性形成小计。不同层即使面积相等，也不能相加成一个“平方米总量”。

## 验证顺序

1. 运行公共最小成果校验；
2. 运行本 Skill 绑定复算校验；
3. 人工或模型复核项目图纸、材料表适用范围、洞口、坡面和完整覆盖；
4. 记录验证通过仍不代表的内容，例如合同清单适用性、采购损耗和未提供的局部构造。

否定结论（“图上无”“未见”“不存在”等）是否都附检索记录，反向核对是否写明覆盖的图纸集合并覆盖所有可能含该类对象的图；没有检索记录的否定结论报待确认，不作为不计或判定清单有误的依据。格式见公共[通用成果字段与状态](../../_qto-shared-evidence/references/通用成果字段与状态.md)“否定结论与检索证据”。
