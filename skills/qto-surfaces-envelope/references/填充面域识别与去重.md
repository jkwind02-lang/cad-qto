# 填充面域识别与去重

吊顶或饰面图有明确填充边界时，可用 `scripts/extract_surface_regions.py` 提取来源绑定的 HATCH 面域。需 Python、ezdxf、shapely。此脚本补充面域证据，不替代模型的识图、材料映射和覆盖检查。

```powershell
python scripts/extract_surface_regions.py --source-dxf <本轮交换DXF> --output <新轮次面域.json> --layers <经图例确认的图层正则> --unit mm --unit-evidence <图注尺寸与CAD跨度校准位置>
```

1. 核验原DWG和交换DXF身份，先确认毫米/米、平面位置及比例。一个DWG可能包含多个楼层、多个详图、图例和重复示意，文件名不能代表全部模型空间的归属。
2. 依据图例和做法表对应图案、比例、图层及叠加关系。图层 `Ceiling-C1` 不一定是做法表“顶棚1”；同名NET图案可有300/600等不同网格；“网格＋点纹”可能是同一块矿棉板而非两层材料。
3. 用明确的视图边界排除图例和无关视图。原图中的历史“算量”选区不能作为独立测试的专业输入。保留排除原因和未识别范围。
4. `measure_region_group` 仅对已经分配到同一物理视图、同一构造层/材料的面域求并集，输出并集前总和、重叠扣除、净面域及原区域编号。不同楼层、不同构造层不能借相同坐标自动去重。不同材料在同面重合须核实，不能简单扣掉其中之一。
5. 嵌套孔洞按HATCH岛屿样式及路径标志解析；图形填充范围不等于已扣除全部实际孔洞。图例覆盖、图中灯孔、柱角、设备孔和梁侧等仍要回图检查。
6. 默认拒绝断口、自交、交叉嵌套、曲边和非XY平面。确需查看条件方案时，可显式使用 `--allow-implicit-segments` 与 `--allow-geometry-repair`；程序保存补线长度与位置、拓扑修补前后面积及候选状态。隐式补线默认最多1毫米，可用 `--max-implicit-gap-mm` 明确设定项目候选上限；超限保留失败，不静默画长对角线。交叉路径可按图形奇偶填充形成候选，但不自动解释为工程孔洞。候选修补不是设计裁决，不得静默提升为完整量。曲边、非平面及不可修补失败继续保留，不能以零面积替代。
7. 提取结果中 `regions` 与 `failures` 一起检查，代理对象计数和块变换失败也不能忽略。文件成功输出不代表视图全部提取完成。
8. 将模型确认的面域并集作为独立几何证据，绑定到面层计算器的 `area_direct` 或其他相应计算方法；同时保留原图身份、做法适用、逐项限制和覆盖状态。

多层做法不共用未经论证的边界。低玻璃隔断、到顶实体墙和跨房间连续吊顶要分别建模；楼地面面积不能自动当吊顶面积。二维平面只能证明水平投影，坡面、翻边、侧壁及扣除规则需另有证据。

HATCH岛屿过滤规则依据 [ezdxf官方HATCH文档](https://ezdxf.readthedocs.io/en/stable/dxfentities/hatch.html)；嵌套模式按路径奇偶填充，outer/ignore模式先按路径标志过滤。该技术规则不能替代设计或合同计量规则。

一个EdgePath内可能混放多个独立闭环。发现路径顺序跨越不同房间时，显式使用 `--stitch-tolerance-mm` 按原边端点组环；每个顶点只能连接两条边，分叉、缺边、歧义近邻或容差导致边塌缩均保留失败。端点合并距离与每个原坐标留痕，结果仍为候选。不能把跨越房间的长断口直接补成对角线，也不能为靠近底稿总量而加大端点容差。闭环重组与缺失边补线是不同操作，分别设限并回图检查。
