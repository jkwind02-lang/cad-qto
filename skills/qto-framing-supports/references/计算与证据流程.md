# 计算与证据流程

1. 分别建立隔墙、吊顶、幕墙、装饰支承系统；禁止跨系统复用排布假定。
2. 将平立面分格、剖面、节点、龙骨/型材表和变更按范围配对；记录每个构件的双端或所在分格。
3. 间距标注只作为候选排布事实；净范围、首末根、洞口加固、转角、接长和避让未闭合时不推数量。
4. 数量按物理构件实例或经核定明细表统计；长度按明确净长分段，接长、插芯和搭接另列。
5. 理论重量仅在规格、壁厚/截面和单位质量来源明确时由 `数量×单件净长×单位质量` 复算。
6. 连接件、埋件、转接件按实例单列，不能以“每根一个”默认；损耗和采购定尺不得混入设计物理量。
7. 每项绑定图号/页码/布局/实体或表格行，输出覆盖范围和未决项。
