# 范围与对象边界

最小对象为可唯一定位的骨架构件或连接实例，至少带系统、区域/立面、角色、规格、净长/数量和来源版本。

| 对象 | 唯一数量出口 |
|---|---|
| 隔墙/吊顶龙骨、幕墙立柱横梁、装饰骨架 | 本 Skill |
| 主体钢柱梁、檩条、主体墙梁 | `qto-structural-steel` |
| 石膏板、幕墙面板、饰面与涂料 | `qto-surfaces-envelope` |
| 砌体实体 | `qto-masonry-secondary` |
| 门窗、开启扇、设备实例 | `qto-components-points` |
| 管道/风管/桥架专用支吊架 | 对应机电 Skill；不得因材质为钢转入本 Skill |

幕墙钢立柱只有设计明确作为主体承重构件时才转钢结构，否则按幕墙支承骨架处理。综合支吊架不由任一单系统按经验独占，须有批准深化方案后按明确责任归组。
