# 常规计算逻辑

## 1. 轻钢龙骨隔墙

- 沿顶、沿地龙骨：按各墙段明确净长分别累计；门洞是否断开、转角搭接和接长按详图。
- 普通竖龙骨：若设计规定最大间距 `s_max`，且墙段净排布长度 `L_grid`、两端设置、起排点和洞口影响均明确，常规候选数为 `N_regular = ceil(L_grid / s_max) + 1`；若设计给定固定模数或端部条件不同，按实际排布逐根建实例，不套本式。
- 洞口边龙骨、加强龙骨、门楣/窗台横撑、转角和交接加固按节点实例另加；先从普通排布中剔除被洞口截断的构件，防止重复。
- 横撑/贯通龙骨按明确道数和各道净长，接长与洞口处分段。

## 2. 吊顶骨架

- 主龙骨、副龙骨、边龙骨按吊顶分区、排布方向、最大间距、首末排与边距生成网格实例；异形边界和洞口按实际相交截断。
- 若矩形净区 `L×W` 且排布条件完整，可分别按排布方向用 `ceil(垂直净宽/s_max)+1` 求排数，再乘各排实际净长；不以吊顶面积÷间距直接冒充总长度。
- 吊杆、吊件、挂件、接插件按明确布点/交点/接头实例统计；风口、灯具、检修口及设备加固按节点另列。

## 3. 幕墙与装饰骨架

- 立柱按立面分格竖向边/轴建立，每根按楼层、伸缩缝、插芯或接头分段；横梁按相邻立柱间实际净距建立。
- 开启扇、门窗洞、转角、收边、层间和避雷连接对构件及连接件的影响按节点逐项增加或替换。
- 钢/铝型材重量：`W = Σ(N_i × L_i × w_i)`，`w_i` 为可追溯单位质量；板件/埋件按数量×单件质量或可追溯几何计算，不能用骨架总面积经验换算。

## 4. 连接与损耗

连接件按节点位置和类型计数；不能默认每根一个。设计物理净长、下料长度、采购定尺及损耗分别保留，接长搭接只有在节点规则明确时进入相应口径。

## 5. 校核

构件端点与分格线/墙段/吊顶边界闭合；普通排布、洞口删减和加固新增守恒；每个节点的连接实例与相连构件端点对得上；分规格长度×单位质量与明细重量一致。未闭合处保持 `null`。
