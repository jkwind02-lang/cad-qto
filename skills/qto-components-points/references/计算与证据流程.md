# 计算与证据流程

由模型执行识图、映射和去重，记录工作识别，不要求人工先给完整对象账。嵌套块范围按变换后几何范围核对，插入基点不等于可见位置；动态块须核对当前可见状态。自动生成数量后仍须按区域回图复核。

1. 选定平面、系统图、详图、图例、门窗/设备表和变更，明确各自覆盖范围。
   声明设备接口或局部附件缺资料前，检查系统图边角、典型节点和安装表。将适用详图映射到实际设备实例，逐端口保留规格与角色；典型示意不另增一台设备。详图阀件交给管网专业，跨平面和详图的阀件重合不能仅凭同型号合并，需列互斥方案或明确对应。
   同一DWG有多个楼层或重复典型节点时，先对应所属图签、系统图标题及PDF页，不按第一个同名文字或相似节点选择依据。来源对应错误即使数值碰巧相同，也须修正并保留复核记录。
2. 建候选实例池，记录源对象句柄/页码/表格行、插入点、楼层房间、编号、规格和状态。
3. 排除图例、详图示意、标题栏、阵列样例、拆除/备用项；排除依据必须可定位。
4. 将多个来源通过明确编号、位置、系统拓扑或人工确认合并到同一物理 ID；空间邻近只能提示，不能自动合并。不能唯一合并时保留多个互斥候选及各自数量影响，不直接停止整个类别。
   - 计数前做同位置审查。`build_component_instances_from_neutral.py` 对已采用实例列出：同块、同朝向、插入点完全重合（`coincident_duplicate`）或在近似容差内错位（`near_offset_duplicate`，默认 50 mm）的重复候选，以及同类别不同块、或同块但转向/镜像不同、在容差内同位置的"疑似同一物理对象"（`colocated_same_category`）。脚本不自动剔除；在识别配置 `duplicate_resolutions` 里逐组写明保留哪些实例和依据（叠放的两台设备可全部保留），未处置的组使工作包不完整。每组只写一条处置；同一组写了两条（无论决定相同还是相反），脚本都报错退出，要改主意就直接改那一条。容差按本图最小设备间距改写时在 `duplicate_check.tolerance_basis` 写依据；收紧到 10 mm 以下前先查有没有十几毫米的错位副本。正反向闭合只证明每个图块都有去向，不证明图块不重复。
   - 容差是物理尺寸（`near_tolerance_mm`、`exact_tolerance_mm`），脚本按“每输出单位折合多少毫米”换算：输出单位写 m、cm、mm 时直接换算；写 `drawing_unit` 等其他名称时按图纸 INSUNITS × `factor_to_output` 推算。声明单位与 INSUNITS × factor 矛盾时报错（真实图纸 INSUNITS 写错时，在 `unit.unit_conflict_basis` 写明以声明为准的依据）。推不出尺度时不套默认值：报告 `duplicate_review.scale_status=unbound`、不做同位置审查、工作包不完整，按本图写 `near_tolerance`（输出坐标数值）加 `tolerance_basis` 后重跑。旧写法 `near_tolerance` 仍按输出坐标单位理解，必须配 `tolerance_basis`。报告的 `near_tolerance_mm_effective` 是实际采用的物理半径，交付前核对它符合本图的设备间距。
   - 天正分解块等"一个实例拆成几个子块"（如 `xxxBody`、`xxxCent`、`xxxCent_UP`、`xxxHand`）的，在 `instance_grouping` 声明：块名正则带命名组 `stem` 和 `role`、主角色、容差和依据。子块常不和主子块共点（叶片符号沿阀轴错开、执行器画在阀体边上）且常镜像插入，所以按外形归属：同词干、轴线一致（相差 180° 视为一致）、插入点落在主角色实例外形框内（外扩 `anchor_tolerance`）的子块并入该实例，外形取并集；主角色外形量不出时才要求插入点相距不超过 `anchor_tolerance`。找不到主角色、落在几个主角色范围内、或同一主角色下同一角色不止一个的子块都不合并，列为未决。合并后按词干核对实例数等于主角色子块数。只要计数、不要外形时，也可以只让规则纳入主角色子块、排除其余子块。
   - 动态块：中性记录带 `dynamic_state_not_evaluated` 或 `anonymous_block_state_unverified` 的实例，适配器默认记未决、工作包不完整。核对过可见状态与计数无关（或逐个看过可见状态）后，在命中它的 include 规则上写 `dynamic_state_adjudication`（确认不计的，写在 exclude 规则上，要求相同，放行后记为排除）：`block_names` 写精确块名（不收通配），`basis` 写依据，`evidence_ids` 写识别记录里登记过的证据；只放行其中几个实例时加 `object_ids`。只剩这两种问题代码的实例才能放行，阵列、外部参照、缺定义等仍记未决；裁决里的块名或实例在本图范围内不存在时报错退出。放行的实例按插入点定位，图形范围不参与范围裁剪和外形归并，处置记录带 `dynamic_state_adjudication`。可见状态决定规格或数量的块（如一个块切换单联、双联开关）不能这样整类放行，要按状态分别识别。
   - 旁注文字：同一个块靠旁边的字母分型号（三防、防爆、黄光灯共用一个灯块，旁注 a、b、c），或靠箱号文字区分实例（GPB 块的属性都是默认值），在 include 或 exclude 规则上写 `text_condition`：`pattern` 文字正则（去掉 MTEXT 格式码后匹配，不分大小写），`radius` 半径（输出坐标单位），`layer_pattern` 只读哪些图层的文字（可选），`basis` 依据（必填），箱号这类要当实例键的加 `"as_instance_key": true`。
     - 只看半径内：恰好一段符合的文字、且这段文字不在别的同类候选半径内，规则才适用，处置记录和计数输入带 `side_text`（文字、距离、规则）；实例键写进 `instance_key`。
     - 一段文字落在两个候选的半径内（文字共用），或一个候选半径内有两段以上（多段文字），记未决，连不带旁注的兜底规则也不用，不按远近硬绑；半径内没有符合的文字，旁注规则不适用，有兜底规则就按兜底，没有就记未决“无文字”。
     - 文字取模型空间的 TEXT、MTEXT，以及去候选的路上经过的容器块（如楼层块）里的文字；候选块自己定义里的文字不算旁注。不追引线，引线引出的旁注照“无文字”或歧义处理，回图核对。
     - 报告 `side_text_binding` 和 `点位旁注绑定.csv` 列出每个候选的绑定状态；作实例键的规则还列“文字无块”（符合箱号写法、没落在任何候选半径内的文字）和同号多块，这两类只列出，要回图核对。
     - 旁注规则的 `priority` 写得比不带旁注的兜底规则高，否则两条同时命中报冲突。半径按本图旁注离图块的实际距离定；半径小于相邻同类块间距的一半时，一段文字不会同时落进两个块的半径。
     - 写法示例（模型工作识别记录的 `object_ids` 可以列这个块的全部实例，取自上一轮的 `点位未决全量.csv`，由旁注条件分型）：
       ```json
       {"rule_id": "LAMP-A", "block_pattern": "^LAMP$", "decision": "include", "priority": 10, "category": "三防灯",
        "text_condition": {"pattern": "^a$", "radius": 0.6, "layer_pattern": "^NOTE$", "basis": "图例：旁注 a 为三防灯"}}
       {"rule_id": "BOX", "block_pattern": "^GPB$", "decision": "include", "category": "配电箱",
        "text_condition": {"pattern": "^\\d+A[LP]\\w*$", "radius": 1.0, "as_instance_key": true, "basis": "箱号文字作实例键"}}
       ```
   - 同一台设备在两张图（如桥架平面和照明平面）上各画一次、编号不同时，先按跨图对应确认是否同一实物，列"疑似同一物理对象"待确认，不各计一台。
5. 表格汇总数量与实例计数作对照；差异未裁决时分别形成确认子集、规则推算或多方案暂估，不把任一口径冒充确认答案。
6. 计数输入用适配器写出的 `点位唯一实例计数输入.json`。它带 `geometry_review` 凭据（适配器版本、配置与来源哈希、实例集指纹、容差、候选组数、未处置组数、工作包完整性）；`count_reconciled_instances.py` 重算指纹，输出 `geometry_review.status`（matched / mismatch / absent）和 `work_quantity_ready`。增删或移动任一实例、拼入另一批点位，指纹都对不上；要补点就改识别配置重跑适配器。项目自造的实例列表只作算术复核，不进汇总。
   按类别、系统、规格、楼层/房间分组计数；宽高均明确的门窗/面板实例可另算面积和周长，单位分开。每项写明数量层级、假定编号和发布状态。
7. 覆盖台账：计数前后各跑一次 `scripts/build_point_coverage_ledger.py`，见[点位覆盖台账](点位覆盖台账.md)。
   - 把本专业的整个图纸集合放进去：用了适配器的图写报告，没用的写中性取证目录和自己的计数表（带图元句柄）。楼层整层画在块里的图，在 `expand_blocks` 声明容器块，计数表写路径编号；台账报 `unexpanded_container_blocks` 时说明有块里的计数对象还看不到。
   - 台账给每个候选和每行图例一个去向（已计、有据排除、待识别、版本冲突、无去向）。
   - 续作先看台账的待识别和无去向，以及适配器的 `点位未决全量.csv`，不看已识别点数。
8. 向砌体、围护、电气或管网 Skill 提供稳定实例 ID 和边界事实；需要连接约束时按 [跨专业端点事实](跨专业端点事实.md) 逐实例处置并生成端点交接。接收方不得再创造设备数量，也不得从缺坐标的分类汇总反造端点。
