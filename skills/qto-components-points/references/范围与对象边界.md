# 范围与对象边界

最小对象是具有唯一物理身份和位置的离散实例。表格行、图例符号和系统图节点可作为证据，但不是天然的新增实例。

| 对象 | 唯一出口 |
|---|---|
| 门窗、百叶、开启扇、成品栏杆段/成品构件实例 | 本 Skill；面板和洞口扣减由相邻 Skill 消费 |
| 洁具、水泵、水箱、喷头、消火栓箱、风口、末端设备 | 本 Skill |
| 灯具、开关、插座、探测器、摄像机、弱电点 | 本 Skill 输出实例数量；线路 Skill 只引用末端 |
| 检查井、阀门井、雨水口等点状构筑物 | 本 Skill 统计实例；土建实体尺寸量按项目分流 |
| 连接管、在线阀门、风管、电气路线 | 对应管网/风管/电气 Skill |
| 设备基础、构件内钢筋 | 混凝土模板/钢筋 Skill |

在线风阀属于风管系统对象，风口及独立末端设备属于本 Skill；边界不清时先列互斥清单，不得双计。
