# 常规计算逻辑

## 1. 实例识别与去重

候选实例来自 CAD 图块/几何、BIM 构件、平面符号、系统图节点、门窗表或设备表。先按资料覆盖范围排除图例、示意、备用、拆除和详图复制，再以明确编号、源对象句柄、空间位置、系统连接和人工确认形成稳定物理 ID。没有唯一映射时不能用空间最近自动合并。

计数基本式为 `N_group = count(distinct physical_id)`，分组键至少包括类别、系统、规格、楼层/房间和状态。表格汇总数只作对账，除非表格本身被确认是唯一实例来源。

## 2. 门窗和成品构件

- 樘数按唯一门窗实例统计；同编号不同位置是不同实例，同一实例在平面/立面/门窗表只计一次。
- 面积：矩形实例 `A_i = b_i × h_i`；异形按实际边界。总面积 `ΣA_i`，不得用某规格单樘面积乘未经去重的汇总数。
- 周长：矩形 `P_i = 2(b_i+h_i)`；门底是否计入、洞口/框外围口径按当前任务规则明确。
- 洞口边界传给砌体/围护作扣减，实例数量仍只在本 Skill 输出。

## 3. 设备与机电点位

- 泵、箱、洁具、喷头、风口、灯具、插座、探测器、摄像机等按物理安装实例计数。
- 成套设备内部组成若合同或设备表作为整套供货，物理子件和成套数量分别标明口径，不能相加。
- 在线附件与独立点位按系统拓扑判断：管路/风管中的在线阀件跟随相应网络，末端或独立设备归本 Skill；不清时建互斥表。
- 器具类型、唯一物理实例、供装范围和接口完整性分别记录。确认是地漏不代表应新增采购，明确不在本次供装范围也不抹去其图纸实例和类型证据。用户只补充器具名称时，不自动认定其新建或利旧范围。
- 末端高度推算先把端口逐个对应到实际器具，再使用本项目安装表。成对冷热水符号不能直接证明都是同一种洗手盆；有对应的可继续计算，未对应者另列，不将全组退回或统一套高度。
- 双联/多联、组合面板、多模块设备按设计标识和计量口径决定“一个物理组合”与“功能点数”，两种结果分列。

## 4. 表图对账

对每个规格输出 `图面实例数、表格声明数、差异、已解释项、未决项`。差异只能由明确的备用/拆除/变更/详图复制/漏画/漏表等证据裁决，不做强行平账。

## 5. 校核

检查物理 ID 唯一、坐标/房间归属、系统连接端点、表图差异、状态、规格和单位；点位数量与线路端点一一引用但不重复汇总。覆盖范围不完整时只形成“已确认实例子集”。
