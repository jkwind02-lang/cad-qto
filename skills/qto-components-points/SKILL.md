# 构件、门窗、设备与点位算量

先按用户目标定阶段：范围/能力问答只读相关边界与能力披露；用户仅要求已有明细复核时做表内复核；原始资料算量执行下文。用户要求检验或改进独立算量能力、底稿仅作参照时，执行[原图独立算量实测](../_qto-shared-evidence/references/原图独立算量实测.md)，不得因已有底稿或历史结果改成表内复核。表内复核不核准原图，细则按需见 [分阶段读取](../_qto-shared-evidence/references/按任务阶段读取.md)。

原图算量先读取并执行 [人工思路识图与算量流程](../_qto-shared-evidence/references/人工思路识图与算量流程.md)。模型负责依据图纸识别工程对象并形成可复核工作量，工具负责取证和计算；人工复核与正式采用另列，不以“用户尚未逐对象核定”代替模型识图。

先看图例、实际位置和设备/门窗表，再按区域识别唯一物理实例；核对父子块、重复视图和备用/拆除状态，计数后逐区回图并交接实际或未决端口。

以“一个物理实例一个稳定 ID”为核心。图块、表格行、图例和系统拓扑只是同一实例的不同证据，不得分别计数。当前整体为候选。

## 边界

读取 [范围与对象边界](references/范围与对象边界.md)。管段和在线附件归 `qto-pipe-networks`；风管及在线风阀的归属先按系统对象判定，风口和末端设备实例归本 Skill；电气线路只引用本 Skill 的末端点位，不重复点数；门窗/开启扇实例由本 Skill 输出，洞口扣减由砌体或围护 Skill 消费；设备基础实体归混凝土/钢筋等 Skill。

## 执行

1. 锁定项目、业务系统、楼栋、楼层/房间、图纸与表格版本、实例类别、输出单位和物理/清单/合同口径。
2. 原始资料按 [资料提取与来源核对](../_qto-shared-evidence/references/按任务阶段读取.md#原始资料与计算) 选择相应公共资源；未进入提取阶段时不展开其他资料类型。
3. 读取 [计算与证据流程](references/计算与证据流程.md)、[常规计算逻辑](references/常规计算逻辑.md)、[专业规则与成熟状态](references/专业规则与成熟状态.md) 和公共 [推算分层协议](../_qto-shared-evidence/references/推算假定与发布分层协议.md)，记录采用/试用/不适用/证据不足。未经真实案例升级的数量规则可以形成明确标识的规则推算量或方案暂估量，不得静默进入正式量。
4. 先由模型看图并结合图例、编号、可见几何和位置识别物理实例；从 CAD 中性事实起算时用 `scripts/build_component_instances_from_neutral.py` 展开嵌套块，以本轮模型工作识别记录（或确有的独立裁决台账）绑定规则和适用实例。格式见公共 [模型工作识别记录](../_qto-shared-evidence/references/模型工作识别记录格式.md)。模型判断可进入工作计数，不能写成人工核定；已有本轮可追溯实例账时直接复用。
5. 实例 ID 去重且类别、规格闭合后，用 `scripts/count_reconciled_instances.py` 复核数量和明确尺寸派生量；脚本不把图例、表格计划数或重复图块变成实例。先用插件脚本，不另写计数脚本。汇总只采用 `work_quantity_ready=true` 的计数：输入是适配器产出的 `点位唯一实例计数输入.json`（带 `geometry_review` 凭据，实例集指纹相符、未处置重复组为 0、工作包完整）。自造或改过的实例列表（`geometry_review` 为 `absent` 或 `mismatch`）只算算术复核，要回到适配器重做同位置审查；新增一批点位不继承旧批的审查。`work_quantity_ready` 只表示工作量可进汇总，`business_adoption_allowed` 才管正式采用，两者不能互相代替。
6. 需要向管网、风管或电气线路提供连接约束时读取 [跨专业端点事实](references/跨专业端点事实.md)，并运行 `scripts/build_network_endpoint_handoff.py` 对来源实例逐一标记 deliver、not_applicable 或 unresolved。交接必须保留坐标/拓扑位置、端口角色、直接或候选规格、传播范围、证据与假定编号；不得只输出类别和数量。设备数量仍由本 Skill 唯一统计。
7. 按 [结果检查与输出](references/结果检查与输出.md) 和公共 [成果约定](../_qto-shared-evidence/references/通用成果字段与状态.md) 输出；成熟度按 [案例与接入清单](references/案例与接入清单.md)。

## 正式采用停止与局部继续

以下条件只阻断受影响实例的正式采用。继续输出已确认实例、候选实例、差异对账、规则推算或多方案暂估；只有完成去重和可解释映射后仍无法形成候选时才使用 `null`：

- 图块、编号、图例或表格与实际位置不能一一或可解释地映射；
- 同一物理实例可能在平面、详图、系统图和表格重复；
- 图块为图例/示意/备用/拆除对象但状态未判定；
- 规格、楼层、房间或系统归属会影响分组但无法确认；
- 设备表数量是设计汇总还是实际实例不清；
- 需要派生门窗面积/周长但宽高、数量或单位缺失。

受影响正式结果为 `null` 或只报已确认实例子集；可复算的候选数量和端点规格按推算协议另列，不用 0 补缺。

## 禁止

- 不按块名、图层、颜色或最近文字直接计数；
- 不把图例符号、设备表汇总行、备用设备和 CAD 实例同时相加；
- 不把灯具/插座点数在电气线路 Skill 再计一次；
- 不把设备基础、连接管线、风管或电缆长度纳入实例数量；
- 不调用旧 Skill、旧归档脚本或旧结果。

## HTML图面复核交付

原图算量形成对象明细后，默认按公共[HTML交互复核与批注](../_qto-shared-evidence/references/HTML交互复核与批注.md)生成可离线点选的复核页，支持问题分组、成员例外、结论与原因、保存和处理回执。沿用共享生成器，不在项目重写前端；收到意见后由本专业复算并更新采用状态，用户方法意见不自动等于数值确认。纯问答、无图表内复核及用户指定其他形态按实际范围处理。

## 已识别对象的路径与重算接续

本轮对象关系已由模型读图形成后，按公共[按人工算量顺序执行与重算](../_qto-shared-evidence/references/按人工算量顺序执行与重算.md)使用完整曲线分段、跨图接口、端口坐标或电气路径台账；修改已确定的参数/规则时保留依赖重算结果。只读取与本任务相关的小节，不自动扩大专业范围。原始识图责任、候选成熟度和正式采用边界不变。
