# 结果检查与输出

- 回路表、系统图、平面/模型和端点是否版本闭合；
- 三维路径是否含竖向、上下翻、跨层和箱柜/设备进出段；
- 桥架共享段、导管并列根数和每条线缆遍历是否各自回放；
- 附加/预留是否逐处有规则，是否与比例或固定值重复；
- 桥架、导管、电缆、电线、母线、配件、支架和点位是否唯一出口；
- 长度 `m`、配件 `个/套`、重量 `kg/t` 分项，规格/系统/回路不静默合并；
- 候选规则只支撑候选参考量，未知为 `null`。

建议输出系统回路表、路径段账、通道明细、线缆遍历表、附加长度表、配件/支架、点位接口和未决事项。

否定结论（“图上无”“未见”“不存在”等）是否都附检索记录，反向核对是否写明覆盖的图纸集合并覆盖所有可能含该类对象的图；没有检索记录的否定结论报待确认，不作为不计或判定清单有误的依据。格式见公共[通用成果字段与状态](../../_qto-shared-evidence/references/通用成果字段与状态.md)“否定结论与检索证据”，检索记录用公共 `search_negative_evidence.py` 出，见公共[否定结论检索](../../_qto-shared-evidence/references/否定结论检索.md)。

**清单闸门**：下面两种条目，必须引用检索记录，而且这条记录检索过“表与说明”类图页（设计说明里的导线、敷设条款，见[计算与证据流程](计算与证据流程.md)开头）：
- 清单有量，本次判“图上无”或本次量为 0；
- 本次量与清单量相差超过清单量的 10%（默认 10%，与[计量口径选择](计量口径选择.md)用法第 4 条共用同一个阈值，不另设；项目可在口径决定单里改）。

写法：
- 判“图上无”的成果项写 `否定结论`（结论、检索记录编号、清单量）。公共校验器会核：记录存在且齐全；有命中的，否定结论不成立；待确认的不能写已确认零值；清单量大于 0 的，记录要检索过“表与说明”。
- 相差超过阈值、但不是“图上无”的，在清单对照表里写检索记录编号。差多少算超阈值，由对照表给，校验器不重算。
