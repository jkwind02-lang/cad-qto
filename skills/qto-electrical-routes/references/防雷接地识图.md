# 防雷接地识图

防雷接地图对象少、线长，但一张图里常叠着几个视图，图层也混用。计数和取长之前，先按下面几步认图和去重。

## 对象与唯一出口

| 对象 | 常见表达 | 数量 |
|---|---|---|
| 接闪带、避雷网 | 屋面和女儿墙上的连续线、网格，旁注材料规格（如镀锌圆钢、扁钢） | 本 Skill，m |
| 引下线 | 屋面平面上柱位处的圆圈或专用符号，旁注“利用柱内主筋”等 | 本 Skill，m |
| 均压环 | 沿外墙圈梁、按层设置的环，或说明里规定的楼层 | 本 Skill，m |
| 接地网、接地母线、接地线 | 基础接地平面上的网格和连线 | 本 Skill，m |
| 等电位联结线 | 局部等电位、门轨、金属构件的联结线 | 本 Skill，m，单独分项 |
| 接地极、端子箱、测试点、断接卡 | 块、图例符号 | 按任务范围定唯一出口（点位或本 Skill），见[范围与对象边界](范围与对象边界.md) |

图层名常含“防雷”“避雷”“接地”“LPS”“GND”，但以图例、旁注和走向为准，不按图层名直接归类。

## 认图与去重

1. **一个图框里有几个视图。** 小单体（如门卫）常把屋顶防雷平面和基础接地平面画在同一个图框里，引下线圆在两个视图各画一次。先按视图标题和范围把图元分到各视图，引下线只在一个视图计数，或按柱位去重。不能整框按块数计。
2. **屋面网格可能画在别的楼层图上。** 主屋面避雷网格可能画在顶层平面，甚至更低一层的平面图上（多层厂房的局部屋面）。先按图签和视图标题找出所有含屋面范围的图，再判断哪张是屋面网，不能只看名为“屋面”的那张。
3. **接地层混着别的线。** 接地图层上可能混有等电位联结线（如伸缩门导轨）、沿墙扁钢等，要按旁注和走向拆出来，归入对应项或清单外，不并入接地网长度。
4. **同一对象在两张图上各画一次**（如屋面图和顶层平面图），按跨图对应确认是否同一实物，不各计一次。

## 引下线

- **双向核对。** 从屋面引下线圆找柱位，从结构或建筑平面的柱位（以及说明里规定的引下线柱）找屋面圆。屋面有圆却找不到柱、或柱位有标注而屋面没有圆的，列待办，不按一侧补齐。
- **内柱上下贯通算不算引下线**，按[计量口径选择](计量口径选择.md) Q1 处理。
- **高度先查本图。** 单根高度取接地连接点到屋面接闪带的高差。先查本图说明（建筑高度、檐口或女儿墙标高）、立面和剖面。只能从别的单体类推时，标为假定、方案暂估，不写成确认。

## 端子箱与设备接地

屋面局部等电位端子箱、设备接地块，要和屋顶接地平面上的对应位置一一对上。写清对应依据（位置、编号、旁注），对不上的列待办。

## 长度

按图示长度计。计量规范规定的附加长度比例（如接地母线、避雷网按全长附加）从规范原文取，单列为附加，不并入图示长度。口径未定时按[计量口径选择](计量口径选择.md)处理。
