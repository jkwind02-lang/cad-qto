# 电气原图对象绑定与同包回图

模型先按本专业计算与证据流程判明系统、回路、规格、敷设方式、物理通道和实际端点，再用本入口将**选择的原图对象**绑定为可复算、可回图的同一对象包。本工具不识别回路语义，不按设备名或最近距离选路，也不批准工程量。几何自洽仅证明选择、计算与叠加一致；回路语义仍须对照系统图、回路表和平面。

## 输入与来源

`scripts/bind_electrical_objects.py` 接受 `qto-electrical-object-request/1.0`。`--cad-manifest` 是本轮完整WCS中性取证清单；同源原图、清单、布局流、块定义流的指纹在前后核对。原图换版、单位冲突或文件变化使绑定失效，不按同句柄继续继承。

请求至少包括：

| 字段 | 含义 |
|---|---|
| `project_id / drawing_id / review_id / title` | 本轮范围和复核身份 |
| `cad_manifest_sha256 / source_sha256` | 中性清单与其权威原图的完整SHA256 |
| `layout / unit / expand_blocks` | 布局、`factor_to_m`及`basis`、显式展开块。单位依据复用中性来源单位约束；无单位需已有文字与几何佐证，不默认mm |
| `route_layers` | 本次应处理的线路图层正则，用于真实覆盖差集；不是只对已选清单作自证 |
| `measurement_mode` | 明确 `plan`（投影水平量）或 `spatial`（原WCS实长） |
| `measurement_basis_source_ids` | 本图量测模式依据的可回读源实体ID |
| `connection_tolerance_m` | 数值/端点检验容差，0～0.01m；不作为未画连接补长。非数值误差的残差仍列未画连接未决 |
| `sheets` | `sheet_id / floor / bounds`，bounds用**原图坐标单位**；不猜图页、楼层或原点 |
| `endpoints` | 以下实际连接口或曲线节点；不由名字建立连接 |
| `objects` | 每一物理通道或每一线缆对象的身份、规格、根数、有序原段、起终端、依据和未决 |
| `exclusions` | 可选，原段同样的精确区间绑定＋`reason`与`basis_source_ids`，从未处理差集中分列；不可与计量区间重叠 |

### 原段与端点

每个 `steps[]` 写 `source_id / instance_path / part_index / fraction_range / direction / sheet_id / floor / role / basis_source_ids`。顶层是 `CAD-句柄`；嵌套是 `CAD-顶层/块名/CAD-子句柄/...`，须与实际完整实例路径一致。同一块定义句柄的不同插入不合并。

`fraction_range: [lo,hi]` 满足 `0<=lo<hi<=1`，是**该原几何部件的参数比例**，不是弧长比例。`direction` 明确为 `1` 或 `-1`。反向不写倒置区间。跨越闭合曲线参数零点时拆为末区间与首区间，按实际行走顺序列出。整环自动拆成两个非零路径，不拿首尾弦长当环长。

共同分界只规范必要的浮点表示误差：同一原部件的边界须同时满足差值不超过2个IEEE-754 ULP、其投影前原WCS曲线微区间实长不超过1nm，才可引用已有边界值。规范组有整体跨度限制，不能逐点链式扩大；不得把任何一个明确声明的正长度原区间合并成零。工程连接容差不参与这一步。极大尺度下即使只差1 ULP，只要实际弧长差可辨，也保留原分界和真实未处理差集。路径引用与覆盖并集在规范后做精确区间判别，不用固定比例epsilon吞掉间隙。

对象`source_steps.fraction_range`保留原请求区间，`normalized_fraction_range`给实际共同路径引用区间；排除项也分列二者。包的`interval_normalization`记录每个原值、采用值、实际边界弧长残差及双门阈值。直线残差按总实长×参数差计算，避免大坐标端点相减抵消；曲线仍用公共曲线积分。路径ID用可往返的17位有效数字表达，避免可辨的相邻分界生成同ID。

程序回取WCS直线、圆弧、椭圆弧和多段线部件，复用公共曲线积分与块实例变换。部分椭圆弧按所选参数区间独立积分，不把整弧长度乘比例；不支持曲线、缺失部件、区间越页等保留未决，不降成弦长。

`role` 是 `horizontal / vertical / offset`。`plan` 只接纳horizontal；水平弧与直线按平面投影，真实竖向/上下翻另外列分量。非水平圆锥曲线的plan投影保守拒绝。需要真实三维原画线时用spatial；有据标高差仍走T36的 `elevation_difference` 与 typed `elevation_link`，不将安装基准高当真实接线口。

电缆/电线起终端须 `kind: connection_port`，复用现有 `Evidence.port`：

- `manifest_sha256`、`physical_source_id / physical_id`、`instance_path` 指向本图实际INSERT实例；
- `port_source_id` 必须来自该实例内部的POINT或有据LINE端，`locator` 为 `point / line_start / line_end`；
- `basis / basis_source_ids` 保留连接依据；可选`point_m`仅用于核对，不能覆盖回取坐标；
- 插入点、图符中心、文字位置和相邻实例同名口均不具备连接口资格。

通道边界可用 `kind: curve_node`，写实际 `source_id / instance_path / part_index / fraction / basis_source_ids`。此节点不能冒充设备端口。图上交叉不会产生额外连接；只有模型明确有序选定且各段端点几何相接，才能组成路径。同名但坐标不接的节点不通过。

### 物理对象、共享与未知分量

对象写 `id / physical_id / kind / system / spec / parallel_count / start_endpoint / end_endpoint / basis_source_ids`，以及 `steps`。支持原类型 tray/trunking/conduit/busbar/cable/wire。每个物理通道根数为1；多个实际通道应独立实例。多根同规格线缆可合并 `parallel_count`，但须给数量相等且全局唯一的 `conductor_instance_ids`，各根保留身份。

所有对象的原曲线区间先按共同边界拆为最小路径；桥架与电缆引用同一组路径，不各算一份不一致长度。不同电缆可合法共用，须共同引用实际绑定的 `channel_ids`；桥架仅按物理通道计一次，各根电缆分别计。相同physical_id、同一对象重复区间、同源同区间被两个通道认领拒绝。图形相同但源身份不同的共线直线仍复用L4重合候选；只有源依据充分的 `keep_both` 才认定不同实物，不自动扣减。需要扣掉的旧线先按精确区间进入`exclusions`。

`component_evidence` 对 `vertical / terminal / reserve / undrawn_connection` 分别声明：

- `pending`：保留未知；缺失声明也按pending，不能解释成0；
- `not_applicable`：须有 `basis / source_ids`，明确本对象、此范围确实不涉及；
- `provided`：同样有依据，vertical须有实际竖段，terminal/reserve须有对应 `extras`。

extras须按原路径台账契约保留id、端头`endpoint_id`、basis、source_ids、length_each_m，增加component、length_basis、basis_ids；规则推算用network_model、假定用assumption。actual_drawn_path只能由steps取原曲线，不能给extras自报“实际长度”。未画连接不能藏进端头extras；该部分继续待办并交既有台账分层建段。本入口不为闭合补直线、不默认竖向或预留。

## 消费已有走线追踪

已有 `trace_drawn_routes.py` 结果可作为 `trace_result: {path,sha256}` 绑定，必须同版清单、原图及相同单位的plan模式。对象写 `trace_route_id`，不同时写steps；`trace_context` 给图页、楼层及basis_source_ids，跨页可用 `trace_segment_context[完整segment_id]` 分别给。

适配器从每个SEG的完整source_id与part_index回取原曲线，按fraction_range及from/to恢复方向，再复算最小段；trace声明长度不能覆盖回算。原trace复核标记继续保留。存在补桥、重合扣减或方向不能唯一恢复时，须改为模型逐项显式对象，不能把它们塞进actual_drawn_path。`route_circuits_on_trays.py` 的network_model输出不属于已画走线，拒绝假冒；T32/T33仍用于先取得回路/通道候选和来源，不等于实画语义确认。

## 计算、回图与命令

```text
python skills/qto-electrical-routes/scripts/bind_electrical_objects.py --cad-manifest <CAD中性取证清单.json> --request <电气对象请求.json> --output-dir <新的中文结果目录> --build-review
```

输出目录已存在时拒绝覆盖，保护旧对象包与用户批注。主输出：

- `电气对象包.json`：schema `qto-electrical-object-package/1.0`，包含对象、源区间、共同最小ledger、quantity_result、coverage、overlap_review、todo和前后指纹。机器字段约束见[对象包schema](电气原图对象包.schema.json)。
- `路径台账.json / 数量复算.json`：既有 `qto-electrical-path-ledger/1.0` 与计算结果。同一个包导出，不另造人工长度表。
- `对象叠加.csv / 图页.csv / 场景映射.json`：调用现有scene生成器的原接口。catalog_key为`电气对象|physical_id`；direction、规格、根数、区间、完整实例、共同路径使用、指纹及可选decision_id作为attributes，保持现有审核事项接线。方向由有序折线点及direction属性表示；原图底图和叠加坐标使用同一绘图单位。
- `复核视图.json / 电气对象复核.html / 场景检查.json / 调用回执.json`：`--build-review`实际调用既有reference计算入口、scene生成器和共享HTML生成器，记录每个真实退出码；reference CLI结果与包内结果须完全一致。HTML本地单文件可离线使用，工具不重写前端。

分层显示直接消费同包`quantity_result.items`，不能只从对象包外层已有总数导出。`对象叠加.csv`和场景属性保留`quantity_level / quantity_basis / basis_classification_complete`、每根`length_components_each_m / length_by_basis_each_m / extra_each_m / extra_by_basis_each_m`、已含根数的已知/完整量、未决与来源。假定附加量的说明、basis_ids和source_ids取自同包ledger.extras，作为依据明细显示；不据明细重新计算层级。缺失字段为null，数量层级缺失显示“数量层级未决”，未知附加量不补0。

一个对象可能有多行原图分段，既有scene映射仍用group_by合成一个物理对象，并继续禁止分段行带数量直接相加。绑定入口在scene生成后按唯一catalog_key将引擎数量投影到原`view.objects[].quantities`接口，再重新normalize，保留几何阶段指纹并刷新最终结果指纹，交原HTML生成器。每对象只投影一次；参考总量已经由计算引擎包含根数，导出不再乘根数；每根实画/附加量另标清楚。正式采用长度始终null。`同源数量投影检查.json`记录来源、数量未重算和投影前后指纹，`场景检查.json`同步最终指纹。

ledger及端口校验统一m；叠加与DXF背景按原图mm/m，图页length_factor明确换算。其他已知工程单位可生成对象包计算，但现有scene底图只接mm/m，本入口保守拒绝其`--build-review`，不静默换底图或改比例。曲线可视化按参数取点，精确量来自曲线积分，显示折线长度不得替代计算量。全部工程对象未定位时，额外输出明确标注“不计工程量”的原图图页外框范围参照，以保留同版底图与来源身份；未知对象本身仍为unlocated，不把外框当其位置。

`known_path_length_each_m`是已绑定原段每根量；`known_length_m`是包含明确附加量的已知参考小计；有未决时`complete_length_m: null`，`official_length_m`始终null。外层完整量不能用内层legacy结果的小计替代。coverage按图层与声明图页枚举原图部件，区间满足计入、排除、未处理差集分列；块未展开、不支持实体与未处理区间都显式保留，不能凭选中对象全部自洽宣称整图完整。

退出码0为本范围绑定/调用检查通过、参考候选仍待工程语义复核；3为有未决/覆盖差集/trace复核标记；2为输入、来源、重复认领或下游调用错误。任何一个均不是正式采用或真实项目准确率。
