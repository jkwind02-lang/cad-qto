# 范围与对象边界

最小对象是一段唯一物理通道或一条明确回路中的一根电缆/电线/母线段，至少带系统、回路、规格、敷设方式、三维端点和来源版本。

| 对象 | 唯一出口 |
|---|---|
| 导管、线槽、桥架、母线及弯通/变径/连接/隔板 | 本 Skill |
| 电缆、电线、控制线、光缆及明确附加长度 | 本 Skill |
| 桥架专用支吊架 | 本 Skill；综合支吊架按批准方案确定 |
| 灯具、开关、插座、探测器、摄像机、箱柜和设备实例 | `qto-components-points` 输出数量；本 Skill 引用端点 |
| 流体管道、风管 | 对应管网/风管 Skill |

箱柜本体数量归点位，但柜内/端接附加线缆是否计入本 Skill 由项目口径决定。接地干线/支线作为电气线路，接地极等离散实例按任务范围确定唯一出口并记录。
