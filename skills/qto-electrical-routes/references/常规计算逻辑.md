# 常规计算逻辑

## 1. 通道长度

- 路径段三维长度：直段 `L=sqrt(Δx²+Δy²+Δz²)`，正交折线路径按各段求和；楼层竖向、上下翻和箱柜进出段必须显式建立。
- 桥架/线槽/母线物理长度：`L_channel=ΣL_unique_segment`，共享段只计一次；并列多列/多层桥架按实际物理通道数量分别计。
- 导管长度：每根导管按实际路径累计；同一路径并列 `n` 根时为 `n×L_path`，分支后分别累计。

## 2. 电缆与电线

- 单根电缆：`L_cable = ΣL_traversed_segments + ΣL_vertical/offset + L_explicit_extra`。
- 同规格并行 `n` 根：`L_total=Σ(n_path×L_path)+Σ明确的逐根附加长度`；不同回路和不同规格分组。
- 电线：每根导线按实际导管/线槽路径计量；相线、中性线、保护线、控制线数量来自明确回路配置，不能默认“管长×固定根数”。
- 多芯电缆的“芯数”是规格属性，通常不将一根多芯电缆长度乘芯数冒充电缆长度；若任务需要导体总长度，另列口径。

## 3. 附加长度与预留

盘柜、设备、接线盒、终端、伸缩或检修预留只按当前项目规则或明确尺寸逐处增加。附加比例、波形余量、损耗和采购盘长不默认进入设计物理量。每项附加量记录端点、规则和公式，防止同一处既按比例又按固定长度重复。清单计量口径下的电缆预留（按计量规范表、按项目规定或不计）见[计量口径选择](计量口径选择.md) Q7：预留单列，不并入设计物理长度。

## 4. 配套构件

- 桥架弯通、三通、四通、变径、连接片、盖板、隔板和伸缩节按物理实例/实际覆盖长度分列。
- 支吊架由明确间距、首末支架、转弯分支和设备附近加固形成；桥架专用支架由本 Skill 输出，综合支架需批准方案。
- 防火封堵、套管和开孔按接口实例建立，实体修补/洞口扣减交相邻土建 Skill，保持唯一出口。

## 5. 校核

回路起终端、路径段序列和点位 ID 连续；桥架共享段不乘回路数；导管根数和线缆根数各自可回放；平面+竖向+附加=明细总长；系统图、回路表、平面点位数量差异有解释；不同规格和单位不混合。缺口为 `null`。

## 路径台账执行入口

已由本轮读图识别路径、通道和回路时，使用`qto-electrical-path-ledger/1.0`及`scripts/calculate_electrical_paths.py`复算。现有参考计算入口也接受新契约；旧route_items保留。字段和作用边界见公共[执行与重算](../../_qto-shared-evidence/references/按人工算量顺序执行与重算.md)。新增脚本不识别原图回路，不能仅靠改输入schema升级业务采用。
