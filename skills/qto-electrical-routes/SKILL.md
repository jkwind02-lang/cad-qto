# 电气线路与通道算量

先按用户目标定阶段：范围/能力问答只读相关边界与能力披露；用户仅要求已有明细复核时做表内复核；原始资料算量执行下文。用户要求检验或改进独立算量能力、底稿仅作参照时，执行[原图独立算量实测](../_qto-shared-evidence/references/原图独立算量实测.md)，不得因已有底稿或历史结果改成表内复核。表内复核不核准原图，细则按需见 [分阶段读取](../_qto-shared-evidence/references/按任务阶段读取.md)。

原图算量先读取并执行 [人工思路识图与算量流程](../_qto-shared-evidence/references/人工思路识图与算量流程.md)。模型负责依据图纸识别工程对象并形成可复核工作量，工具负责取证和计算；人工复核与正式采用另列，不以“用户尚未逐对象核定”代替模型识图。

先将系统图、回路表与平面配对，从箱柜沿回路追踪至末端；分清共用通道与每根线缆，计算三维路径及有依据的附加量，再回图对回路和端接。

以“系统—回路—物理通道—三维路径—导管/桥架—电缆/电线—端点”为链。桥架长度、导管长度和穿行其上的每根线缆长度分别计算，不互相替代。当前为完整常规逻辑候选。

## 边界与执行

先读 [范围与对象边界](references/范围与对象边界.md)。灯具、开关、插座、探测器、摄像机和设备实例由 `qto-components-points` 唯一计数，本 Skill 只引用端点；桥架专用支吊架跟随本 Skill；综合支吊架无批准深化时未决；水管和风管分流。

1. 锁定项目、系统、配电层级/回路、楼栋楼层/区域、平面/系统图/配电表/桥架深化/变更版本、敷设方式和物理/清单/合同口径。
2. 原始资料按 [资料提取与来源核对](../_qto-shared-evidence/references/按任务阶段读取.md#原始资料与计算) 选择相应公共资源；未进入提取阶段时不展开其他资料类型。
3. 读取 [计算与证据流程](references/计算与证据流程.md)、[常规计算逻辑](references/常规计算逻辑.md)、[专业规则与成熟状态](references/专业规则与成熟状态.md) 和公共 [推算分层协议](../_qto-shared-evidence/references/推算假定与发布分层协议.md)，记录采用/试用/不适用/证据不足；未升级规则可形成规则推算量或方案暂估量，不静默进入正式量。
4. 为物理路径段、桥架/线槽/导管、弯通连接、每条电缆/电线/母线和端接建立稳定 ID；按系统、回路、规格、敷设方式和区域分组。
5. 路径、并行根数及每根明确附加长度都闭合时，可用 `scripts/calculate_electrical_routes_reference.py` 复算候选参考长度；脚本不识别回路、不自动寻路、不默认垂直或预留。
6. 按 [结果检查与输出](references/结果检查与输出.md) 和公共 [成果约定](../_qto-shared-evidence/references/通用成果字段与状态.md) 输出；案例门见 [案例与接入清单](references/案例与接入清单.md)。

## 正式采用停止与局部分支继续

以下条件只阻断受影响结果进入正式量；已知回路、候选路径、端点约束和附加长度方案继续输出，无法形成有意义候选才使用 `null`：

- 平面、系统图、回路表、设备端点或变更不能唯一配对；
- 只有二维路径，竖向、跨层、上下翻、箱柜进出线或设备端接缺失；
- 电缆/电线规格、芯数、根数、回路归属或敷设通道未确认；
- 共享桥架中的回路占用、分支/合流或重复路段不能回放；
- 附加/预留/松弛、终端和盘柜内长度缺项目依据；
- 桥架弯通、变径、隔板、连接、支吊架或综合支架方案未闭合。

受影响正式结果为 `null`；安全闭合路径、规则推算和方案暂估按数量层级分列。

## 禁止

- 不把平面投影直接当完整三维路径，不以最近回路文字传播规格；
- 不把桥架物理长度乘回路数，也不把一根导管长度冒充其中全部电线长度；
- 不默认竖向高度、附加率、预留长度、芯数、并行根数、弯通或支架间距；
- 不重复统计末端点位，不进行负荷/选型设计；
- 不调用旧 Skill、旧归档脚本或旧结果。

## HTML图面复核交付

原图算量形成对象明细后，默认按公共[HTML交互复核与批注](../_qto-shared-evidence/references/HTML交互复核与批注.md)生成可离线点选的复核页，支持问题分组、成员例外、结论与原因、保存和处理回执。沿用共享生成器，不在项目重写前端；收到意见后由本专业复算并更新采用状态，用户方法意见不自动等于数值确认。纯问答、无图表内复核及用户指定其他形态按实际范围处理。

## 已识别对象的路径与重算接续

本轮对象关系已由模型读图形成后，按公共[按人工算量顺序执行与重算](../_qto-shared-evidence/references/按人工算量顺序执行与重算.md)使用完整曲线分段、跨图接口、端口坐标或电气路径台账；修改已确定的参数/规则时保留依赖重算结果。只读取与本任务相关的小节，不自动扩大专业范围。原始识图责任、候选成熟度和正式采用边界不变。

## 长任务持续执行

多图、多范围或需要修改后复算时，按共享[项目作业台账与持续执行](../_qto-shared-evidence/references/项目作业台账与持续执行.md)建立或恢复本任务；本专业继续主责识图、规则解释和计算。依照[各专业持续算量执行路径](../_qto-shared-evidence/references/各专业持续算量执行路径.md)先完整做通代表范围，再处理同族对象及例外。用 `next` 推进局部取证、模型输入、实际计算和回图检查，尚可处理的工作持续完成；不要只交清单让用户代做。

物理对象与应计量项分开登记，结果引用本次原生文件及对象身份；复核视图从同一结果索引绑定。当前任务的有效检查点可恢复，图纸、规则或输入变化则沿依赖重算；独立复测使用新任务身份并隔离旧结果。程序完成不替代专业复核及正式采用。
