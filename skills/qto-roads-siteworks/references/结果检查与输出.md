# 结果检查与输出

- 范围是封闭面还是中心线推算；HATCH 身份、单位、空洞、重叠和未覆盖区是否披露；
- 各层边界与厚度是否独立确认，是否错误复制面层面积；
- 交叉口、扩幅、曲线、岛头、转角和端部是否去重；
- 面积 `m²`、体积 `m³`、长度 `m`、构件 `个` 是否分项；
- 道路土方、挡墙、管网、建筑面层是否排除；
- 局部成果是否明确“已证实部分”，未知为 `null`，零值有覆盖复核。

建议按道路/地块—结构层—材料/规格—区域输出，保留原始面积、扣减/并集、厚度、公式、来源、规则和未决项。

否定结论（“图上无”“未见”“不存在”等）是否都附检索记录，反向核对是否写明覆盖的图纸集合并覆盖所有可能含该类对象的图；没有检索记录的否定结论报待确认，不作为不计或判定清单有误的依据。格式见公共[通用成果字段与状态](../../_qto-shared-evidence/references/通用成果字段与状态.md)“否定结论与检索证据”。
