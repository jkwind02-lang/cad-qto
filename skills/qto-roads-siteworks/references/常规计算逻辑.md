# 常规计算逻辑

## 1. 平面面积

- 封闭面优先：`A_net = Area(union(有效外边界) - union(孔洞/排除区))`，相邻地块公共边不得形成重叠面。
- 等宽直段：`A = L_centerline × W_effective`，仅在转弯、交叉口、扩幅、中央分隔和端头已单独处理时适用。
- 变宽分站段：若相邻桩号间宽度线性变化，`A_i = ΔL_i × (W_i + W_{i+1}) / 2`；非线性或复杂交叉口使用真实封闭面。
- 坡面铺装使用实际坡面面积；仅平面投影和坡度已闭合时可按几何换算，不能把平面投影直接当坡面。

## 2. 结构层

- 等厚且范围一致：`V_layer = A_layer × t_layer`。
- 变厚分区：`V = Σ(A_j × t_j)`；若厚度沿单一方向线性变化且边界闭合，可用分段平均厚度，但必须保留分段点。
- 每层实际边界独立确定；基层外扩、路肩、找平层、土工材料和面层不默认同面积。
- 土工布/格栅按确认铺设面面积；搭接只有在设计或项目计量口径明确时另加。

## 3. 线性及附属构造

- 路缘石/路平石：按实体中心线或设计计量线净长，交叉口、出入口、端头和共边去重；弧段用弧长。
- 沟渠：长度按沟中心线/净长；混凝土或砌体体积可由已确认断面面积×长度分段复算，归属混凝土/砌体时保持唯一出口。
- 停车位、人行道、广场、植草砖和绿化按闭合分区面积；标线按实际线长/面积另列，不能并入铺装面积。

## 4. 纵横断面与土方接口

道路结构构造底界与路床/土方交接标高必须一致。路床以下挖填交土方 Skill；本 Skill 向其提供已确认道路底界，不在两处重复计算。挡墙、管网和井类同理使用稳定接口对象。

## 5. 校核

分区并集面积与总边界守恒；各层体积/面积/厚度量纲一致；桩号分段连续且无重叠/断档；路缘、沟渠与平面边界长度可回放；局部 HATCH 覆盖率明确。无法闭合时只报已证实局部。
