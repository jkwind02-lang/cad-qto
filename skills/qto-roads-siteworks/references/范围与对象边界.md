# 范围与对象边界

最小对象为可唯一定位的封闭地块、道路段、结构层或线性附属构造，至少带区域、几何来源、做法/断面、版本和输出单位。

| 对象 | 唯一出口 |
|---|---|
| 道路面层、基层、垫层、场坪、停车位、人行道、室外铺装 | 本 Skill |
| 路缘石、路平石、排水明沟、边沟、绿化地块 | 本 Skill；构件尺寸或断面必须明确 |
| 路床以下挖填、换填和土方平衡 | `qto-earthwork-terrain` |
| 挡土墙主体混凝土/模板/钢筋 | 混凝土模板与钢筋 Skill；本 Skill 只保留道路接口 |
| 雨污水管网、检查井 | 管网与点位 Skill |
| 建筑室内地面、建筑台阶/坡道面层 | `qto-surfaces-envelope`，项目明确为道路场地时除外 |

同一封闭边界可作为多个结构层的来源事实，但每层的实际范围和厚度必须独立确认。
