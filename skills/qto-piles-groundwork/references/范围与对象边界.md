# 范围与对象边界

最小对象为一根物理桩、一个桩段/接头或一个地基处理单元/区域。

| 对象 | 唯一出口 |
|---|---|
| 灌注桩/预制桩/钢桩根数、桩长、成孔、灌注、护筒、接桩、截桩 | 本 Skill |
| CFG、水泥土搅拌桩、高压旋喷、碎石桩等处理桩及注浆 | 本 Skill |
| 强夯、换填、褥垫层和处理面积/体积 | 本 Skill；大面土方只接收交界 |
| 桩身钢筋笼、预应力筋 | `qto-rebar` 或对应专项，桩 ID 由本 Skill 提供 |
| 承台、筏板、基础梁、桩帽 | `qto-concrete-formwork`；钢筋另归钢筋 Skill |
| 基坑、场地和外运土方 | `qto-earthwork-terrain` |

灌注桩桩身混凝土留在本 Skill，避免与通用混凝土构件重复；承台从桩顶界面开始由混凝土模板 Skill 输出。
