# 矩形换填区域来源复算

`scripts/calculate_groundwork_regions_reference.py INPUT --output OUTPUT` 计算同一竖向范围内、等厚一层的矩形换填区域，并先对扩边区域求平面并集。它不计算桩身、成孔、基坑开挖、一般回填或土体状态换算，不自动识别持力层或决定施工方案。

输入 `schema: qto-groundwork-regions-reference/1.0`，含 `source`、`unit_evidence`（与阶形基础入口一样绑定实际单位说明）、`regions` 和恰好一条 `layers`。

每区域声明 `physical_id`、`footprint_object_id` 和 `extension_rule`。脚印由当前 DXF 重读，限轴对齐的水平矩形。扩边规则含 `numerator/denominator`、实际原图分数文字的 `source_note` 和最小扩边距离的 `minimum_note`；后者以 `{object_id,text_contains,pattern,group,unit}` 提取。按各方向宽度分别求每边扩距，再与明确最小值比较。规则没有默认扩边或经验面积系数。

层含 `layer_id`、`material`、`earth_state`、`thickness_note`、`material_note`、`same_vertical_extent_note`。材料及状态是模型解释，来源文字必须实际存在；同一底标高、厚度及设计适用范围由识图者逐区域核对。标高不同、变厚或多材料分层须分开处理，不可由本平面并集入口代替三维并集。

输出各原脚印、扩边区域、逐区面积和、并集面积、重叠扣减、并集几何及层体积。相同源轮廓或物理区域不能换编号重复计算。固定 `REFERENCE_ONLY`、`business_adoption_allowed:false`，拒绝覆盖已有文件。CAD轮廓尺寸与设计标注有差异时分别保存图面参考和设计方案，不悄悄调坐标去贴结果。施工实测、质量检测及正式采用另核。
