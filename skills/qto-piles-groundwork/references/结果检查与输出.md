# 结果检查与输出

- 桩位、桩表和施工记录是否按稳定 ID 对账，试/工程/补/废桩是否分状态；
- 桩顶桩底及高程基准是否一致，设计/施工/清单长度是否分链；
- 桩径/截面、扩底、变径、空桩、超灌、充盈、护筒和接头是否有依据；
- 根、m、m²、m³、个/套及材料量是否分成果项；
- 桩身与钢筋笼、承台和土方是否重复；
- 候选规则只支撑候选参考量，未知为 `null`，真正零值有覆盖证据。

建议输出桩实例账、分组长度、成孔/灌注/实体体积、附属量、处理区/处理单元、接口表和未决事项。

否定结论（“图上无”“未见”“不存在”等）是否都附检索记录，反向核对是否写明覆盖的图纸集合并覆盖所有可能含该类对象的图；没有检索记录的否定结论报待确认，不作为不计或判定清单有误的依据。格式见公共[通用成果字段与状态](../../_qto-shared-evidence/references/通用成果字段与状态.md)“否定结论与检索证据”。
