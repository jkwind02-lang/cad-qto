# 块实例归属修复与有限实图复核

当冻结的有效识别规则排除一个符号块，或把它整体纳入附件数量时，块内轮廓仍可能被通用图层规则纳入管长，形成重复或错误计量。本次在对象选择审计前落实实例归属：已处置父块控制后代，后代保留原实体身份、父实例和规则证据，不另形成管段或附件数量。

只修改 `skills/qto-pipe-networks/scripts/build_pipe_inference_input.py`。安装版本、规则权限门、系统/DN判断和计量条款未更改。有效排除对父插入点在局部窗外的后代同样生效；窗外附件不会因此被纳入数量。未决或不匹配的普通工程容器不吞掉已明确选中的工程曲线。嵌套实例使用完整实例路径，按外层已处置实例归属；查找按路径深度完成。

本地手算反例使用5m工程线与0.675m符号线：旧源码12项中10项失败、2项通过；修复后12项通过。覆盖整体纳入/排除、嵌套、单位mm/m/in、改名、未决容器及窗外父块。完整开发副本455项回归通过；这不代表全项目或全专业识别准确。

有限实图对照先冻结原图、对象和独立规则，再运行插件。复现一个流向箭头实例：父块排除时旧版仍纳入其0.675m内部图元，修复后为0；真实中心线保持0.650250071756m。这个差值属于冻结局部配置的复现，不是历史全图工程量偏差声明。

三个混合DN详图路径独立核算使用原始端点、弧长弦逼近及原图异径端面，分规格最大差约3.50e-9m。两台设备、供回水各两支路及限定共享干管的唯一图示轴长55.837652841383m；简单逐台路径相加会重复共同段3.326255759414m。现有拓扑唯一实体归属正常，本轮未改该算法。

4个图示管端与设备轮廓端点均绑定；换错供回水系统后4个均拒绝，重复实体输入拒绝。两个局部干管截断点提供窗外原实体延续证据后为“边界管件未决”；省略边界上下文会形成两个假弯头候选。窗外事实不计长度。

仍未解决或未覆盖：厂家真实管口/高度、阀件扣减及计价边界、全部DN自动传播、附件分类自动闭环、外参和阵列全图端到端、医院新图前向识别。模型工作识别未人工复核，结果不自动变为正式可采用工程量。历史对象选择已见过，不能称盲测。
