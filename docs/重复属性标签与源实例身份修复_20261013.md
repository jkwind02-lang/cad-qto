# 重复属性标签与源实例身份

同一 INSERT 的多个 ATTRIB 可以使用相同标签。旧索引展开属性时按标签查找第一个源属性，导致后续属性复用了第一个句柄，正常图纸也会报“实例身份碰撞”。

现在按附着顺序对应原属性与阵列单元的复制属性，保留每个源句柄、文字和坐标。普通属性的实例路径保持不变。父块增加 `attribute_instances` 和 `duplicate_attribute_tags`；旧 `attributes` 字典保留兼容摘要，重复标签明确提示，不能用摘要替代逐实例值。

九个合成反例覆盖不同值、重合位置、旋转父块、阵列和普通唯一标签。真实图纸只在本机作同输入复测，不进入仓库。此修复解决读取身份问题，不决定设备类型、系统归属、施工范围或安装数量。
