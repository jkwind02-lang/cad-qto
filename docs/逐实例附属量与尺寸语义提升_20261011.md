# 逐实例附属量、尺寸语义与陌生范围实测

本轮针对原图算量中的三个缺口改进：说明要求未逐实例落实、尺寸数值正确而起算含义可能错误、已有主量未覆盖完整有界范围。原始项目值、图元句柄、坐标及答案仅保存在本机验证输入，不进入运行代码。本轮保留13个专业和1个协调入口，不增加项目专用规则或统一专业公式引擎。

## 通用变化

- 新增 `qto_instance_requirements.py`，消费当前来源及模型工作识别台账，将条款条件、例外、事实规格与实际实例/端口对应。应设、图示已覆盖与规则新增余量分开；同源别名、多视图、共享安装位和端口拆分均有身份约束。需长度、面积或布置的条款形成专业待办，不套固定件数。
- 新增 `merge_pipe_instance_requirements.py`，以原管网物理对象和实际数量记录合并附属量。既有builder与infer显式透传 `source_object_id`，保留原证据编号；另一件同型号阀门不能冒领数量出口。用户汇总保留原管长、断口、管件、块族及未决；不适用不再显示为假未决。
- 新增 `qto_dimension_semantics.py`，重新读取SHA绑定的原DIMENSION与完整实例路径，核对有限源几何测点和模型选择。设计尺寸、显示比例、实例变换分别保存，检查有向尺寸链与包含关系，向既有钢长度推导器交接轴线、支承面和切口扣减。非均匀变换使用适合投影量测的协向量，避免普通方向变换造成误拒或越界误放行。
- 面层计算器新增 `boundary_intervals_net`：从来源事实读取逐边起终点、有效区间及洞口区间，裁切、求并集并输出踢脚长度。米与平方米分别汇总。一个真实洞口跨不同源边可分别定位，同边重复和物理边别名重叠仍拒绝。
- 面积项新增显式 `frame_binding`：来源框架和源边均绑定本物理表面、来源哈希与JSON Pointer，声明共同坐标系、有限边区间、正反向和竖向范围；核对局部原点/轴向与矩形长高并导出四角坐标。支持整边中的子段及反向取段，拒绝旧原点、错坐标系和越界；旧输入保持兼容并披露unbound/not_provided。校验范围是来源事实内部的一致性，不证明设计解释及洞口三维定位已成立。
- 专业入口和公共方法接入上述能力；补充局部坐标正向与源边转换、全部基层构件分区、实际接缝而非每柱固定面积，以及明确尺寸与示意轮廓的区分。

## 验证

本轮新增186项测试，连同已有回归为 **956项通过**。逐实例42项、尺寸53项、踢脚39项、面积定位绑定52项；运行包包含249个文件。首轮904项后，真实范围的最后审查又发现尺寸更新而定位字段沿用的问题，因此继续增加通用绑定并重新执行956项完整回归。独立审查分别重放原反例与合法对照，覆盖来源别名、共享安装位、条款互斥、端口身份、错件抵扣、投影方向、非均匀变换、跨拆分边洞口、单位分账、有限子区坐标和成果篡改。

逐实例审查原端口格式有一例需要补冻结台账中的 `port_bindings`；已保留原拒绝结果，并在不改变原设备和端口关系的情况下验证迁移正负对照。个别早期反例使用保存的早期源码后补重放，未冒称全部首次输出均完整保留。原脚本中的文案断言变化与实际语义检查分开记录。

真实回归完成了图示与条款两路附属量查漏、同物去重、穿墙实例、保温兼容性及有依据的支承方案。旧原图面积回归无数值变化。陌生项目测试在计算前限定完整面层计算链，主算与复核各自封存后比较；继续回图发现共同遗漏，再读取相关专业原件并形成后续版本。没有把双方同数、工具PASS或所有对象均有状态当作完整工程量已经验收。

## 使用与边界

使用说明在运行入口及共享参考 `逐实例构造要求与附属量.md`、`尺寸指向与尺寸链复核.md`，面层长度输入见 `表面与构造层清单格式.md`。项目源条款、对象身份和适用事实由模型本轮读图准备，不要求用户先逐个识别。

原PDF尺寸观察仍为 `non_geometric_review`；程序不能自动裁决尺寸线起点或偏心方向。源哈希、几何吻合和算式成立不证明工程语义已正确。源图缺少的安装高度、构造节点和相互冲突的明确设计条件继续保留影响与未决，不能补零、凑差或擅改设计。全部新识别和计算仍是模型工作层，未提升专业成熟度或正式采用权限。

本轮实测证据保存在本机本轮验证目录；仓库只保留通用实现、测试与方法。当前本机版本和实际安装验收以根目录 `仓库发布核对.json` 的本轮记录及维护入口为准，未提交、推送或上传原始资料。
