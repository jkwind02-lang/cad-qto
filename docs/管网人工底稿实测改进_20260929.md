# 管网真实资料与人工底稿对照改进

> 2026-09-30目标回查：本页为历史局部机制、原图选定对象或底稿辅助检查记录，不代表完整独立算量验收。当前测试目标和证明范围以[既有实测目标回查](既有实测目标回查_20260930.md)为准，保留有效修复，补齐独立算量主线。

2026-09-29，本地已保留前序管网和钢结构修改。本轮关注真实图纸转换、已识别管段的长度、空间范围、DN绑定和人工底稿对照，不以项目答案反填插件。

| 已复现问题 | 改进后的行为 |
|---|---|
| 单位系数只要求为正，可以混入双线除数或损耗 | 两个管长入口按物理单位检查系数，并核对原始单位；未知和冲突单位拒绝计算 |
| 窗口与长线相交时，整对象长度被当作窗内量 | 默认仅纳入完整落在范围内的对象；跨界对象未决；明确整对象选择必须记录依据和越界对象 |
| 原图改版后，内部自洽的旧CAD缓存仍能继续计算 | 现场检查权威原图、交换DXF和转换记录的哈希与存在性 |
| 显式DN目标与文字规则空间冲突时，映射被静默跳过 | 显式绑定先核对目标、系统和空间；不可用关系明确失败；修正次近候选差值和显式绑定敏感性 |
| 转换器退出码为0但DXF被截断，仍报告成功 | 先查组码与文件节闭合，再发布DXF；保留失败诊断；支持已安装ODA对工作副本转换，修复转换须显式选择并传递待复核状态 |

人工底稿比对补充：先对齐包别、楼层、轴线起终点、供回根数、已绘／竖向／详图接管和净量／损耗。自定义宏公式保存值不能充当本轮重算；每台固定接管长度、详图套数和设备台数分别取证。局部已绘长度与整线路不能直接判准确率。
