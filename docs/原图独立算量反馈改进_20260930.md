# 原图独立算量反馈改进（2026-09-30）

本轮将装修技能测试从人工底稿复核纠正为先独立识图算量、封存后再对照。真实工程数据留在测试任务，插件只吸收通用方法和缺陷修复；前序装修反馈文档仍保留为历史，不代表独立算量验收。

- 专业与协调入口增加原图独立实测要求，披露历史上下文暴露，不将非盲测称为盲测。
- 新增 `extract_surface_regions.py`：多边形HATCH、岛屿样式、路径过滤、嵌套块/阵列、单位与来源绑定，显式失败位置；同视图同材料面域并集去重。
- 图案/网格尺度必须与图例核对。不同楼层不能按相同坐标合并，重合图案可能是同一构造层，图层后缀不等于装修表做法编号。
- 修复同一EdgePath中的独立边环被长对角线串联的问题。显式端点容差重组、顶点度数约束和近邻歧义拒绝；所有端点位移、补线位置及长度留痕。缺边补线默认1毫米上限，不能通过拓扑修补静默造边。
- 曲边、无法闭合的图形与代理实体继续明示失败；显式修补始终候选，不自动提高业务成熟度。

实际完成7个单体63条限定范围结果，其中两栋多层吊顶34组。首轮62条已封存，底稿后续只作差异参照。图面检查追加修复了22个混合边环路径。仍有候选填充、来源冲突及整栋地面、墙面、踢脚、楼梯等未覆盖内容，不能报告完整装修准确率或整体采用许可。

新增16项面域回归，连同原299项共315项；完整运行与安装状态以本轮实际核验记录为准。项目证据目录为 `D:/All-Ai/CAD算量/测试/神州细胞装修插件实测_2026-09-30/独立图纸算量`，含独立结果、每轮提取、首轮封存、图面视图及最终核验。此记录只包含通用问题与验证边界，项目图纸和数量未复制进插件运行包。Git改动未提交/推送。
