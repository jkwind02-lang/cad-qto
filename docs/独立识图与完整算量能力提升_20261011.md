# 独立识图与完整算量能力提升

本轮改进通用 CAD 取证和专业计算工具。模型从原图识别对象、尺寸起点、系统及适用范围，工具执行来源核验、几何计算和明确约束检查。项目名称、坐标、实体句柄、固定配管长度及参照答案留在本地验证输入，不进入运行规则。

## 新增和修复

| 环节 | 可执行改进 | 保留边界 |
|---|---|---|
| 读取覆盖 | 区分可测曲线、标注、定位、专业适配待办、未支持和失败；失败实体保留身份 | 代理对象、动态块和外参缺口不冒充已解析，不把未知量写零 |
| 尺寸及坐标 | 按线性/对齐尺寸类型读取，分别记录原几何、DIMLFAC、缓存及文字；块线性变换不通过大平移相减提取 | 覆盖文字、基准或缓存冲突仍需回图；不能把示意图尺寸当实际设计量 |
| 局部识图操作 | 来源绑定的局部索引、上下文、同族候选、模型操作记录及现有管网1.2输入导出 | 同族和近邻只是候选；不按层名自动认管线，不声称全图自动识别 |
| 跨图对应 | 区分同实物多视图、跨层接续和典型详图适用；显式判断后才输出工作配对 | 唯一候选不等于采用；无向源端口关系防止正反或别名重复计量 |
| 标高接口 | 显式测点、外径、基准及换算，绑定来源事实身份；接入既有依赖重算 | DN不能当外径；竖向投影不等于完整路径；缺端口高度保持未决 |
| 普通线网面域 | 源线节点化、面/孔洞/悬边/割边，逐边来源，源端点解释分界 | 柱面不自动当房间，房间不自动套做法，不自动闭合所有缺口 |
| 钢构件长度 | 三维端点及单位、中心/支承面/切口起算基准、两端扣减 | 检查输入一致性，不替代尺寸语义判断；未知三维端点不当水平梁 |
| 维护评估 | 逐对象查漏、误纳、重复、关系和口径错配、未决及绝对误差；冻结输入和来源 | 不以总量相等证明准确，不把争议或无证据底稿当真值 |

原有块包围盒和管道附件父块归属修复一并纳入安装包。

## 独立审查与实图边界

独立审查使用自建反例确认并修复了单位子串误匹配、反向接口重复计量、标高测点/基准替换、线网坏段吞后续边、父块问题丢失、大坐标精度损失、参照证据状态和循环引用等缺陷。修复后重放原失败输入，正常独立连接及共享原始图纸的对照仍允许。代码测试和输入约束不证明模型理解所有图纸语义。

真实验证分别使用有限管网支路、无填充的装修房间、单跨钢梁与节点；保留实际源图、操作/计算输入、冻结记录、独立复核和未覆盖对象。实例中未标端口高度、窗与柱界面冲突、牛腿尺寸起点及构造矛盾未用底稿补齐。部分事项属于本轮尚未完成的识图，不能改称资料缺失。没有将有限范围提升为全项目独立算量验收。

底稿对照后置；历史项目资料曾在此前任务出现的，记录历史暴露，不称严格盲测。参照缺实例身份或口径不能对应时不评分，不用最接近的数量匹配。

## 运行与维护

新增能力从原有专业 Skill 及共享识图流程按需进入，仍为13个专业加1个协调入口。运行目录不增加新的学习入口。评估工具位于 `maintenance/evaluate_takeoff.py`，不作为项目数量引擎。

本轮最终 Python 回归数、运行文件数、安装版本及本地验证状态以根目录 `仓库发布核对.json` 的 `local_capability_update_20261011` 记录为准。没有推送远端、上传项目资料或提高全专业成熟度；本地安装通过宿主的插件安装流程完成，已有会话不假定自动重新加载入口文本。

真实业务资料和初次失败反例保存在本地长期维护目录，公开仓库说明不携带项目原图及人工底稿。
