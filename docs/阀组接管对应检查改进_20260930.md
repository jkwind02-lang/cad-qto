# 阀组接管与人工底稿对应检查

> 2026-09-30目标回查：本页为历史局部机制、原图选定对象或底稿辅助检查记录，不代表完整独立算量验收。当前测试目标和证明范围以[既有实测目标回查](既有实测目标回查_20260930.md)为准，保留有效修复，补齐独立算量主线。

真实资料暴露的主要问题是：不同区域或设备型号的数量可互相抵消，汇总值相等仍不能证明逐阀组、逐设备对应；每台固定长度也可能只是底稿假定。

本轮增加管网专用 `audit_pipe_correspondence.py` 及按需参考，将对象、共用阀组、逐台接管、竖向和底稿行分别记录。来源重新校验哈希；拒绝把阀组共用管乘设备数、重复实物区段、无依据并行系数、混合系统/规格/单位及无效数值。算术匹配、范围一致、物理实例身份、尺寸依据和区段覆盖分别输出。缺尺寸时保留固定值假定，不反推差额或自动升格为图纸工程量。

新增30项定向回归，包含同总数不同范围/成员、同名不同实例、供回竖向标高差、详图多视图重复、汇总组与独立实例差异、来源变化和无效数值。真实资料的23条对照中20条算术匹配，全部保留尚缺图纸对应的限制。完整Python回归结果和安装字节核验留于维护入口及本地实测记录。

检查器不识别CAD连接关系，不裁决图纸有效版本，也不能发现人为给重复区段起了不同标识的情况。`correspondence_complete` 只检查输入台账的已编码条件，不能取代实际图纸复核。通用插件不保存项目设备名、数量、坐标或底稿内容。
