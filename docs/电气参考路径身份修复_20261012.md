# 电气参考路径稳定身份修复

旧版电气参考入口在 `route_items` 中接收同一稳定 ID 两次后，逐行执行计算并输出两条数量，造成重复计量；空白或非文本 ID 也能进入旧入口。新的路径台账入口已有独立身份校验。

本轮只修旧参考入口：每行须为对象，ID 须为非空文本，去除两端空白后检验重复。正常输入的输出字段、精度和数量不变；不同 ID 的真实并行导体仍可分别计量。新版路径台账继续交给现有计算器处理。

测试使用合成输入覆盖重复 ID、空白别名、非文本 ID、正常并行数量、正常输出契约及新版路径台账转发。真实图纸的输入、原生结果和同输入前后对照只保存在本机项目工作区，不进入仓库。该修复不提高原图自动识别或业务采用成熟度，不证明完整专业覆盖。
