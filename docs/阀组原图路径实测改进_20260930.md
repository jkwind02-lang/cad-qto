# 阀组原图路径实测改进

本轮继续以原图独立计算、底稿事后比较完善技能。既有上下文已暴露底稿，因此不宣称严格盲测。原图选段和计算输入不含底稿长度或套数；原始图纸和底稿只读。

## 实际推进

- 重新转换并绑定原始DWG及DXF哈希，在四种典型阀组正视图内独立识别外侧供水U形、内侧回水U形和顶部旁通，共12条路径、84个计算区段。
- 原图中的弯头中心圆弧位于块定义内，部分实例有镜像；阀件处既有轴线连续画法，也有断口。三通顶端只有端面/轮廓及局部中心线。将这些情况转为可复算源引用，未用经验固定长度补齐。
- 12条路径用图元逐段计算，并用端口坐标、尺寸链和圆弧半径另式交叉计算；均在1e-6米内一致。该阈值只检验数学一致，不代表工程精度。
- 原图結果冻结后读取人工底稿。含阀组备注的轴网间管段与典型详图内配管口径不同；通用弯头数与详图转弯数存在差异。实际实例到详图的映射未建立，未将这些差异直接判成项目漏算或计算准确率。

## 通用改进

新增 `measure_pipe_detail_routes.py` 及直接使用说明，接入管道Skill入口和底稿对应规则。模型决定主视图、对象、连接及源引用；工具计算源实体，不接受手工填入的长度作为原图量。

- 读取完整块实例路径，保留旋转、镜像、非均匀缩放及圆弧；禁止把内外壁曲线与中心弧混算。
- 分别输出已绘、阀件断口、端口和三通恢复轴长。已有连续中心线不重复加阀长。
- 检查空结果误报、对象身份、源文件及转换凭据、单位与线性尺寸比例、端点接续、视图范围、同一路径重复、完整曲线重复和共线线段重叠。
- 辅助视图不得新增同一实物数量；块名不自动决定DN；混合规格轴线不自动按主管DN汇总。
- 保留模型工作状态，实际安装套数和计量管长保持未定；本轮不推导缺失的计量扣减条款。

## 验证与边界

28项新定向测试通过；全量Python回归343项通过。覆盖真实案例暴露的块内弧、镜像、阀件断口、端口、三通，以及过期源、非法引用、比例覆盖、异面/偏轴、重复量等反例。测试通过证明已编码约束，不是全工程识图保证。

本轮主回路几何可复算；泄水和仪表支管长度、出平面偏移、现场高差、不同DN完整分段、实际阀组与典型变型对应及净管计量仍未完成。不能将未展开范围写成已证明资料不足，也不能用局部模板结果乘底稿套数。钢结构与装修既有改进保留，本轮没有新增它们的独立识图覆盖。

四视图、84段的单文件HTML用共享生成器生成，纯本地保存；实际成果完成隔离DOM初始化、批注保存/恢复和数量载荷不变检查，没有网络调用。中文静态路径图已回看；未进行原生浏览器视觉验收。

具体原图、冻结输入、逐段计算、手工底稿对照及验证凭据留在本机F03测试目录，不打包进运行技能。安装版本及四处运行文件核验以该轮安装凭据为准；未提交或推送远端。
