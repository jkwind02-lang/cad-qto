# CAD 原图推导与通用能力提升

本轮针对原 CAD 阅读、逐实例高程、基层分区及尺寸语义继续改进。运行时只接受当前来源与对象事实，没有加入项目名称、固定实例、固定安装高度、固定配管长度或拟合底稿的系数。模型继续承担原图识别和适用性判断，工具承担来源核验、几何与数量复算及去重；正式采用和专业成熟度边界保持不变。

## 本轮变化

- **原生 CAD 读取**：对重复句柄逐原始记录核对完整标签及引用影响。已证明完全相同的非图形资源声明作为保留提示，冲突或图形身份不唯一继续阻断；坏编码和截断不构成完整取证。工作台将已核提示与阻断风险分开传递，仍不声称解析器全量保真。
- **外部底图依赖**：输出定义文件、页码、定义与实例身份、完整变换、可见状态和读取状态。相对引用只依据经核验的原 CAD 上下文解析，不用临时交换目录内的同名文件冒充原引用。该能力记录依赖，未读取的内容仍未读。
- **竖向管段组合**：独立入口把带来源的测点、高程基准、中心换算和路线条件转为逐实物区段长度，与既有管网数量出口比较。保留同物别名证据、共享区段、端口身份、完整规格及未决状态，按证据层级分别汇总；不会把系统图排版线长变成竖向量。
- **材料基层分区**：同一有限母面按真实洞口、同材并集、异材冲突和显式未知区域复算。缺少依据的材料不由补集猜测，条带选取范围有单独来源声明；净多边形与互不重叠矩形可供后续施工层计算，材料区域和施工层结果分别计量。
- **原生尺寸投影**：新增从闭合矩形的真实边推导中心，再显式核对尺寸测量方向投影的选择器。区分投影吻合和空间共点，拒绝任意包围盒、非矩形、错平面或错量测轴；钢构件实际长度仍需要真实目标方向闭合。
- **关系式重算**：安全公式支持有量纲的 min/max，全部候选参与依赖与最弱证据传播。被拒绝的中间值清空，单位换算或 SI 归一溢出阻断，不能由后继函数恢复成可用量。
- **识图方法**：CAD 表格同时记录行对象、列标题、单位、基准与型式；跨图保留邻接关系和控制尺寸；平面交墙只先作为穿越候选，继续核实际高程处的墙身和构造适用范围。

## 验证与边界

先保留旧运行源和首次失败，再用独立构造的合法、错误与未决输入进行修复后重放。材料几何另采用独立原子格网分类作对照，避免以实现自身的布尔运算生成唯一预期。实际 CAD 测试输入与证据留在维护工作区，未打入运行包。

实际来源仍可能含跨专业不一致、预算参考高程、厂家接口未定义、未定位构造或缺失外部依赖。能推导的工作量和条件量继续出数；不能唯一裁决的保留影响及来源，不用底稿补差，不把测试通过解释成完整项目验收。具体测试次数、最终运行指纹、安装状态和实际缓存复验以本轮维护入口及验证记录为准。

改进与安装验证完成时尚未提交 Git；随后按用户要求归档为本地提交。推送、远端 CI 与项目资料上传不在此次归档范围内。
