# 天正基础读取接入

本版本将已冻结的0.5.1原生字段读取器接入公共CAD读取层，新增 `cad-basic-read`（CAD基础读取）入口。只提取普通CAD与天正构件基础数据，不调用专业算量器。

## 实现

- 公共中性提取器和实例工作台共用 `cad_native` 包，随插件分发，不依赖原型任务目录、厂商二进制文件或项目固定句柄。
- 保留一个原生构件的身份，在对象内部输出参数、文字、接口、原生路径、序列化轮廓和引用图块；实例输出完整插入路径及变换后坐标。
- 中性取证新增 `CAD原生构件基础数据.json`；专用入口额外输出 `CAD基础读取回执.json`，记录源图身份、活动实例、非活动定义、配置容器、缺口及读取进程模块审计。
- 原生字段读取完整与可测量几何分开表示，未核明曲线语义不自动生成中心线、长度或面积。嵌套实例的公共矩阵转为ezdxf矩阵时显式转置。

## 验证边界

0.5.1既有68项测试在移植包上通过。新增合成测试覆盖实际公共入口、缓存更新、未知代理、嵌套旋转缩放阵列、只读回执及覆盖保护。真实工程数据在本地任务目录验证，不进入运行包或仓库。

## 保留限制

0.5.1未解码 `TCH_DBCONFIG`、`TCH_PSCONFIG`。不引入后续配置试验分支。序列化完整不等于全部字段工程名称及曲线语义已核明；源图单位、无效坐标、缺失引用及普通CAD覆盖缺口保持显式状态。整体读取可为 `PARTIAL`，已读基础数据仍可使用。

本次不改变专业算量规则、成熟度或正式采用条件。安装结果与真实活动实例证据以本地当次核验回执为准。
