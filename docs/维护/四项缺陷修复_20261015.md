## 输入与输出兼容变化

- `single_end_plane_policy` 默认 `geometry_evidence`；旧 `extension_full` / `extension_minus_half_width` 仍可读取，但只输出诊断值，不能选择为采用量。单端件补 `single_end_geometry`，包含 `source_id`、`basis`、`endpoint_relation` 及几何依据，竖向自动匹配还须 `turn_plane: vertical`。完整格式见风管 reference。缺依据的管件长度及单端几何完整合计为 `null`，已知小计另列，直管已知量保留。
- `frame_size_scale.paper_size_mm` 改为 `[纸宽,纸高]`，`measured_drawing_units` 改为 `[原始X跨度,原始Y跨度]`。旧单边标量拒绝并提示补齐，不自动从幅面文字猜第二边。`known_component_size` 仍为一维尺寸契约。管网适配器和对象工作台共用该校验。
- 批量新增全图 `未定位对象待办.jsonl` / `未定位对象明细.jsonl` 与 `drawing_level_unlocated_objects`。未定位对象不计入每框 `pending_line_objects`；整批有未定位对象保持 REVIEW_REQUIRED，已定位图框 NO_PIPES 不等于整图无管线。
