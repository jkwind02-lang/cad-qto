## 来源

本目录依据《cad-qto 双宿主维护方案（第五版）》整理，方案原文在本机评估目录 `Claude移植评估_20261014/01_移植分析/双宿主协同维护方案.md`，不随仓库发布。方案与本目录不一致时，以经双方确认后更新的本目录为准，并在提交信息中说明。

## 分工

- 共享源码由当前持锁者写入，另一宿主只读复核。
- Claude 负责 Claude 外壳（`.claude-plugin/`、`CLAUDE.md`）、Claude 安装与恢复。
- Codex 负责 Codex 清单与 `agents/openai.yaml` 的兼容复核、Codex 安装与恢复、`~/.codex/AGENTS.md` 等 Codex 配置，以及旧开发源和旧独立入口的最终退出。
- 两边的接续结果写回安装核对记录或维护记录，不通过自动向另一个聊天发消息协调。
