## 已接入实际计算

| 原问题 | 本轮处理 |
|---|---|
| 主管中部接管、多段线只按两端建网 | 保留完整参数路线，按有证据接点、变径及几何拐点分段；原对象审计与派生段数分离，长度守恒。 |
| 相交、同坐标不同楼层可能误连 | 系统、图页和三维坐标隔离；明确连接、分离或待核实；未知T接、直线内交叉和共线重叠只列候选。 |
| 跨图对应混成新增管长 | 接口身份、两侧定位、标高及DN连续依据分别记录；已证明垂直路径按标高差另列，既有实物计量出口只引用。 |
| 分段后规格错误继承、按弦线匹配文字 | 标注需定位作用段；整对象继承需范围依据；按完整曲线匹配，保留其他候选及敏感条件。 |
| 阀门仅凭邻近继承、环网强套树状关系 | 附近只作候选，在线连接单独核对；环网或多源不套树状下游末端数定主支管。 |
| 未绑定个别端口导致全任务停止 | 局部问题保留，已绘可独立量继续；变径不明限制相关规格传播；端口交付、接收及未决对账。 |
| 端口交接丢图页、局部坐标语义不清 | 图页、单位、明确管段绑定透传；显式块内端口按完整矩阵换算；台数和端口数分列，兼容旧端口数量别名。 |
| 端点全量两两比较及传递过度吸附 | 分组网格近邻、曲线包围盒树及精确距离复核；限制吸附簇内部距离，避免链式过连。 |
| 修改后只有重算说明，没有更新算式 | 明确事实、公式及依赖构成台账；安全运算与量纲检查；沿依赖重算、输出变化及旧确认失效；缺引用、环和未闭合正式依赖拦截。 |
| 共用桥架、线缆和芯数容易混用倍数 | 新增有序路径台账，通道及回路分别计量；水平、竖向、上下翻、端头分列；芯数只作规格，保留旧参考输入。 |
