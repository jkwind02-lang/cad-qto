# 实例、规格与接管实测改进

本地安装版本 `0.2.0+codex.20260930042613`，2026-09-30。目标是从真实图纸独立算量、底稿后置比较并改进通用插件。

新增 `bind_pipe_callouts.py` 和 `partition_pipe_detail_specs.py`，分别把实物—引线—框内标注绑定，以及混合DN的原图端面分界/连续覆盖/长度守恒接入运行。结果保留来源哈希、完整实例路径、原始文字和工作识图状态；不推定完整安装尺寸或净管计量。新增方法文件《实例规格与逐台接管》，明确上下层与连续编号、供回水拓扑隔离、共享干段、孤立接口、BOP与管中心的区别，以及转换后目标实体核验。

修复详图测量器两项可复现缺陷：零长DIMENSION被接受为标定；部分重叠圆弧未被去重。旧版与新版对同一反例已验证。重叠检测处理圆弧/椭圆弧的正反向、跨零角及仿射参数，不用折线长度替代源圆弧。

实测包括五层38个实际阀组的逐实例与文字绑定；4种典型详图12条主路径的28个规格区间；七层8台设备按连接分3+5并识别一对孤立管端；四层56个PAH本体和6个RCU身份，其中53台PAH的两个回路可对应；屋面11台PAH及80条已绘管线；14处跨层供回水接口。原DWG目标实体与交换DXF交叉核验，不用人工固定长度作为原图输入。

235个运行文件四处一致，14入口；全量370项Python回归通过，本轮新增27项。实际安装版重跑真实规格分段、引线绑定和3项错误输入；两项漏洞修复前后反例证据保存在项目测试目录。没有提升专业业务采用许可，没有声称整项目、全专业自动识图成熟。

接口缺绘、实际管口标高、详图尺寸适用及计量边界仍按具体源证据保留。钢结构与装修只随全量代码回归保持兼容，本轮没有新增全范围原图识图，不能用本轮结果替它们完成验收。项目资料只在本地测试目录，Git未提交或推送。
