# 逐实例未匹配需求表达

逐实例输入没有提交现件匹配时，原输出把全部需求放入 `additional_quantity`，管网汇总又称其为“新增余量”。读图与现件匹配不完整时，这种表述容易被误作采购缺口。

保留需求、已匹配件数及兼容字段的算术，增加明确的 `unmatched_requirement_quantity` 与字段含义。`procurement_additional_quantity` 保持 null；它不是本工具可以从图示和匹配列表证明的量。管网摘要采用“未匹配需求”，明示空列表不证明没有现件，需求已包含已匹配量。

验证包括无现件列表、部分匹配、规格未知、规格冲突、重复观察和用户摘要六类合成用例；同时在本地对真实同输入检查需求/匹配/兼容余量/规格/状态不变，采购字段始终未定。真实项目图纸、输入、结果和回图未进入仓库。软件验证不提高原图识别成熟度或正式采用资格。
