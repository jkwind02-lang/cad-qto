# 本地组合候选

候选以PR8精确提交为基线，该提交链已经包含PR6证据定位修复和PR7构件根数/单位验证修复；再应用PR9旧电气参考入口身份修复。组合时运行清单有冲突，按实际组合内容重新生成，没有直接选择任一旧清单。原分支、main和安装源不变。

补充风管身份边界：PR8只拒绝完全相同ID；两端空白别名仍可重复输出数量。候选将ID按两端空白规范化后检查唯一性，不改合法输出的ID，不将几何相同但物理ID不同的真实重复实例合并。原有count字段仍可以表达有依据的同类实例组。

项目源图、识别记录、工作输入、原生结果、组合回归和新增实测证据只存项目工作区。组合回归只能证明既有输入及已编码条件，不提高识图成熟度，也不代替完整工程范围验证。
