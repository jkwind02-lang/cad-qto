# 按人工算量思路复核计算路径

复核基线：`48bf5cef731b321e6c28abb52a73a21b8a2d6356`。对应改进版本：`0.2.0+codex.20260920`。

## 结论

保留“模型读图判断工程含义，程序提取几何并计算，人工复核关键歧义和采用条件”的分工。不能把人工算量理解成用户先填完所有计算输入，也不能把按人工顺序编写提示词视为识图能力已经成熟。

本轮审查了13个专业入口及相关计算路径说明，深入修改和测试的是管网连接、点位交接、电气路径、共用空间查询和依赖重算。其他专业的以下结论属于流程和接口复核，不是全部识别器逐行认证，也不是实图准确率验收。

原流程已经要求读说明、图例、平面和系统图，但执行上容易从“提取一批线”直接进入“加总长度”。本轮把关键步骤落到数据及代码：先确定工程对象和作用范围，保留完整测量路线；再按有证据的接点、变径和实际几何分段；最后计算分规格明细和附件。不同图页先隔离，跨图关系单独记录；变更后按依赖重算，旧确认不能自动延续。

## 一、用人工算量的七步检验现有执行链

| 人工工作顺序 | 必须得到的工程事实 | 程序应承担的工作 | 不应越过的判断 |
|---|---|---|---|
| 1. 明确算什么、按什么口径算 | 楼栋、楼层、系统、分项范围、图纸版本；物理量、清单量、方案量分列 | 来源、单位及范围核对 | 不把图层名当合同范围，不把区域小计称全项目总量 |
| 2. 通读说明、图例和有关图纸 | 图例、设备和构件编号、材料规格、做法和计量依据 | 文字及几何取证和定位 | 模型实际读图，关键词命中不等于识别完成 |
| 3. 建立系统或构件关系 | 管路起终点、支路、立管对应；构件—节点—零件或房间—表面—做法关系 | 关系台账、实物身份和冲突提示 | 平面、系统和详图是互补证据，不是三份数量 |
| 4. 分段分规格测量 | 接管、变径、标高变化、实际尺寸；闭合面域及洞口 | 全曲线测量、有依据分段和守恒检查 | 相交不一定连通，示意位置不一定是实际三维位置 |
| 5. 用本项目已确定规则 | 材料、施工、计量口径和附加扣减条件 | 确定性复算与条件量分列 | 不为凑完整量默认层高、DN、连接件比例、支架间距或损耗 |
| 6. 沿工程关系回图 | 每条支路或构件的节点、洞口和附属项覆盖 | 图面定位、漏重候选和明细小计核对 | 总量接近不能替代分项核对，相反误差可能抵消 |
| 7. 修正与重算 | 改了什么事实、规则或范围，影响哪些结果 | 沿依赖重算、保留旧版、旧确认失效 | 方法意见不等于确认任意新数字 |

这是一次算量内的实际顺序，不另造七套表格。对象、证据和假定已有记录应复用。单专业直接算，只有确实跨对象或跨专业才协调。资料缺失只阻断受影响部分，模型未完成识图不能伪装成缺少用户输入。

## 二、按专业逐项复核

| 专业 | 人工算量主线 | 本轮核对与处理 | 必须保留的未验证边界 |
|---|---|---|---|
| 管道管网 | 说明图例→平面系统互读→水源立管逐支路追踪→水平竖向分规格→附属→回图 | 路线与拓扑管段分离；有依据中部接点分段；交叉跨越、图页隔离、立管对应、环网多源、阀门邻近与在线连接加入约束 | 接点依据仍由模型读图提供；复杂曲线交叉、排水画法、竖向DN及附件范围不因几何测试自动确认 |
| 构件设备点位 | 图例→设备构件编号→多视图去重→实例→实际端口→网络对账 | 台数与端口数分列；交接保留图页、管段及坐标单位；块内端口按实例矩阵换算 | 插入点默认不是核实端口，成套范围和匿名块含义须回图 |
| 电气线路 | 系统回路表→设备起终端→桥架导管路径→每回路路径→根数端头 | 增加路径台账；通道、回路、路径独立；连续性、唯一实物、共用桥架不乘回路数、多芯电缆不乘芯数，水平竖向上下翻预留分列 | 回路归属和导线配置仍需识别；不默认三根五根，不凭颜色或最近线推回路 |
| 风管风系统 | 系统设备→主支管→截面标高→直段管件→保温法兰支架→回图 | 维持直段面积与管件分链；要求直管与弯头、变径、软接端口对应，不重复计长 | 当前参考脚本不是异形件自动展开器；加工面积与清单面积不互代 |
| 混凝土模板 | 说明→基础柱墙梁板编号→截面标高→实体并集扣减→模板接触面 | 同一几何支撑体积和模板；增加未闭合上游进入正式成果的依赖检查 | 土模砖胎模、施工缝、浇筑顺序及节点相交仍需事实，模板不按体积系数估算 |
| 钢筋 | 构件→集中原位标注→钢筋组直径位置→根数→展开→锚固搭接接头 | 保持钢筋组和节点依据链；间距、端部条件、展开长度分别复核，明确参数可接依赖重算 | 平法与节点自动识别无本轮实图证明，不凭图集名或常用锚固值补量 |
| 主体钢结构 | 布置构件表→物理构件→截面实长→每处节点→板件连接件→处理表面 | 保持主材节点连接件涂装分链；同件多视图只计一次，详图次数不等于实物次数 | 节点漏识别不按吨位比例补齐，面积仍需暴露接触面和处理范围证据 |
| 砌体二次结构 | 墙段→材料厚高→洞口并集→构造柱圈梁过梁占位→分项 | 墙系及二次构件唯一出口，扣减可回放，与混凝土钢筋交接不重复 | L/T交接、变高墙、马牙槎、过梁支承长度具体判断，不默认 |
| 饰面围护 | 房间立面→表面边界→侧别做法层→洞口→毛净量→材料分项 | 物理表面和构造层区分；层高洞口变化重算关联面积，门窗数与洞口扣减互校 | 不盲目桥接门洞封房间；重叠、单双面、不同做法仍要读图 |
| 龙骨支承 | 分区→方向起排边距→普通骨架→洞口删减→加强连接 | 保留最大间距公式的端部适用条件，普通、删减和新增加固分别核对 | 面积除间距不代异形逐根排布，综合支架不与专业支架重复 |
| 土方地形 | 原始面设计施工标高→坑槽底边→工作面放坡→相交并集→挖填占位→平衡 | 同高程、同土体状态、同基准；现状地面不能用设计室外地坪替代 | 局部坑群试运行不等于完整地形、深基坑及土方平衡验证 |
| 桩基地基 | 桩位→唯一桩号状态→不同标高→设计成孔灌注空桩截桩→处理分区 | 根米体积分列，工程试废补桩状态互斥，承台占位与桩量不双计 | 不把一种桩长套所有口径，充盈泥浆渣土不得无依据换算 |
| 道路室外 | 桩号平纵横断面→分区边界→各层厚度范围→路缘沟渠→路床土方 | 分段连续、变宽条件、各层独立边界和土方唯一出口，弧形路缘用曲线长 | 基层面层不默认同面积，复杂交叉口、变厚坡面不一律长宽厚相乘 |

## 三、实际纠正的计算路径问题

### 先认工程路线，再切成计算管段

以主管10m、中部支管3m为独立算例。读图确认三通后，主管切成两个5m管段，支管仍3m；管段数由2变3，长度仍13m。源审计数与派生数分开。无连接证据时已绘长度仍可计算，但接管处列待核实，不自动生成三通。

折线、圆弧和闭合路线保留参数几何。切分不把曲线拉成弦线；方向判断用端点切线。相邻折线段同一拐点及闭合接缝采用同一节点身份，不能因写法不同形成冲突决定。同一对路线一处已裁决，不掩盖另一处未知接点。

### 平面与系统提供互补事实，不直接叠加

不同图页相同坐标不合并。跨图接口给同一实物身份、两侧对应和依据。只在直立路径和标高明确时按高差计竖向。例如已绘水平各10m，图面相距100m，标高3.0/7.2m，结果应为水平20m、竖向4.2m分列，而不是连接排版两点得到100m以上。

已有竖向计量出口时只引用。缺标高不填0，不阻断独立水平量。规格连续另需依据，不能因为两点关联便传播DN。

### 规格、阀门和主支路受连接证据约束

分段后原DN标注定位作用区，不能无依据复制所有子段；明确全段同规格才整条继承。最近、次近候选保留，按完整曲线距离匹配。附近阀门列候选，不直接当在线连接继承规格。环网、多水源不能按一棵树的下游末端数定主支管。未绑定端口、水源和变径保留问题及影响，不删除后假装完整。

### 用实际依赖代替“修改后请重算”文字

台账保存明确标高、长度、数量因子及算式。高度变化影响竖向、分项及关联表面积；规则变化即使数字未变也使旧确认失效。不相关水平量不因缺高度被清零。缺引用、循环依赖、量纲冲突和未闭合正式依赖不能通过。

公共工具不自选计量规则，不代替各专业并集、节点或扣减算法。复杂算法仍由原专业执行，其新输出可作为有来源的事实输入。工具不自动侦测全部图纸变更，模型须先识别改变的事实。

### 提速不改变工程判断

端点、断口采用分系统图页空间索引，曲线采用包围盒树，最终仍用完整几何精确距离及相同阈值。限制吸附簇内部距离，防止短间距传递成过大节点。用同组数据对照穷举，并检查稀疏大样本候选比较量，不以删对象换速度。

## 四、真实图纸验收仍需满足的条件

独立对象清单和人工算式作为标准，不用程序首轮结果当答案。选择清晰典型图、嵌套块跨图图纸、画法歧义缺资料图；开发与保留样本按项目/画法隔离，不只换文件名。

逐系统、规格、楼层、类型比较漏项、重项、误连、错规格、数值偏差、未决范围及人工修正量。验证同件多视图、两处接点只确认一处、同坐标异标高、环网多源、断口不补长、附加只计一次、尺寸修改连锁重算。

合成回归只证明所测约束。没有实跑DWG/Core Console、真实识图、浏览器视觉和业务复核，不升级为正式能力，也不宣称所有专业自动识图已成熟。
